## 本次实测最重要的发现（负面，留档）

**对抗性场景是技能净提升最小的地方**：p3 组三张卡全部 tie 或接近 tie——当前强模型对「冷开篇不可取」「过渡集不能水」「爽点不能单一拉满」这类**常识性错误已有先验，不带技能也会劝**。
技能的真实增量在**它独有的体系化产出**上：反转结尾卡把「三句以内/不替读者下结论/价值重估」执行成可判定的交付纪律（clear 胜出），开篇八法卡把「八法标注/付费点四写法」变成逐项可查的结构（slight 胜出）。
⇒ **结论：技能的价值不在「纠正常识错误」，在「把专家级执行纪律变成默认动作」。后续测评应加重体系化产出类用例的权重。**

## 复现方式

- 测试用例：各技能目录 `test-prompts.json`（3 用例/卡）
- 运行原始输出：`runs/<slug>/p{1,2,3}-{with,base}.md`
- 独立评审报告：`runs/<slug>/judge.md`
- 评分日志：`results.tsv`（9 列，eval_mode=full_test）
- judge 为独立子 agent 盲评（不知条件归属），主 agent 只做结构维度静态评分

## 诚实边界

- 单模型单版本（当前会话模型）实测，不等于跨模型稳定；
- 每用例 1 次运行，非多次采样平均——judge 噪声存在，组判定只信 clear/slight 分级不信绝对分；
- E1 标注含义：**当前版本 + 当前模型 + 真实用例实测净提升为正**，不保证其他模型/其他用例复现。
