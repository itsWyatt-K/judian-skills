# 结尾（成稿）

老板是第三天头上，听说酒婆死了。

清早扫街的来沽酒，顺口说起的：后半夜，有人看见酒婆倒在街口的雪地里，身子都僵了。脸上倒带着笑，像喝到了这辈子最舒坦的一口酒。官面上的人来收尸，翻她的兜，翻出几个铜板，用手绢包了一层又一层——是留着明天再来喝一碗的。

老板听完，把手里的酒盅轻轻放下。盅里的酒是真的，前天进的货，一滴水没兑。他盯着那盅酒看了很久，忽然想起十天前的夜里，酒婆就坐在这儿，端着酒盅，眯着眼跟他说：

“老板，我喝了你十年酒，一口真的都没喝过。哪天你要是进了真酒，我第一个来。”

他当时笑着应了一声：“好。”

他没当真。她当了真。

那天上午，酒厂换了东家，送来的酒货真价实，再不掺水。老板本想照老规矩自己兑水，手伸到半路，不知怎么想起了她那句话。他在柜台后面站了一袋烟的工夫，最后一咬牙：让她喝一口真的吧。十年了，就当还她个人情。

就这一口，要了她的命。

老板锁了门，去了街口。雪地上的粉笔圈还在，圈里只剩一滩早冻透的酒渍。他在那滩酒渍前站了很久。十年了，他每夜看着她喝下半碗假酒，红着脸上路，摇摇晃晃，却从没在这条街上躺下过。他一直以为，是她命大。

现在他才明白，不是她命大。是他那十年的假酒，一直替她扶着墙、撑着腿，一夜一夜把她送回家的。真酒才要她的命。她这一辈子，就死在“心想事成”四个字上。

回到酒馆，老板把剩下的真酒一缸一缸搬到门口，当着半个街坊的面，全倒进了阴沟。然后他从床底下翻出十年前那个方子，重新兑了一缸。假酒出缸那天，酒馆照常开门，灯照常亮，柜台后面坐着的，还是那个卖了十年假酒的老板。

老客来喝酒，咂咂嘴，皱眉：“今儿这酒，味儿不对。”

“假的。”老板说。

“假的？”

“假的死不了人。”老板往柜台上一趴，“真的才死人。”

打那天起，酒馆的灯每夜都亮到很晚。老板守着这条街，守着一屋子的假酒。夜夜有人来，夜夜有人走，再没有人死在街上。

只是他再也不去街口站着。倒酒的时候，手也不再抖了。

---

## 设计说明

- 明反转：杀死她的不是假酒，是她自己那句“想喝真酒”——心愿成真之日，即是死期。
- 暗反转：十年假酒一直在暗中保她活着；老板迟来的那点“良心”，才是那把刀。
- 终反转：读者等着他关张赎罪，他却把真酒倒进阴沟、重操旧业——“假的死不了人，真的才死人。”卖假酒，倒成了这条街上唯一的慈悲。
