# 《认错了》——喜剧场景收尾成稿

> 两人吵到一半，发现都认错了人。反转不止"抖包袱"一次：两条误线同时收拢，误骂出口的话，字字落在另一个人身上。

## 场景与人物

- **场景**：老旧小区楼道，深夜。声控灯坏了一半，一半能亮。
- **老陈**，55岁，工地安全员，喝了点酒，攥着一张揉皱的照片——找包工头赵建国赔儿子住院的钱。
- **小周**，29岁，刚被辞退的房产中介，抱着纸箱上楼——箱子里是全部家当，明天本该搬走。
- **道具**：照片（赵建国）、门牌号（三栋二单元 / 五栋）、一只纸箱。

## 台词成稿

【声控灯"啪"地亮了半层。老陈堵在楼梯口。小周抱着纸箱上楼。】

**老陈**：赵总。您这觉，睡得可真够死的。

**小周**：（把纸箱往台阶上一放，火蹿上来）我都说了明天就搬！合同写的是十五号，今天才十三！你们这叫违约！

**老陈**：（一噎，随即更怒）你跟我吼？你撞了人，跑了三个月，现在跟我吼？

**小周**：什么撞人？你们收房的时候怎么不说？锁都换了，现在跟我讲合同？

**老陈**：（逼近）我儿子二十八！二十八的人，现在还躺着！我陈大江五十五年没跟人低过头——人只要肯认，事就不大，你跑什么你跑！

**小周**：（话赶话，声音也高了）那我呢？我在这个城市八年！八年！说让我走就让我走，给我一天时间了吗？！

**老陈**：我让你赔钱，没让你搬！

**小周**：我让你退押金，没让你骂人！

【两人同时一噎。都从对方嘴里听出了不对。】

**老陈**：……什么押金？

**小周**：……什么医院？

【静了两秒。老陈慢慢掏出照片，借声控灯看。小周凑过去，也看清了照片上的人。】

**小周**：……这人谁？

**老陈**：赵建国。包工头。（顿）……不是你。

**小周**：……我叫周源。三栋的租客。

**老陈**：（低头看手里的地址，又抬头看门牌）……三栋二单元。这是五栋。

【声控灯灭了。老陈"啪"地拍了两下手，灯亮了。】

**小周**：叔，赵建国……住三栋？

**老陈**：嗯。邻居说的，应该没记错……

**小周**：（指指自己怀里的纸箱）这一片我熟，之前帮客户找房。三栋二单元，二楼，左手第一户。（顿）我陪您过去？

**老陈**：（看他一眼）你不搬了？

**小周**：（愣了愣，苦笑）……合同都黄了。搬哪儿去。

【老陈没接话，转身往下走。小周抱起纸箱，跟在后面。走到二楼转角，老陈忽然停住。】

**老陈**：小伙子。

**小周**：嗯？

**老陈**：刚才……对不住。

**小周**：（沉默几秒）叔，您有句话，其实骂得挺准的。

**老陈**：哪句？

**小周**：人只要肯认，事就不大。（顿）我不是赵建国。可您骂的那些——跑了、躲了、睡得着——我听着，句句都像我。

【声控灯灭了。老陈在黑暗里轻轻拍了两下手，灯亮了。】

**老陈**：……走吧。灯给你留着。

【老陈下楼，脚步声远了。小周站在原地，低头看了看箱子——最上面，露出一件叠得整整齐齐的灰色连帽衫，和照片上那人身上那件，一模一样。】

【小周站了几秒，忽然转身，上楼。】

【声控灯一层一层，亮了上去。】

【收光。】

## 收尾设计说明

1. **反转结构：双向认错。** 两个火药桶都认定对方是自己的"仇人"，于是谁都觉得对方"句句可恨又句句在理"，架才吵得起来、吵得凶。包袱在"押金/医院""三栋/五栋"两处对撞中一次抖开，信息一镜收拢，不拖第二抖。
2. **余味一：误骂成真。** 老陈骂赵建国的话——跑了、躲了、睡得着——字字落在小周自己身上。观众笑完才回过味：骂错人的话，反而骂中了另一个该被骂醒的人。所以小周最后那句"我不是赵建国"，不是辩解，是认账。
3. **余味二：拍手与灯。** 愤怒的老人用最笨的方式给陌生的年轻人留灯。前半场有多横，这一拍就有多软，人物弧线在一秒内完成。
4. **余味三：灰外套。** 全城打工人都穿一样的灰外套——这就是认错人的土壤。小周最终转身上楼，是被一句误骂踢回了"不逃"的那一边；灯一层层亮上去，人已不见，收在"余"上。

**表演提示**：反转后的沉默至少留两秒；"灯给你留着"要轻，不能喊；收光放在灯一层层亮上去、人已经不在画面里的那一刻。
