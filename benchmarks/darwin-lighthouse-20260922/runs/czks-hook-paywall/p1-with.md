# 《赘婿》前3集开篇设计 · 男频赘婿逆袭 · 抖音竖屏 · 单集90秒

> 付费点选型一句话：本剧首付费点采用四写法之「身份差付费点」——林渊隐藏身份在第9集尾全面曝光，与第1集「报恩守苏家」的目的直接呼应；前三集所有冲突、伏笔、反转全部向这一爆点蓄力。

## 一、项目定位

- **题材**：男频赘婿逆袭（隐藏身份 + 打压反击 + 豪门恩怨）
- **平台/形态**：抖音竖屏短剧，单集90秒，3秒出冲突，每集尾留钩子
- **核心信息差**：全苏家当林渊是吃软饭的废物赘婿；观众从第1集起知道他不是——爽感来自"剧中人不识货，观众先知道"
- **一句话主线**：灭门遗孤林渊入赘苏家报恩三年，苏家辱他、叛他、卖他，他在第9集当众亮出真身，护住苏家，也揭开三年前灭门真相。

## 二、人物

| 人物 | 定位 | 前三集功能 |
|---|---|---|
| 林渊（男主，26） | 表面：苏家废物赘婿；实际：林氏灭门遗孤、龙刃旧部之主"渊阁阁主"、神医传人 | 被压制的一方，每次反转只露一线真身 |
| 苏晚晴（女主，25） | 苏氏集团总裁，冷傲，被逼联姻 | 关系拉扯轴心：冷漠→疑心→动摇→递笔手抖 |
| 王凤兰（主母） | 势利、刻薄 | 羞辱主火力，第3集主导"卖婿" |
| 苏浩铭（小舅子） | 纨绔、抢功、闯祸 | 羞辱执行者，陷害案执行者 |
| 苏正庭（老爷子） | 苏家创始人，三年前火场救下林渊 | 第1集倒下的危机源；知晓林渊身份的"暗灯塔" |
| 赵天豪 / 秦枭 | 赵氏公子 / 秦家家主（灭林家幕后） | 第2集做局、第3集逼宫登场的双反派 |

## 三、第1集《逐婿》时长轴与剧本

**时长轴**：0-3s寿礼落地｜3-20s当众羞辱｜20-40s逐婿令+离婚协议｜40-55s老爷子倒地｜55-75s掏针被当"弑父"、针包打飞｜75-90s神秘电话+狠话收尾

### 分场剧本

**【场景一】苏家老宅·寿堂·夜**

（特写）一盒土黄纸包的药膏落进堆满金镶玉礼盒的寿礼堆里。

王凤兰（捏起药盒，嫌弃）：地摊货也配上苏家的台面？

苏浩铭（拆开念）："龙虎断续膏"？哈哈哈哈姐夫，你这假药哪儿批发的？妈，他咒咱爸呢！

全场哄笑。

林渊（平静）：治跌打，续筋脉。不信，可以留着。

王凤兰：别叫我妈！寿宴一散，你就滚出苏家！

（推镜）苏浩铭把离婚协议拍在林渊胸口，一支笔滚落在地。

苏浩铭：签了它。三年了，我姐连手都没让你碰过，你也配姓苏？

苏晚晴（背对人群站着，指尖攥紧杯壁，没有回头）。

林渊（弯腰捡笔，忽然抬眼）：笔我可以签。但在签之前——

（身后"砰"的一声闷响）

**【场景二】寿堂中央**

苏正庭（致辞中猛地扶案，口吐白沫，倒地抽搐）：……

管家（嘶吼）：叫救护车！快！

家族医生（匆匆把脉，脸色骤变）：急性心衰！路上堵死了，来不及了……准备后事吧。

全场大乱。苏浩铭（红着眼一把推开林渊）：都怪你这个丧门星！滚！

（特写）林渊从怀里掏出一卷旧帆布针包，银针根根泛着幽光。

林渊（单膝跪地）：让开。三分钟，我保他。

王凤兰（尖叫）：苏浩铭！他要杀你爸！拦下他！

（慢镜）苏浩铭一拳砸向林渊面门——针包飞脱，银针撒了一地。

林渊撞上桌角，缓缓滑坐，嘴角渗血。笑声、骂声、哭声糊成一片。

（特写）林渊抬手抹掉血，在哄闹中缓缓站起。

林渊（极轻，像说给三年前听）：我保了他三年，没人信过一次。

（特写）他掏出一部屏幕碎裂的旧手机，拨号。通讯录备注只有一个字："刃"。

电话秒通。

电话音（颤抖、毕恭毕敬）：……龙先生？！三年了，您终于肯接电话了——

林渊（淡淡）：苏城，苏宅，救命。十分钟。

全场死寂。

林渊（抬眼扫过众人）：从现在起，谁再动我一下，老爷子殉葬，苏家陪葬。

（黑屏，字幕：三年前，他挂断这个电话的那天，发生了什么？）

### 本集八法落点

- **① 第1行陷危机**：第一秒寿礼被摔打、三分钟内连遭羞辱，男主从未离开危机
- **②④ 塞信息+埋伏笔**：银针（神医线）、手机备注"刃"（身份线）、三年隐忍（动机线）
- **③⑤ 信息差+拉扯**：全家视他废物；苏晚晴背身不回头，但"指尖攥紧杯壁"埋下动摇
- **⑥ 反转**：废物袖藏银针 → 神秘电话秒接，位高权重者口称"龙先生"
- **⑦ 压情绪+反击信号**：被打、被辱压到最低；反击信号的第一缕是那通电话

## 四、第2集《暗牌》时长轴与剧本

**时长轴**：0-5s直升机降落｜5-20s误会长老"恰好"路过、林渊继续被嘲笑｜20-40s赵天豪登门逼债三亿、条件是苏晚晴陪出差｜40-55s酒局林渊被驱赶、低声点破赵家批文有假｜55-70s赵天豪接急电反被做局赔罪｜70-85s车库背影与半截"渊阁"名片｜85-90s药方字迹对上老爷子书房落款+老爷子呢喃龙王玺

### 分场剧本

**【场景一】苏宅上空→寿堂外·晨**

（外景）三架直升机轰鸣降落，白大褂人群小跑入院。

院长（擦汗对管家）：哪位是苏老？快！备针！

（堂内）苏正庭悠悠转醒。王家众人喜极而泣，对着院长千恩万谢。

王凤兰（斜眼看林渊）：某些人啊，装神弄鬼，正巧人家院长义诊。

苏浩铭：哈哈哈哈龙先生？他咋不叫龙王爷呢！

林渊（垂眼扫地，不辩）。

苏晚晴（人群中第一次正眼看他，欲言又止）。

**【场景二】苏氏集团·会客室·日**

赵天豪（把合同摔在桌上）：苏氏旗下建材厂抽老千，违约金三亿。不过嘛——赵某可以宽限，只要晚晴姐陪我去出一趟差，一周。

苏浩铭（赔笑）：赵少，这……

苏晚晴（攥拳，指甲掐进掌心）：……我去。

（闪回一帧：三个月前雨夜，苏晚晴被劫匪逼停，一个戴黑色腕带的神秘人一招制敌，消失在雨里。同款黑色腕带，系在林渊左手。）

**【场景三】赵氏酒店·酒桌·夜**

苏晚晴被灌第三杯。赵天豪的手搭上她的腰。

苏晚晴（躲开，冷）：赵少。

（门开）服务生林渊低着头送果盘。

赵天豪（讥笑）：哟，苏总家废物赘婿也来陪酒？行，你老婆这杯酒，你替我喝。

林渊（端起杯一饮而尽，放下空杯）：赵少，三亿的合同，你父亲知道吗？

赵天豪（愣，随即大笑）：你算什么东西，也配提我爸？

林渊（压低声音，只有两人能听见）：赵氏城南那块地，批文是假的。我说的对吗，赵少。

（特写）赵天豪瞳孔骤缩。

**【场景四】酒桌→苏宅·夜**

赵天豪手机狂震。接听，脸色由红转白。

赵天豪（起身鞠躬）：苏总！刚才玩笑！合同作废！违约金分文不取！我爸还有事，先走！

（赵天豪狼狈冲出门）

苏家人面面相对，只道天降好运。苏浩铭（拍胸脯）：我就说那合同有猫腻，是我谈下来的！

**【场景五】苏宅车库·夜**

苏晚晴取车，撞见赵天豪立在角落，对一个穿司机服的高大背影鞠躬哈腰，双手捧上一张卡。

背影（抬手制止，声线低沉）：滚。

（车灯一晃）背影已不见。地上落着半截烫金名片，被苏晚晴捡起——

（特写）名片残字："……渊阁"。

**【场景六】苏宅·林渊房中→医院·夜**

苏晚晴推门送文件，愣住——

（特写）林渊伏案写药方，狼毫落纸，字迹瘦硬如刀。

（叠化）苏正庭书房那幅字："雪夜赠药，没齿不忘——苏正庭"，落款小字一个"渊"字，笔势与眼前药方一模一样。

（苏晚晴手一抖，文件散了一地）

（医院·夜）老爷子昏迷中攥紧管家的手，呢喃：渊小子……龙王玺……就藏在苏家……别让秦家……找到……

（黑屏，字幕：苏家，到底藏着林渊的什么？）

### 本集八法落点

- **②④ 信息加密+新伏笔**：黑色腕带（呼应三个月前救命之恩）、半截"渊阁"名片、龙王玺藏于苏家
- **③⑤ 拉扯升级**：苏晚晴"第一次正眼看他"；字迹对上，疑心落到纸面
- **⑥ 反转**：第3集结尾还任人嘲笑的赘婿，是赵天豪都要鞠躬的"司机"——反做局成功而无人知情
- **⑦ 压情绪**：全场误当笑话，爽点全部压在观众一侧；老爷子一句"龙王玺"把主线拉向更大黑幕

## 五、第3集《离婚》时长轴与剧本

**时长轴**：0-10s捉奸陷害局｜10-30s王凤兰逼离婚净身出户、苏晚晴递笔手抖｜30-45s林渊签字只落半个名字、宣言"承诺到期"｜45-60s秦枭登门当众曝光"林家余孽"档案｜60-75s林渊被按倒、花瓶砸头、雨夜逐出大门｜75-90s长街灯灭、黑影围街、秦枭接急电仓皇撤走

### 分场剧本

**【场景一】苏宅·二楼走廊·晨**

（一个女人衣衫不整从林渊房内冲出，撞见苏晚晴，尖叫着跑下楼）

王凤兰（哭天抢地）：哎呀苏家的脸丢尽了！赘婿偷人偷到正主头上！

（房内）床头柜上一捆现金、一枚扯碎的珍珠耳环。苏浩铭（"义愤填膺"）：姐！这还得了？报警！

苏晚晴（指尖发白，声音很轻）：林渊。解释。

林渊（看她两秒）：我解释过。你信吗。

（闪回一帧：苏晚晴加班深夜，林渊把姜汤放在她桌角，被她当众倒掉——"别演了。"）

苏晚晴（闭眼）：……离婚吧。

**【场景二】苏宅客厅·日**

王凤兰（把离婚协议拍在桌上）：签！净身出户！不然我立刻报警，让你吃牢饭！

林渊（提笔，笔锋一顿，落名）——（特写）只写完一个偏旁，笔锋如刀，合同被苏浩铭一把抽走：签了！废物也配写全名？

林渊（起身，掸了掸衣角，像掸掉三年灰尘）：三年之期，今日到期。入赘，是为守一个承诺。承诺了了——苏家的事，我不再管。

苏晚晴（心头莫名一空）。

**【场景三】苏宅大门·日**

（汽车轰鸣）秦枭（五十岁，负手，两名黑西装随从）登门，笑吟吟拱手：苏老爷子大难不死，秦某特来道贺。另外——听闻府上藏了一位故人之子，林渊。

（特写）秦枭展开一份泛黄档案，当众念：林氏余孽，林渊。三年前苏宅火场，唯此一人漏网。

全场死寂。王凤兰（瘫坐，随即跳起来指林渊）：怪不得！你是扫把星！来人！绑了送给秦先生！

林渊（被反剪双手按跪在地，忽然低笑）：苏家养我三年，今日卖我，两清。

（慢镜）苏浩铭抡起花瓶砸向林渊后脑——

苏晚晴（脱口）：住手！

（花瓶碎裂）林渊额头血流如注，被拖出大门，扔进雨里。

**【场景四】苏宅大门外·雨夜**

秦枭（撑伞，俯视泥水中的林渊）：你师父把龙王玺藏进了苏家。交出来，我赏你全尸。

林渊（缓缓抬头，抹了把脸上的血，笑了）：三年前，苏正庭跪着求我活下来的时候——你们秦家，还在给我林家看门呢。

（特写）秦枭脸色骤变，拔枪顶住林渊眉心：你找死！

（突然）长街两侧路灯"唰"地尽灭。

（雨幕）不知何处而来的黑色车队无声围拢，数百黑影立定，雨夜中看不清面目。

秦枭手机狂震。接听，手一抖，伞落地。

秦枭（嘶声）：撤！全撤！

（黑车绝尘。雨里只剩林渊跪立的剪影）

**【场景五】苏宅二楼窗口·雨夜**

苏晚晴（攥着那半截"渊阁"名片，望着雨夜中男主的背影，泪毫无预兆地落下来）——她不知道自己为什么哭。

（医院·特写）老爷子床头监护仪，心跳曲线猛地飙升。

（黑屏，字幕：三年前那场大火，烧掉的是林家一百三十七口人——还是林渊最后一丝"人味"？）

### 本集八法落点

- **① 危机叠加**：陷害离婚 + 秦枭逼宫双压，男主在"自己人"手里流血
- **⑥ 反转且自洽**：离婚=三年承诺到期，身份线寸步未泄；签字只落半字，把真名悬念完整留给付费点
- **③⑤ 拉扯顶点**：苏晚晴"递笔手抖""脱口住手""窗前落泪"，冷漠立场被事实一寸寸撬开
- **⑦ 压到最低 + 反击信号**：雨夜砸头是压情绪谷底；长街灯灭、黑影围街、秦枭仓皇撤走，是首付费点前最强的一道反击信号

## 六、首付费点设计（第9集尾卡点）

- **写法**：四写法之「身份差付费点」——林渊隐藏身份在付费点全面暴露。当秦枭枪指苏晚晴逼问龙王玺、苏家即将灭门时，林渊当众现出"渊阁阁主"真身，黑影跪满长街，苏晚晴与苏家第一次看见丈夫的真面目。
- **与第1集目的呼应**：第1集目的是"报恩、守住苏家"；付费点是"身份公开、以渊阁之力保住苏家"——同一目的的第二次推进。
- **只解一个问题**：付费点只解决"林渊身份公开"这一件事。离婚关系的复合留到第12集（妻子追夫），秦枭复仇总攻留到第20集后，龙王玺归属在第10集单独解——不向付费点一次塞多事件。
- **压情绪曲线**：第4-8集持续压（羞辱+误解+秦家逼宫升级+苏家二次背叛），第8集尾先上反击信号（黑影跪街被苏晚晴亲眼撞见），第9集付费点集中释放。
