# 《赘婿藏锋》前三集开篇设计案

（男频 / 赘婿逆袭 / 抖音端竖屏短剧 / 单集 1 分 30 秒）

## 一、项目定位

| 项目 | 设定 |
|---|---|
| 题材 | 男频·赘婿逆袭（战神归位 + 报恩守诺 + 微悬疑） |
| 平台 | 抖音端原生付费短剧，竖屏 9:16 |
| 单集时长 | 1 分 30 秒（含 0-6 秒黄金钩子 + 3-5 秒黑屏卡点） |
| 集数节奏 | 每集 1 个核心冲突 + 1 个硬反转 + 1 个集尾卡点 |
| 付费模式 | 前 3 集免费引流；首付费卡位建议第 8-10 集（身份差全爆："龙渊"当众归位） |
| 台词密度 | 每集对白约 250-330 字，语速 4-4.5 字/秒，留足动作、音效与情绪停顿 |
| 备选剧名 | 《三年赘婿，今天不装了》《废婿有龙》（便于抖音搜索关键词布局） |

**开篇策略（只做热开篇）**：第 1 集第 1 秒即冲突——离婚协议拍桌、满堂逼签，零铺垫镜头。第 1 集立住"信息差"：观众从副官来电即知男主是"龙帅"，剧中人只当笑话——此后每一集羞辱都是给观众的"预支爽感"，爽感留到付费点集中兑付。

## 二、核心人设（标签锁性格，防崩塌）

| 人物 | 身份 | 标签 | 功能 |
|---|---|---|---|
| 秦铮 | 明：江家废物赘婿、外卖骑手；暗：镇北军统帅，封号"龙渊" | 隐忍、重诺、出手即巅峰 | 为报江老爷子救命之恩入赘，守"护晚晴三年"之诺；主线：查老爷子猝死真相 |
| 江晚晴 | 江氏集团副总，老爷子亲孙女 | 外冷内热、护夫、清醒 | 全场唯一护男主的人；第 2 集为夫踏出江家；第 3 集发现父亲疑点 |
| 王丽华 | 岳母 | 势利、刻薄、变脸快 | 前三集头号施压者；第 2 集末第一次低头（连续打脸位） |
| 江成峰 | 岳父，江氏集团董事长 | 圆滑、城府深 | 第 3 集埋"疑似参与害死老爷子"阴影，制造翁婿、夫妻双重拉扯 |
| 江晚悦 | 小姨子 | 拜金、拱火 | 嘲讽担当；第 2 集直播"姐夫被扫地出门"，评论区引爆点 |
| 赵天赐 | 赵氏集团独子，情敌 | 纨绔、嚣张 | 第 1 集当众宣布下聘，第 2 集被父亲当众打脸，仇恨延续至付费段 |
| 赵乾坤 | 赵氏集团董事长 | 势利、审时度势 | 第 2 集雨中鞠躬，完成半曝光打脸 |
| 陈锋 | 男主副官 | 只闻其声 | "信息差阀门"：观众凭他确认男主真身份 |
| 忠叔 | 老爷子旧仆 | 知情人 | 第 3 集奉遗命送铁盒，递出主线与势力底牌 |

## 三、三集总纲与钩子链

**大目标（第 1 集立）**：护晚晴；查清老爷子猝死真相。

**小目标拆解**：
- 小目标 1（第 1-3 集）：寿宴风波中不让晚晴被逼嫁——受挫失败（赵家下聘成功、二人被逐），目标升级；
- 小目标 2（第 3 集启动，第 4-6 集实现）：脱离江家仍护晚晴，并保住她在乎的江氏；
- 主线暗线（贯穿）：老爷子之死——第 3 集锁定第一嫌疑人：岳父。

**信息差布局**：观众（知：男主是龙帅、赵家畏他、老爷子留有底牌）对剧中人（只知：废物赘婿）。每一次羞辱 = 给观众预支一次爽感。

**情绪曲线**：第 1 集压（当众逼签 + 护夫耳光）→ 第 2 集压至谷底（扫地出门 + 雨夜）后给半口糖（赵乾坤雨中鞠躬）→ 第 3 集糖中带刀（身份半露、岳父疑云收尾），情绪不落地，直推付费。

**伏笔清单（兑现均不超过 3 集，或明确挂靠付费段）**：

| 伏笔 | 埋设 | 兑现 |
|---|---|---|
| 副官来电"三年之期已到" | 第 1 集 | 第 3 集"启动潜龙"首尾呼应，付费段全爆 |
| 掌心刀茧 / 旧军装 / 弹壳 | 第 1 集 / 第 2 集 | 第 3 集铁盒印证，付费段身份全爆 |
| 赵天赐胸前古玉 | 第 1 集 | 第 2 集"古玉，摘了"，后续赵家靠山线 |
| 老爷子"心梗猝死" | 第 1 集尾 | 第 3 集启动调查，付费段揭晓 |
| 铁盒"大劫方可开" | 第 3 集 | 第 3 集开启，"听潮一脉"延至付费段 |
| 病房走廊背影 + 腕表 | 第 3 集尾 | 第 8-10 集付费点揭晓 |

## 四、分集剧本

### 第 1 集《逼签》（1:30）

**本集任务**：热开篇当众羞辱；立信息差；埋主线钩子；给第 2 集"下聘"加压。

【0:00-0:06 · 黄金 6 秒】
江家老宅寿宴大堂，宾客满堂，红绸高挂。
（特写）一纸离婚协议"啪"地拍上桌面，震得寿桃碟一跳。
王丽华（岳母）："秦铮，签了它。你吃江家的、住江家的，一个废物——也配做我王丽华的女婿？"
（拉）秦铮站在堂中，围裙未解，手里还拎着给岳母贺寿的保温壶。满堂嗤笑。

【0:06-0:20 · 信息交代 + 拱火】
江晚悦（小姨子，挽着赵天赐）："姐，你看看他！送外卖的命，操副总的心。天赐哥哪点不比他强？"
王丽华："今天赵家带厚礼上门，有些人，自己自觉点！"
（特写）首席位上，赵天赐含笑举杯，贺礼——一份《江北地块合同》摆在中央，满堂喝彩。
江晚晴（妻，素色旗袍，第一次开口）："妈。今天您寿辰，非要这样？"
王丽华（摔筷子）："我还没死！这个婚，离定了！"

【0:20-0:38 · 压情绪：护夫被辱】
江晚晴放下酒杯，静静走到秦铮身前，挡着他："我的丈夫，我护定了。"
"反了你了！"——（音效）一记耳光，清脆。晚晴脸颊瞬间红肿。
秦铮瞳孔一缩，扶住她，指节攥得发白。
秦铮（低声）："……对不起。"
江晚晴（通红的眼看他）："三年了。你除了对不起，还会说什么？"
秦铮张了张口，无言以对。
（特写）他垂在身侧的手——掌心旧茧、刀痕，与这身围裙格格不入。

【0:38-0:55 · 身份悬念 · 信息差阀门】
秦铮手机震动，屏幕亮起一个字：锋。他按断。又震。
王丽华一把抢过，点开免提——
陈锋（电话内，激动嘶吼）："龙帅！三年之期已到！边境三十万弟兄，等您归位——"
全场死寂两秒，轰然哄笑。
王丽华（把手机摔回他怀里）："还龙帅？你怎么不说是玉皇大帝！戏，演够没有！"
秦铮捡起手机，神色平淡："打错了。"
（特写）他垂眼，掩去一闪而过的锋芒。
【字幕炸出·给观众】他没打错。

【0:55-1:15 · 冲突升级：逼嫁】
赵天赐起身，当众向王丽华深深一揖："伯母，我赵天赐非晚晴不娶。下月初八，我赵家——正式下聘。"
王丽华（大喜）："好！好！"
江晚晴（失色）："你们……"
秦铮（终于抬眼，看向赵天赐）："赵天赐。你胸前那枚古玉，别乱戴。"
赵天赐（一愣，嗤笑）："废物也配教训我？识相的，滚去后院——今天给你留口剩饭。"
哄笑再起。秦铮垂目，不语。

【1:15-1:30 · 集尾卡点】
（夜，长廊，BGM 渐弱）
江晚晴追出来，拽住他衣袖，声音发颤："秦铮……三年了。你到底，是谁？"
秦铮（替她拢紧外套，一笑）："我？废物。"
他转身接起电话，背影没入黑暗："说。"
陈锋（压低）："龙帅，查到了。三年前，江家老爷子那场'心梗猝死'……另有隐情。"
秦铮脚步，骤然一顿。
（镜头缓缓推向堂上——江老爷子的遗像）
【黑屏字幕】他入赘三年，从不为吃一口软饭。
【下集钩子字幕】下集：赵家下聘，扫地出门。

**第 1 集复盘**：反转 = 副官来电（身份悬念反打全场嘲笑）；爽点预支 = 观众知情；仇恨拉满 = 护夫耳光 + 逼嫁；主线钩 = 老爷子死因。

### 第 2 集《下聘》（1:30）

**本集任务**：仇恨压至谷底；妻子为夫出走锁死感情线；恶母第一次低头；小爽半曝光。

【0:00-0:08 · 黄金 8 秒】
江家大门外，锣鼓喧天。赵家聘礼队伍抬箱入院，红绸铺地。
赵天赐（高举婚书，当众宣）："从今日起，江晚晴，是我赵家钦定的媳妇！"
王丽华笑得合不拢嘴，回头吩咐管家："把后院那间杂物室，清出去。江家——不养闲人。"

【0:08-0:28 · 扫地出门（压至谷底）】
（特写）男主的行李被扔出大门，滚落台阶，散了一地。
一只旧铁皮盒摔开——里面是一套叠得方正的旧军装，和一枚磨花的弹壳。
江晚悦（举着手机直播，大笑）："家人们！现场直播！我姐夫——被扫地出门啦！"
秦铮弯腰正要去捡，一只名牌高跟鞋"哒"地踩住那枚弹壳。
江晚悦："捡垃圾的命。"
秦铮（声音淡下去）："抬脚。"
江晚悦（故意碾）："偏不。"
秦铮（抬眼，平静）："有些东西，你踩不起。"

【0:28-0:45 · 感情线锁死（第一次护夫）】
江晚晴从客厅走出，看见满地狼藉，脚步停了。
三年来，她第一次违逆这个家——
江晚晴："秦铮。走。"
王丽华（惊）："你说什么？！"
江晚晴（一字一顿）："他走。我跟他走。"
王丽华（尖叫）："你今天敢踏出这个门，就别认我这个妈！"
江晚晴（眼圈通红，却笑了）："从我嫁他那天起，我就只有一个家。"
她伸出手。秦铮看着那只手，沉默两秒，握住。
（全景背影）两人踏出江家大门，红绸在他们身后，像一团烧剩的火。
【BGM】鼓点起，情绪顶点。

【0:45-1:05 · 危机总爆 + 恶母低头】
江氏集团。屏幕绿光暴跌。
秘书（冲进病房）："江总！赵家官宣——撤销全部三亿注资！放话：想救江氏，拿大小姐联姻来换！"
病床上，江成峰急怒攻心，捂着心口倒下。
王丽华（六神无主，忽然想起什么，冲进雨里）："……秦铮！秦铮！"
（雨夜长街）她拦住那对夫妻，伞掉在地上。第一次，低声下气：
王丽华："……以前，是妈不对。只要你有办法救江家，妈……给你赔不是。"
秦铮（扶她起来，语气平静）："妈，先回去。江家，塌不了。"
【字幕】此刻无人知晓：这句话，值多少个亿。

【1:05-1:30 · 小爽 · 半曝光卡点】
"砰——！"一辆黑色轿车急刹在雨里。
车门开，赵氏集团董事长赵乾坤，竟亲自下车。
赵天赐（以为来撑腰）："爸！你来得正好！就是这——"
赵乾坤（看都没看他，径直走到秦铮面前，在暴雨中，弯腰九十度）：
"秦先生。犬子有眼无珠，赵家……特来赔罪。"
赵天赐（如遭雷击）："……爸？！"
江晚悦（直播手机"啪"地掉进水洼）。
王丽华（僵在原地，伞彻底歪了）。
秦铮（抬手，掸了掸赵乾坤肩上的雨）："回去告诉赵天赐——古玉，摘了。"
【黑屏字幕】一个电话，赵氏股价，跌了三成。
【下集钩子字幕】下集：老爷子遗盒，现世。

**第 2 集复盘**：反转 = 赵乾坤雨中鞠躬（全场打脸）；爽点 = 半曝光，信息差仍在；仇恨 = 扫地出门 + 踩弹壳；感情线 = 妻子随夫出走；恶母低头 = 第 3-6 集连续打脸位。

### 第 3 集《遗盒》（1:30）

**本集任务**：身份半揭露；老爷子铁盒开启主线与势力底牌；岳父疑云收尾，情绪不落地直推付费。

【0:00-0:10 · 黄金 8 秒（紧接雨夜）】
赵天赐（不信，冲上来）："爸！你给一个废物鞠躬？！"
赵乾坤（回身一记耳光，暴喝）："住口！你可知，我赵家上下三百口，抵不上秦先生一根手指！"
赵天赐（捂脸，懵）："……他、他到底是谁？"
赵乾坤（冷汗直下，对秦铮更深一躬）："秦先生，下聘之事，赵家……绝不敢再提。"
秦铮（不置可否，牵晚晴与他擦肩而过）："嗯。滚吧。"

【0:10-0:30 · 半揭露 + 妻子的疑问】
江家人匆匆赶到，正看见赵乾坤鞠躬一幕，全员石化。
王丽华（嘴唇哆嗦）："秦……秦铮他……"
江晚晴（望着丈夫平静的侧脸，三年疑云翻涌）："你到底，是谁？"
秦铮（替她拢紧被雨打湿的外套，一笑）："先回家。江家，塌不了。"
（他答非所问。晚晴看着他的背影，没有追问——她比谁都清楚，这个男人，藏得最深。）
【评论区埋点】他到底是谁！！！

【0:30-0:50 · 老爷子遗盒（主线 + 势力底牌）】
（深夜，秦铮住处）敲门声。忠叔（老爷子旧仆）捧一只铁盒，老泪纵横：
"姑爷。老太爷临终前吩咐——江家逢生死大劫，方可开此盒。"
（特写）盒中三物：一封信、一枚褪色龙纹印、一张"心脏骤停"旧病历单。
信（老爷子江誓行笔迹）："秦铮小友：晚晴性柔，此劫无解。持此印，可调'听潮'一脉，救她一次。"
秦铮（指尖发颤，眼底发红）："老爷子……原来您，早就知道。"
忠叔（跪下）："老太爷还有一句话——他的死，不是天灾。是有人，等不及了。"

【0:50-1:10 · 反转：查案启动】
秦铮（拨号，气场骤变）："陈锋。"
陈锋（立正声）："在！"
秦铮（一字一句）："启动'潜龙'。不动边境，只查一案——三年前，江氏老董事长猝死当晚，谁进过那间病房。"
陈锋（肃然）："是！三个月内……"
秦铮："一周。"
【音效】时钟疾走，压迫感拉满。（BGM 压至最低）

【1:10-1:30 · 集尾大卡点（关系拉扯）】
（深夜，江家老宅，书房）
江晚晴（悄悄翻开父亲的书桌抽屉，手机屏幕亮着）——一份转账记录，和三年前那份"心脏骤停"的旧病历。
她手在抖，拨通秦铮电话，声音轻得像风：
"秦铮……我爸爸，可能有问题。"
（同一时刻，秦铮手机"叮"一声）
（特写）加密邮件送达：三年前病房走廊的监控截图——深夜，一个男人的背影，推开了老爷子的病房门。
（背影放大，看不清脸，但那枚腕表——与江成峰腕上那枚，一模一样。）
秦铮（瞳孔骤缩）："……"
【黑屏字幕】他要查的第一个人，是他的岳父。
【金句弹幕预设】"这声'爸'，还叫得出口吗？"
【挂载】全集入口已开：看龙帅归位。

**第 3 集复盘**：反转 = 铁盒遗命 + 岳父腕表背影；爽点 = 半揭露（赵家打脸 + 潜龙启动）；情绪 = 不落地（至亲疑云），直推第 8-10 集付费点（身份差全爆）。
