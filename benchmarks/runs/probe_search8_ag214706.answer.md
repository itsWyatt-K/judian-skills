## 三、角色设定要点

### 3.1 内核层

| 项 | 内容 |
|---|---|
| **功能定位** | 品牌化身 / 全片视觉锚点 / 记忆位。不是有弧光的主角——15 秒装不下弧光，只装得下一个签名 |
| **姓名与绰号** | **苏趁**，人称「趁露人」。姓名本身 = 她的信念 + 她的语言签名（一元供给三处） |
| **外目标（想要）** | 在天亮之前，把还带着露的茶送到昨天约好的人手里 |
| **内需要（其实缺）** | 她自己也被这座城市追赶，「送茶」是她替自己讨到的一次「慢」——**外目标与内需要错位**，这是她所有行为的引擎 |
| **矛盾同体** | 「最古老的时辰」×「最现代的城市」：采露人 / 早高峰前的通勤者，同一个人 |
| **信念（决策母规则）** | **「东西要赶在太阳前头。」**——所有选择都从这一句推出来 |
| **缺口（必须影响行动）** | 她**从不喝自己采的茶**；围裙口袋里永远有一小包没人领走的茶，是「昨天那个没来的人」的。影响行动：每次递出前先用拇指验露；路过空座位时会多停半秒 |
| **表里关系** | **一致型**（表即是里）——清冷是纯粹，不是伪装。全片只给**一次真表情**：交接那一瞬 |

**魅力机制（2 条）**：① **某维拉满**——「早」这个维度拉到极限，全世界只有她一个人是醒着的，她独自拥有一座空城；② **猜不到但事后合理**——别人以为采露是古意，她其实是个在赶时间的人（母规则「赶在太阳前头」）。
**在乎机制（2 条）**：① **亏欠**——口袋里那包没人领的茶；② **连带**——一只篾片一新一旧、侧面缝着麻布补丁的旧竹篓。

### 3.2 行为层

- **决策模式**：① 山雾未散但首班车将至 → 她把竹篓换到另一侧肩，步子加快，**茶不洒**；② 有人加价买她手里第一杯 → 她不卖，「这杯有主了」；③ 茶洒了一点 → 她用指尖接起来，抹在竹篓边缘，不擦。
- **语言签名**：① 「趁露。」（递茶时，两个字）② 从不说「早安」，只说「还早」③ 被问累不累，答「露不累。」
- **动态签名**：站姿——单肩挎篓，重心倒向靠篓那一侧，整个人微微**向前倾**（永远准备出发）；步态——步幅小、步频快、脚跟轻落（不惊动露）；手势——**递茶前用拇指内侧沿杯沿抹一圈（验露）**，这是全片最容易被记住的那一下。
- **表情域**：**窄域**。默认「半醒的平静」——眼皮比常人低半度，像还没完全醒，也像不想醒。泄漏点在眼角，不在嘴。**爆发格全片只留一次**。

### 3.3 视觉层

| 项 | 设计 | 服务什么 |
|---|---|---|
| **Shape language** | 基础形 = **修长的竹**（直、长、有节）。混合编码：竹的直硬 × 围裙带在风里软软地飘（刚里一点柔 = 她「赶时间」与「不惊动露」的矛盾）。锐角只出现在袖口与篾片收口，**不上脸** | 矛盾同体可感知 |
| **头身比** | 7.5–8 头身（理想化、时尚感，贴合都市女性审美）；肩略窄、四肢纤长，不用 9 头身的压迫感 | 受众审美 |
| **主色** | 雨过天青 / 蟹壳青的**低饱和青灰**（晨雾色）——全片最大面积 | 「清冷」基调 |
| **辅色** | 未漂苎麻白 / 米白，带织物纹理 | 温度与手工感 |
| **签名色** | **茶汤的金珀色 + 指尖的那点光**——全片唯一的暖 | 冷调里唯一的情绪出口 = 她的泄漏点 |
| **服装** | 交领右衽短袄（扣到第二颗）+ 苎麻围裙（**有口袋，且鼓着**）+ 收口小袖 + 布鞋。是**采露人的工装，不是仙女广袖**——她是要干活的人 | 世界逻辑 + 性格泄漏 |
| **签名道具** | 修补过的旧竹篓：篾片一新一旧，侧面缝一块麻布补丁，内垫湿苔保露 | 缺口可视化 + 投入的可见代价 |

**签名锁定清单（下游每条 prompt 逐字复制）**
1. `a repaired bamboo dew basket with a stitched linen patch on its side, one fresh pale strip among darkened older ones`
2. `a low-saturation cyan-grey short cross-collar jacket over an unbleached linen apron, cuffs tied tight, a small bulging sachet in the apron pocket`
3. `the only warm accent in the whole frame: amber tea liquid and the light on her fingertips`

**配角「都市的她」——刻意做薄**：只给两个特征（圆团形轮廓、披发、端杯），其余**去特征化**。这不是偷懒，是角色设计里的「代入通道」：主角走**辨识通道**（高记忆），受者走**代入通道**（让 22–30 岁都市女性直接穿进去）。两条通道不能都要。

### 3.4 三测试自审

- **剪影**：竖长竹形 + 单肩斜绳一道 + 小袖收口 → 涂黑可认。与「她」（圆团形）剪影互斥 ✓
- **溯源**：删旧竹篓 → 丢「干了很多年且舍不得换」；删扎口袖 → 丢「不惊动露」；删口袋鼓包 → 丢「昨天没来的人」；删茶汤暖色 → 丢全片唯一情绪出口。四项全部不过关 = 全部保留 ✓
- **三距**：远读（青灰竖形 + 斜绳剪影）／中读（交领 + 围裙 + 扎口袖的姿态）／近读（半垂的眼皮、拇指抹杯沿、指尖的光）✓

## 四、世界观设定要点

**定位**：不是奇幻世界，是**被改写了的一个早晨**。invention 定在**表层级**——15 秒的尺度撑不起系统级，表层级 + 完整性足以取胜。

### 4.1 内核层

- **核心法则（invention）**：**「城市有一条隐形的时辰契约：04:00–06:00，城市归采露人。太阳出来之前，茶可以送到任何人手里；太阳一出来，契约失效，世界回到日常。」**——把「晨露茶」的产品事实（凌晨采、清晨饮）直接做成了世界规则。
- **主题立场（表意）**：**「新鲜是有代价的，而代价发生在别人睡着的时候。」**删掉所有旁白，空城 + 她一个人的脚印 + 别人手里那杯茶，这句话依然立得住。
- **情绪基调定位**：**清冷的温柔**。空间疏朗、安静、低饱和（先感到）；情感上有人接应（后理解）。

### 4.2 系统层（只做清晨两小时，按需取用）

| 基础设施 | 内容 | 勾连 |
|---|---|---|
| **时间规则** | 04:00 山雾起，露在叶背 → 04:40 首班车进城 → 05:20 空城 → 06:00 契约失效 | 直接决定分镜节拍：**全片 15 秒就是契约生效到失效的窗口** |
| **地理** | 城边一座不高的山（雾带）+ 一条穿城的河 + 一条早高峰前的空街 + 一座没名字的石桥 | 只留三个空间，15 秒够用 |
| **经济** | 采露人不卖茶，茶是「昨天约好的」 | 决定她不收钱，也决定了口袋里那包没人领的茶 |
| **文化** | 行话「趁露」；规矩「第一杯给昨天约好的人，不加价」 | 语言签名的世界来源 |
| **神话（极轻，只喂母题）** | 老人说露是「夜吐出来的一口气」，采露人要在太阳之前把这口气还给睡着的人 | 圆露母题的来源 |
| **哲学（一句）** | 「东西要赶在太阳前头。」 | **一元供给**：同时是世界规则、角色信念、品牌承诺 |

### 4.3 视觉层

- **色彩底色**：全片低饱和青灰蓝（spatial expression：疏朗、安静、冷），唯一暖色是茶汤与指尖。
- **视觉母题（表意载体）**：① **圆形露珠**——叶背的水光、杯口的月白水汽、路灯下的湿痕，反复出现；② **一道斜线**——竹篓绳从左肩到右腰，是她的空间签名；③ **未干的水迹**——契约的时间证据。
- **地标**：一盏路灯 + 一座无名的石桥。空城里唯一亮着的东西 = 世界的记忆点。
- **器物**：厚壁粗陶杯（杯沿一道手绘青线）、旧竹篓、苎麻围裙。
- **叙事地层（一物多轴）**：湿痕脚印 = 生活痕迹（可信）+ 她来过（情绪）；石桥上未干的水迹 = 契约证据（表意）；路灯下那包没人领的茶 = 亏欠（在乎）；日出一瞬的暖 = 契约失效（结构节拍）。
