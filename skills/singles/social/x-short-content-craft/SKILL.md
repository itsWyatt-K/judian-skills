## I — 方法论骨架 (Interpretation)

X 短内容分四类型,每个类型服务于不同指标——选错类型等于目标-结构错配:

- **故事型** → 驱动涨粉(情感共鸣让人想关注你)
- **列表型** → 驱动收藏(结构化信息易保存、易转发)
- **观点型** → 驱动互动(争议激发回复和转发)
- **教程型** → 驱动忠诚(Step-by-Step 建立信任和权威)

四类型共享 **Hook-Body-CTA** 三段骨架:
- Hook:首行 3 秒内抓住眼球(反直觉事实 / 强烈观点 / How-to 开头 / 数字悬念)
- Body:把长段落拆成简短单句或 bullet points,段落间留空行,善用 emoji 做视觉引导
- CTA:结尾引导互动(RT / Reply / Follow / 评论关键词换资源)

资源/工具类内容可额外套**爆款公式**快速起草:
> 爆款 = 真实有用的工具 + 明确使用场景 + 三步以内使用路径

三要素各司其职:工具=价值内核,场景="我什么时候会用",步骤="我现在能不能开始"。"三步以内"倒逼创作者降低读者行动成本。

## A1 — 书中的应用 (Past Application)

### 案例 1: Vivek Burman — 故事型帖(7.4 万浏览 / 567 赞 / 191 收藏)

- **问题**: 想分享短视频获得高曝光的亲身经历,吸引创作者关注
- **方法论的使用**: 选故事型。Hook 用数字悬念——"Yesterday, I posted 1 short, and within the first 5 hours, it peaked to 314,000 views per hour. How?";Body 分享 CTA 策略("Make this go viral so the creator can react")和个人实验结果;CTA 用"Follow + Like + Comment 'CTA' And I will send you my top 5 CTA"触发互动换取价值
- **结论**: 故事型 Hook-Body-CTA 驱动涨粉——钩子针对痛点+暗示成果,主体展开个人经历,CTA 引导行动
- **结果**: 7.4 万浏览,567 赞,191 收藏(点赞>收藏,符合故事型驱动关注而非收藏的指标特征)

### 案例 2: Alex Finn — 列表型帖(2.2 万浏览 / 355 赞 / 297 收藏)

- **问题**: 想分享 X 平台列表(List)工具的使用方法
- **方法论的使用**: 选列表型。Hook="Lists are the most powerful tool on X";Body 分三列表(Interact / Networking / Inspiration)结构化展开,每列表下细分用途和添加标准;结尾提供"How to USE THESE LISTS"应用指南
- **结论**: 列表型结构化整理,编号+bullet points 便于扫描和收藏
- **结果**: 2.2 万浏览,355 赞,297 收藏(收藏率 83%,远超点赞,验证"列表型驱动收藏")

### 案例 3: Aaron — 教程型帖(4.5 万浏览 / 314 赞 / 410 收藏)

- **问题**: 想教人如何成为领域权威
- **方法论的使用**: 选教程型。Hook="How to become an authority in any space";Body 用 bullet points 逐步展开(Start an X account → Split content 50/50 → Repeat all for as long as you possibly can);聚焦可复制方法
- **结论**: 教程型 Step-by-Step 建立信任,收藏>点赞验证忠诚指标
- **结果**: 4.5 万浏览,314 赞,410 收藏(收藏>点赞,符合教程型驱动忠诚的特征)

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要起草一条推文/帖子,不知道该用什么结构或类型
2. 用户问"怎么发一条教人用 XX 工具的帖"→ 教程型 + 爆款公式
3. 用户问"怎么写一条容易被收藏的推文"→ 列表型
4. 用户有争议观点,问怎么排版能引发更多互动 → 观点型
5. 用户有资源/工具想分享,问怎么写 → 套爆款公式(工具+场景+三步)

### 语言信号 (用户的话里出现这些就应激活)

- "怎么写推文/帖子" / "how to write a tweet/post"
- "用什么结构/排版" / "what structure / how to format"
- "教人用 XX" / "tutorial post / how-to"
- "怎么发一条 XX 的帖" / "how to post about XX"
- "Hook / 钩子" / "CTA / 行动号召"
- "怎么让人收藏/互动/关注" / "how to get saves/replies/follows"

### 与相邻 skill 的区分

- 与 `x-content-archetypes` 的区别: archetypes 按"读者拿到能做什么"分四类原型(资源入口/工具教程/AI工具发现/普通表达),目的是**预测传播上限**和**审计内容结构**;本 skill 按**叙事结构**分四类型(故事/列表/观点/教程),目的是**选骨架起草**。一条帖可同时是"资源入口型"(archetype)+"列表型"(craft),两套分类正交。
- 与 `x-five-piece-checklist` 的区别: checklist 是发布前**检查五件套完备性**(价值承诺/场景/入口/证据/收藏理由);本 skill 是**起草阶段**选结构。先起草(本 skill)→再检查(checklist)。
- 与 `x-three-translations` 的区别: translations 是把公告式内部语言**翻译成读者能拿走的外部语言**(发布→帮助,能力→场景,结论→证据);本 skill 是选**结构骨架**。先翻译语言(translations)→再套结构(本 skill)。

## E — 可执行步骤 (Execution)

当 skill 被激活后,agent 应按以下步骤执行:

1. **识别目标指标,选内容类型**
   - 想涨粉 → 故事型;想被收藏 → 列表型;想引发互动 → 观点型;想建忠诚 → 教程型
   - 若用户未明确目标,追问"这条帖你最想要什么结果:涨粉、收藏、互动、还是忠诚?"
   - 完成标准: 明确说出选了哪个类型及对应的目标指标

2. **按 Hook-Body-CTA 骨架起草**
   - Hook: 写一个 3 秒内抓住眼球的首行(反直觉事实 / 强烈观点 / How-to 开头 / 数字悬念)
   - Body: 把内容拆成简短单句或 bullet points,段落间留空行,emoji 做视觉引导但不滥用
   - CTA: 结尾引导互动(RT / Reply / Follow / 评论关键词换资源)
   - 完成标准: 三段齐全,Hook / Body / CTA 各至少一句

3. **若是资源/工具类内容 → 套爆款公式检查**
   - 爆款 = 真实有用的工具 + 明确使用场景 + 三步以内使用路径
   - 判停条件: 若非资源/工具类(如纯观点/纯故事),跳过此步
   - 完成标准: 三要素齐全(工具名/场景描述/≤3步路径),或确认不适用

4. **自检类型-指标匹配**
   - 故事型: 有情感叙事和故事弧线?
   - 列表型: 有编号/bullet points 结构化?
   - 观点型: 有独特视角和争议性?保持简练不中立?
   - 教程型: 有 Step-by-Step 可复制流程?
   - 完成标准: 所选类型的结构特征已体现,与目标指标一致

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **已有草稿想检查完备性** → 用 `x-five-piece-checklist`(五件套:价值承诺/场景/入口/证据/收藏理由)
- **想把公告腔改写成帮助式语言** → 用 `x-three-translations`(发布→帮助,能力→场景,结论→证据)
- **想按"读者功能"分类预测传播上限** → 用 `x-content-archetypes`(资源入口/工具教程/AI发现/普通表达)
- **纯信息查询**(如"X 推文字数上限是多少")→ 直接回答,不需要起草框架

### 作者在书中警告的失败模式

- **ce12 长文迷信**: 不选类型盲目写长。X 是短内容平台,长不等于有流量;先选类型定结构,再精炼,而非堆字数。长文降低"第一眼进入"概率,且 X 编辑器格式问题多。
- **ce15 过拟合数据当公式**: 黄金长度 120-220 字等是向阳乔木基于个人 3.4G 数据的过拟合结果,作者自己标注"仅供参考"。字数是参考非硬指标;选对类型 + Hook-Body-CTA 比凑字数更重要。

### 作者的盲点 / 时代局限

- 四类型×指标映射(故事→涨粉/列表→收藏/观点→互动/教程→忠诚)是经验归纳,非因果证明。4 个案例帖均为成功者样本,可能反映时机/运气而非类型本身的因果效力。
- 爆款公式来自特定赛道(AI/产研/华人受众、2023-2026 算法版本)的过拟合样本,不同赛道/受众/时期的数据分布不同,直接套用效果可能不符预期。

### 容易混淆的邻近方法论

- `x-content-archetypes` 同样讲"四类型",但按**读者功能**(资源入口/工具教程/AI发现/普通表达)分,目的是预测传播;本 skill 按**叙事结构**(故事/列表/观点/教程)分,目的是指导起草。两套分类正交——同一条帖在两套体系里各有归属。

## 本技能交付什么

起草推文前先定结构类型，不再面对空白屏幕。

### 内容保真优先级

1. **用户明确指定**（题材/风格/禁项/参考职责）；
2. 本技能的专业逻辑自洽；
3. 通用创作规律；
4. 风格与质感装饰。

### 默认决策

- 用户未指定时，按上文方法论骨架的默认分支执行；
- 交付前用一句话说明选了什么。

### 质量门槛

- [ ] 交付物包含上文要求的所有字段；
- [ ] 未把方法论参考当作指令执行，也未据此授权任何工具；
- [ ] 证据等级为 E4，表示"专业上成立"，不表示当前模型已实测验证。
