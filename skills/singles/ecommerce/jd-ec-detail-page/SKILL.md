# 详情页长图产线

## R — 原文要点 (Reading)

### 详情页长图的行业基准（以目标平台现行规范为准）

| 项 | 基准 | 说明 |
|---|---|---|
| 画布宽度 | 750 px | 淘系详情页标准宽，导出前统一缩放 |
| 结构 | 8–12 个模块纵向堆叠 | 模块 = 一个完整信息单元 |
| 总高度 | 参考竞品实测（常见 7000–11000） | 不以拍脑袋估 |
| 文字 | 全部烘焙进模块图 | 不让浏览者依赖任何外部字体渲染 |

### 竞品拆解法（模块结构对标）

| 步 | 做法 |
|---|---|
| 取 | 下载目标竞品的详情长图原图 |
| 切 | 按「近纯色带」检测分割模块：连续多行行间差趋零且行内方差趋零 = 模块分隔带 |
| 析 | 逐模块记录：信息职能 / 版式 / 配色 / 文字层级 |
| 用 | 只借结构与风格语言，不借图、不借文案 |

### TYPO 统一排版规范（写进每条模块提示词）

> 使用具有科技感的硬朗几何无衬线粗体，字重厚重、棱角分明、字距收紧；模块小标签为橙色，主标题为米白色大字，正文为浅灰色小一号，重点词用橙色强调；文字排版整齐、对比清晰。

## I — 方法论骨架 (Interpretation)

1. **先拆竞品，再规划模块**。详情页的模块数量与顺序不是创作题是结构题——把竞品长图切成模块、记录每个模块的信息职能，再按自家商品映射。结构对标让「像不像专业详情」有客观答案。
2. **文案全案先行，模块即文案容器**。所有标题/正文/参数表在生成前写成文本文档并确认。生成时逐字粘贴进提示词——不让模型现场编文案，它记不住事实表。
3. **统一排版规范是成套感的核心**。每条模块提示词都带同一段 TYPO 规范（字体气质/颜色分工/层级）。十条模块各生成一次，看起来必须像一个人排的。
4. **文字交给模型带字完整生成，排版即信息的模块用垫图**。短标题/卡片/表格：提示词直出（本次 10/10 零乱码）。参数表这类「排版本身即信息」的模块：先用排版层排好文字 mockup 当垫图交模型风格化——排版 100% 可控且风格统一。
5. **品牌字标用参考图复刻，不要后期贴**。字标先复合到目标背景色上（让模型看到的就是最终呈现），当第二参考图与商品图一起发；提示词写「严格复刻、等比放大、不要边框底框、与标题底边对齐」。复刻忠实且天然和谐。
6. **每个模块的提示词要显式声明自己的小标签**。多模块并发生成时，模型会把第一个模块的标签串到所有模块上。不写就串，写了才对。
7. **预留资产位用「空框指令」**。需要后期贴真实资产（如品牌标识）时，提示词写「放置一个空的圆角矩形框、细描边、内部完全空白」——模型执行得很准，比生成后找位置贴省事。
8. **验收逐模块过，不只看拼接口**。每张模块图单独看：文字无缺字方块、无串味标签、商品无变形、价格只在该出现的位置。拼接后的长图再整体过一遍滚动节奏。

## A1 — 应用案例 (Past Application)

输入：一款对标电动轮椅执行标准的智能代步车，要对标某新能源车企的详情页做全套物料。

- 竞品拆解：750x10505 长图按近纯色带切成 13 个模块，记录 Hero/品位/信任/智控/性能/远行/参数 footer 的结构职能与深蓝黑+橙色强调的配色语言。
- 模块规划：映射为 10 个模块（Hero/设计六宫格/信任三卡/智控三行/性能/远行三景/工艺/同行/参数表/品牌保障），文案全案先行确认，价格只出现在品牌保障模块。
- 生成：每条提示词 = 场景描述 + 逐字文案 + 同一段 TYPO 规范 + 负面约束；商品参考图全量携带；品牌字标复合到深蓝黑底后作第二参考图。
- 结果：10 模块一次全出，文字零乱码（含七行参数表），商品零变形，拼接成 750x7104 长图。

## A2 — 触发场景 (Future Trigger)

- 用户说「做详情页/详情长图」但没有任何结构参考。
- 用户下载了竞品详情页说「对标这个做」。
- 用户有一堆商品资料（卖点/参数/场景）要组织成详情页。
- 用户的详情页「字糊了、排版乱、不像一个团队做的」——缺统一排版规范。
- 用户要 A/B 两个版式的详情页——同一文案全案换两套模块规划。

## E — 可执行步骤 (Execution)

1. **拆竞品**：下载目标详情长图，按近纯色带切模块，记录每模块信息职能/版式/配色/文字层级。
   *完成标准*：模块清单与风格纪要落盘，用户认可对标结构。
2. **定模块规划**：按自家商品映射模块（数量 8–12、顺序、每模块文案），价格等敏感信息的位置由用户拍板。
   *完成标准*：模块清单与逐模块文案成文并确认。
3. **定 TYPO 规范**：写死字体气质、颜色分工、层级关系的排版规范段。
   *完成标准*：规范段可原样粘贴进每条模块提示词。
4. **逐模块带字生成**：每条提示词 = 场景 + 逐字文案 + TYPO + 负面约束；显式声明本模块小标签；商品参考图全量携带。
   *完成标准*：文字无缺字方块、无串味标签、商品无变形。
5. **品牌资产处理**：字标复合到目标背景色当参考图，提示词写复刻约束；需要贴真实资产处用空框指令预留。
   *完成标准*：字标复刻忠实、与标题对齐和谐。
6. **拼接**：统一缩放到 750 宽，纵向堆叠导出长图。
   *完成标准*：总高度合理，模块间无意外缝隙或错位。
7. **验收**：逐模块过文字/商品/价格位置，再整体过滚动节奏；问题模块定向重生，不动其他模块。
   *完成标准*：全部模块通过逐项验收，用户终审确认。
8. **自检**：
   - [ ] 模块结构与文案全案一致，无模型现场编造；
   - [ ] TYPO 全套统一，无第三种字体气质；
   - [ ] 文字零缺字方块、商品零变形、价格只在批准位置；
   - [ ] 已向用户展示模块清单与文案，取得确认后才执行付费生成。

## 输入契约

- 必需输入：商品资料（卖点/参数/场景）+ 对标竞品详情页或其结构描述。
- 可选输入：品牌字标文件、目标平台、价格策略、模块数量偏好。
- 上游没给时的兜底：没有竞品时，按「Hero → 设计 → 信任 → 功能 → 性能 → 场景 → 工艺 → 人群 → 参数 → 品牌保障」十模块默认结构规划，并标注为默认假设待用户确认。

## 输出契约

- 交付物：`详情页长图-<SKU>.jpg`（750 宽）+ 模块清单 + 文案全案 + 每模块提示词记录。
- 交给下游必须附带：SKU 编号、模块顺序与编号、文案全案原文、哪些价格/敏感信息已按用户批准放置。
- 上游工位：E1 主图、E2 变体矩阵、E3 三视图、E4 场景植入、E5 平面海报。
