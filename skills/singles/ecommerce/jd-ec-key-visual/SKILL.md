# 平面海报排版

## R — 原文要点 (Reading)

### 平台尺寸表（以目标平台现行规范为准）

| 用途 | 常见画幅 | 备注 |
|---|---|---|
| 信息流方图 | 1:1 | 通用 |
| 竖版故事/短视频封面 | 9:16 | 注意上下安全区 |
| 横版横幅 | 16:9 或更宽 | 首页/详情头图 |
| 详情页长图 | 长条比例 | 分段导出，勿一次出超长图 |

### 排版骨架（直接填空）

```
<画幅>，<主商品位于何处、占多大>，<辅助图 N 张如何排>，
文案位：<标题位置><副标题位置><价格位><行动位>，
<行业视觉语言>，<背景与底色的关系>，文字区留白充足不被商品压住
```

### 文字工艺决策树（实测版）

| 文字类型 | 方案 | 理由 |
|---|---|---|
| 十个字以内短标题 | 写进提示词让模型直出 | 融入场景有设计感，规避字体坑 |
| 长文案/参数表 | 生成后用排版层压字 | 模型直出长文有乱码风险 |
| 排版即信息的模块 | 先排文字 mockup 当垫图交模型风格化 | 排版 100% 可控且风格统一 |

## I — 方法论骨架 (Interpretation)

1. **平面感任务要选擅长排版的模型**。同样的输入，擅长排版的模型在文字位、留白、对齐上明显更稳；擅长光影的模型在这里常常把字糊掉。选错模型，返工两次抵掉全部收益。
2. **文案位要预留，不要生成后加字**。让模型在图里留出空白区，再在排版阶段压字。生成后再抠字位，位置永远差一点。
3. **行业视觉语言不同，不要一套模板打天下**。美妆走肤感与柔光，硬件走结构与参数，服饰走版型与穿搭。同一套排版逻辑套不同品类，一眼假。
4. **文字区留白优先于画面饱满**。海报最常见的失败是商品和字抢同一块区域。宁可画面松一点。
5. **多图合并时 SKU 必须一致**。同一张海报里的多张商品图必须同 SKU、同造型、同不可变短语，否则观众会以为在卖两个东西。
6. **先出骨架再出图**。先定「主商品在哪、文案在哪、辅助图怎么排」，再生成。跳过骨架直接生成，出来的图只能重做。
7. **渲染前自检，不要生成后补救**。平台规则、文案留白、SKU 一致性在生成前查，生成后改一项等于重出一张。
8. **压字之前先实测压位**。文字压没压到商品，用暗像素行扫描实测产品在底图中的压位再定坐标。目测判断压位关系至少错三次起步；压字元素压在产品或倒影上是最高频返工原因。
9. **压字字体只用标点完备的无衬线系**。汉字专用衬线重字体的标点全部渲染成缺字方框（逗号、间隔号、顿号无一幸免）；展示级短标题优先模型直出，绕开字体坑。

## A1 — 应用案例 (Past Application)

输入：一款智能电动轮椅代步车的主图、副图与两张场景图，要做一套信息流物料。

- 骨架决策：卖点卡版 1:1——标题居上、产品居中、四张卖点卡居下；卡片带图标位、编号位、标题位、正文位。
- 模型选择：平面感任务选排版稳定的模型；卡片图标用排版层绘制（盾牌/旋转/遮阳棚/扶手），不劳模型。
- 执行：底图生成时按「产品占上中部、下 28% 干净留白」定向构图；压字前实测产品压位（暗像素行扫描）再定卡片坐标；标题短句直出，正文压字。
- 关键决策：第一版卡片压在产品车轮上——实测压位后整体下移解决；价格元素经用户确认后才保留在指定物料上。

## A2 — 触发场景 (Future Trigger)

- 用户要出海报、详情图、社媒图、宣传图。
- 用户说生成的图「字糊了、字压到商品上」——文案位未预留或压位未实测。
- 用户要把多张商品图拼成一张。
- 用户要在多个平台发同一组物料，需要尺寸适配。
- 用户要做 A/B 版本测试不同排版。
- 用户说图上「出现了方框/乱码符号」——压字字体踩了标点坑，换无衬线系或改直出。

## E — 可执行步骤 (Execution)

1. **定用途与画幅**：按平台现行规范定画幅与安全区。
   *完成标准*：画幅与安全区写入《产线事实表》。
2. **选模型**：平面感任务选擅长排版的模型。
   *完成标准*：模型选择理由已记录。
3. **定排版骨架**：主商品位置与占比、辅助图排法、文案位清单（标题/副标/价格/行动位逐一点名）。
   *完成标准*：骨架含全部文案位且不与商品重叠。
4. **定向构图底图**：提示词写清产品压位与留白区（如「产品占上中部、下 28% 干净留白」）。
   *完成标准*：底图留白区与骨架规划一致。
5. **实测压位**：暗像素行扫描产品压位，定文字与卡片坐标。
   *完成标准*：所有压字元素坐标有实测依据，无一压在商品上。
6. **文字工艺**：短标题直出，长文案压字（只用无衬线系），排版即信息模块走垫图。
   *完成标准*：文字清晰无缺字方块，SKU 一致。
7. **生成与导出**：按骨架出图，文字区留白，按平台尺寸导出。
   *完成标准*：文案不在安全区外、无遮挡。
8. **自检**：
   - [ ] 骨架先于生成确定，文案位逐一点名；
   - [ ] 压字压位经实测，无文字压商品；
   - [ ] 多图同 SKU，文字无缺字方块；
   - [ ] 平台尺寸与安全区合规；
   - [ ] 已向用户展示本批内容与参数，取得确认后才执行付费生成。

## 输入契约

- 必需输入：一组商品图（同一 SKU），以及目标用途与平台。
- 可选输入：文案、品牌色、排版骨架、已有海报模板、是否带价格。
- 上游没给时的兜底：没有文案时先做纯图版并预留文案位，标注文案待用户提供；没有平台信息时按 1:1 通用方图出，并标注需按平台现行规范复核。

## 输出契约

- 交付物：`海报-<SKU>-<平台>.md`（骨架 + 模型选择理由 + SKU 一致性核对 + 提示词 + 压位实测记录）+ 成图文件。
- 交给下游必须附带：SKU 编号、画幅与安全区、文案位清单、待用户确认项。
- 上游工位：E1 主图、E2 变体矩阵、E3 三视图、E4 场景植入。
