# 产品三视图

## R — 原文要点 (Reading)

### 两档出图方案

| 档 | 做法 | 成本 | 风险 |
|---|---|---|---|
| 保守 | 每个视角单独一张图，共用不可变短语 | 高（张数多） | 低 |
| 激进 | 16:9 一次出多视角复合版面，再切分 | 低 | 中：可能串形、糊边、诱发脏字 |

### 视角清单（按商品类型裁剪）

| 编号 | 视角 | 用途 |
|---|---|---|
| V1 | 正面 | 识别主视角 |
| V2 | 侧面 | 轮廓与厚度 |
| V3 | 背面 | 结构与收口 |
| V4 | 俯视 | 顶面与开口 |
| V5 | 底部/内侧 | 细节与工艺 |

### 批量切分参数

| 项 | 值 |
|---|---|
| 画幅 | 16:9 |
| 切分格数 | 4x4（十六宫格） |
| 省下的东西 | 次数与等待：一次生成替代十六次逐张 |

## I — 方法论骨架 (Interpretation)

1. **一次多视角比逐个凑省，但必须先评估串形风险**。多视角同图在部分模型上会把不同角度的结构糊在一起。轮廓简单、对称性强的商品适合激进档；有手持部件、镂空、印刷图案的商品走保守档。
2. **切分是批量工具，不是万能工具**。十六宫格省次数，但每格构图不可控，通常用于「先看哪些角度可用」的粗筛，不用于终稿。
3. **多机位九宫是粗筛的升级版**。让模型自己找九个角度，再切分出来，适合快速凑齐展示视角；终稿仍需从可用帧里挑。
4. **细节增强用参考式，不用放大式**。让模型「参考图2的结构，提高图1中产品的细节」，比单纯放大更稳，因为它有结构可依。
5. **模型按任务挑**。三视图这类偏结构、偏版面的任务，优先选擅长排版的模型；光影氛围重的选擅长光的模型。选错模型，返工两次就抵掉省下的次数。
6. **三视图是后续所有工位的地基**。场景植入、平面海报、产品视频都以三视图或视角图为输入；这里缺一个角度，下游就要回头补。

## A1 — 应用案例 (Past Application)

输入：一款带提手与翻盖的保温杯干净商品图。

- 决策：走保守档。理由：提手与翻盖是两个活动部件，复合版面极易把开合状态糊成同一状态。
- 执行：按 V1-V5 逐张出图，全部共用不可变短语（杯型轮廓、提手展开状态、翻盖闭合状态、logo 位置与大小）；杯身印刷图案单独锁一条描述。
- 粗筛：另跑一次十六宫格，只为快速看哪些角度视觉上最可用，挑出两帧补进视角集。
- 关键决策：粗筛帧只作参考，不直接进终稿；终稿一律来自保守档单图。

## A2 — 触发场景 (Future Trigger)

- 用户要做三视图、多角度展示图。
- 用户说「角度图糊了、两个角度长得一样」——串形，需降级到保守档。
- 用户要快速看一个商品有哪些可用角度——十六宫格粗筛。
- 商品有活动部件、镂空、印刷图案——默认保守档。
- 下游工位（场景植入、海报、产品视频）报缺角度。

## E — 可执行步骤 (Execution)

1. **判档**：按商品结构复杂度选保守档或激进档。
   *完成标准*：档位与理由已记录。
2. **裁剪视角清单**：按商品类型定要哪几个视角，去掉用不到的。
   *完成标准*：视角清单无冗余项。
3. **出图**：按档出图，全部共用不可变短语。
   *完成标准*：每张图的不可变短语逐字一致。
4. **粗筛补位**：跑一次十六宫格或九宫，挑可用帧补缺角。
   *完成标准*：粗筛帧仅作参考，未混入终稿。
5. **细节增强**：对关键视角做参考式细节增强。
   *完成标准*：增强前后结构一致，仅细节提升。
6. **归档编号**：视角编号与出图编号回填。
   *完成标准*：每个视角有唯一出图编号。
7. **自检**：
   - [ ] 档位选择有理由；
   - [ ] 不可变短语逐字一致；
   - [ ] 各角度结构可辨，无两图串形；
   - [ ] 终稿与粗筛帧已分开标注；
   - [ ] 已向用户展示本批数量与参数，取得确认后才执行付费生成。

## 输入契约

- 必需输入：一个 SKU 的干净商品图（E1 产出）。
- 可选输入：视角清单、不可变短语、画幅、切分格数、模型偏好。
- 上游没给时的兜底：没有干净商品图时先跑 E1；没有视角清单时按 V1-V3 正面/侧面/背面出最小三件套，并标注为默认裁切。

## 输出契约

- 交付物：`三视图-<SKU>.md`（档位声明 + 视角清单 + 不可变短语 + 每视角提示词）+ 各视角出图文件。
- 交给下游必须附带：SKU 编号、视角编号与出图编号对照、不可变短语原文、哪些帧是粗筛参考。
- 下游工位：E4 场景植入、E5 平面海报、E6 产品视频。
