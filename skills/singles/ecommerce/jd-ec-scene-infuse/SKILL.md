# 场景植入与氛围

## R — 原文要点 (Reading)

### 场景植入三档控制

| 档 | 做法 | 随机性 | 适用 |
|---|---|---|---|
| 直描 | 用文字描述目标场景 | 高 | 快速试方向 |
| 定图 | 先生成一张确定的场景图，再把商品放进去 | 低 | 推荐作默认 |
| 换影 | 只换光影氛围，场景不动 | 极低 | 场景对、氛围不对时 |

### 场景一致性命中项

| 项 | 判据 |
|---|---|
| 商品形状 | 与不可变短语逐条一致 |
| 透视 | 商品与场景的视角、地平线一致 |
| 接触影 | 商品与接触面有合理投影 |
| 光向 | 场景主光方向与商品受光方向一致 |
| 场景无文字 | 场景图与成品中均无任何文字、logo 或品牌标识 |

## I — 方法论骨架 (Interpretation)

1. **先定场景图，再放商品**。直接描述场景，模型给的方向每次都不一样，改十次也定不下来。先生成一张确定的场景图，再让商品进入，方向一旦认可就不会跑。
2. **一次只换一层参数**。场景与影调是可分别替换的两层。同时改，两层会互相打架；改场景时别顺手改光。
3. **氛围是氛围图，不是形容词**。「高级感」「ins风」在模型那里不可执行。找一张氛围参考图，让模型按它的影调走，比写二十个形容词都准。
4. **接触影是真实感的开关**。商品悬在场景里没有投影，一眼假。投影方向、软硬、浓度必须和场景主光一致。
5. **商品防变形优先于氛围**。场景再好看，杯子口变成椭圆就是废图。不可变短语逐字复用，场景植入指令里要显式写「保持商品造型、比例、logo 不变」。
6. **场景为商品服务，不为炫技**。场景信息密度不能高于商品。观众三秒内必须看到商品，否则这张图只是风景。
7. **源图的品牌元素会迁移进场景**。商品原图背景里的品牌字样，会被模型当成环境常识画进场景里。植入提示词必须显式写「场景中不得出现任何文字、logo 或品牌标识」——不可变短语只锁商品，锁不住环境。
8. **商品的结构性部件要写成可验证的几何描述**。「遮阳棚」三个字不够，模型两次画歪；写成「水平顶棚 + 座椅后两根弧形支架杆 + 前缘细饰条 + 无额外凸起」后一次通过。凡是商品上有造型风险的结构（棚/杆/弧/把手），都拆成几何件描述。

## A1 — 应用案例 (Past Application)

输入：一款智能电动轮椅代步车的白底主图，要做一张家庭客厅场景图与一张湖畔夕阳场景图。

- 决策：选「定图」档。理由：场景构图与色温需要可控，直描每次给的都不一样。
- 执行：① 先生成确定的客厅场景图（米白沙发、落地窗侧逆光、低信息密度）并冻结；② 双参考图植入——场景图 + 商品图一起给模型，指令含「保持商品造型比例 logo 不变、投影与侧逆光一致、透视一致、场景中不得出现任何文字 logo」；③ 湖畔夕阳场景图（长者坐姿背影）中，遮阳棚连续两次被画歪，第三次把遮阳棚拆成几何件描述后一次通过。
- 关键决策：场景图先行冻结；结构部件几何化描述；品牌字样禁入写进每条植入提示词。

## A2 — 触发场景 (Future Trigger)

- 用户要把净底商品图放进使用场景。
- 用户说场景图「氛围不对、不够高级」——改用氛围参考图换影调。
- 用户说商品放进场景后「变形了、悬浮了」——补接触影与防变形约束。
- 用户说场景里「出现了奇怪的字/logo」——补场景文字禁入约束。
- 用户说商品某个部件「画歪了、结构不对」——把该部件拆成几何件描述。
- 用户要一组同场景不同商品的图，保证场景一致。

## E — 可执行步骤 (Execution)

1. **选档**：按随机性需求选定图 / 换影 / 直描，写一句理由。
   *完成标准*：档位已声明。
2. **定场景图**（定图档）：先生成并认可一张场景图。
   *完成标准*：场景图已冻结，不再随商品改动。
3. **拆结构描述**：把商品有造型风险的结构部件拆成几何件描述，与不可变短语合并。
   *完成标准*：提示词中每个风险部件都有几何级描述。
4. **放商品**：双参考图（场景 + 商品），写清保持什么、换什么、光怎么来，并显式写「场景中不得出现任何文字、logo 或品牌标识」。
   *完成标准*：指令同时含「保持商品造型比例 logo 不变」「场景无文字」与受光要求。
5. **补接触影**：检查并指定投影方向、软硬、浓度。
   *完成标准*：商品与接触面之间有合理投影。
6. **换影调**（换影档）：取氛围参考图，只换影调不动场景。
   *完成标准*：本轮未同时改场景。
7. **归档编号**：场景图编号与成品编号回填。
   *完成标准*：每个成品有唯一编号与来源场景图编号。
8. **自检**：
   - [ ] 不可变短语逐字复用，风险部件已几何化；
   - [ ] 透视、接触影、光向、场景无文字四项一致；
   - [ ] 商品在三秒内可被识别；
   - [ ] 本轮只换一层参数；
   - [ ] 已向用户展示本批内容与参数，取得确认后才执行付费生成。

## 输入契约

- 必需输入：一个 SKU 的净底商品图或三视图，以及目标场景方向。
- 可选输入：氛围参考图、不可变短语、场景图编号、画幅。
- 上游没给时的兜底：没有场景方向时，按商品品类给一个最通用场景（桌面 + 侧光 + 简洁背景）并标注为默认假设；没有氛围参考图时用直描档并标注随机性高。

## 输出契约

- 交付物：`场景图-<SKU>.md`（档位声明 + 场景图编号 + 不可变短语 + 提示词 + 一致性命中项核对结果）。
- 交给下游必须附带：SKU 编号、场景图编号、不可变短语原文、命中项核对结果。
- 下游工位：E5 平面海报、E6 产品视频。

## 本技能交付什么

把净底商品放进有代入感的使用场景：场景植入三档控制、氛围参考图指定影调、场景一致性五项检查（含场景无文字）、商品防变形约束与结构几何化描述。
