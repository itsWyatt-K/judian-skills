# 影视提示词编译

## R — 原文要点 (Reading)

### 图片四要素核对表（每个格子都要回答「写什么、或为什么跳过」）

| 要素 | 写什么 | 什么时候可以跳过 |
|---|---|---|
| 时间 | 清晨/正午/黄昏/深夜/雨夜——顺手换来一整套光 | 棚内人工光可控时；纯底色产品图时 |
| 主体 | 画面主角，人/动物/物品均可；是观众视线该停的地方 | 纯风景（雪山、沙漠、空镜）可能没有主体 |
| 场景 | 一个场景词等于白送一批信息（写厨房自动补厨师、写古寺自动补僧侣） | 纯白底/纯色底时；logo、图标、二维动画类要素更少 |
| 风格 | 参考片、影调、介质——直接决定质感上限 | 几乎不可跳过，但可短 |

### 视频八字组词模板

```
<主体><在做什么/什么状态>，<镜头怎么动>，<稳定还是手持>，<焦深与光>，
<第 N 秒切到<谁的什么部位><在做什么>，第 M 秒切回<什么景别><什么状态>>，
<不要自动配乐>
```

### 内嵌切镜头示例（一次生成出一组分镜）

> 红色机器人一动不动，手持镜头、步伐轻微起伏，缓慢推进。第 2 秒切到机器人脸部特写，眼眶灯缓慢变暗。第 5 秒切回全景，镜头缓慢拉远，废墟逐渐入画。不要自动配乐。

## I — 方法论骨架 (Interpretation)

1. **场景是隐性信息载体**。写「现代都市」而不写「孤独」，模型会自动补出人与环境的隔阂；写「古寺」会自动补香火与僧侣。用场景词换免费信息，比堆形容词便宜。
2. **时间是拿光影最便宜的办法**。不会写专业光影名词时，写清晨/黄昏即可换来一整套光的方案；会写时再直接写光位。
3. **四要素是查漏补缺的核对表，不是必填模板**。每格都要主动判断「要不要写」。该跳过的不写，写满反而互相打架。
4. **短提示词 = 烧钱**。过于简短模糊，模型只能猜，同一句会出插画版、游戏版、写实版；重抽次数上去等于直接烧预算。写详细不是洁癖，是成本控制。
5. **让 AI 反推与扩写可以，但不能让它替你做决定**。把已锁定的具体设定（老人、白袍、某颗痣）交给 AI 自由发挥，会被改掉。正确顺序：你先定外观短语与四要素，AI 只补措辞。
6. **运镜有情绪功能，不是装饰**。推（靠近，主体放大）适合进入内心；拉（远离，主体变小）适合孤独与揭示环境；摇（原地转）适合给出新信息、制造惊喜；移（平行平移）让背景横向划过，观众像在走路。
7. **稳定性也是效果**。固定镜头 = 三脚架、克制、观察感；手持 = 呼吸感、临场感、第一视角。不稳定可以叠加运镜（手持 + 缓慢推进 = 我正走向它）。
8. **关掉自动配乐**。每段各自配乐再拼起来会各想各的、非常混乱；音乐必须成片后统一配。
9. **文生视频提示词 = 图片提示词 + 视频提示词直接拼接**。跳过先生成图再动图这一步，代价是主体失控风险更高。
10. **平台差异不写死**。不同平台对同一意图的写法、参数名、是否支持负向词、单段时长上限都不同，全部按《产线事实表》现填现用，不要相信任何写死的参数。

## A1 — 应用案例 (Past Application)

输入：「一个雨夜，穿旧夹克的男人站在便利店门口犹豫要不要进去」。

- 四要素判定：时间 = 雨夜深夜（写）；主体 = 男人（写）；场景 = 便利店门口（写，会自动补暖光与雨棚积水）；风格 = 参考写实都市剧照（写）。
- 图片提示词产出：雨夜深夜，一名穿洗旧深棕夹克的男人站在便利店门口，橱窗暖光打亮他半张脸、地面有积水反光，写实都市剧照质感，胶片颗粒，浅景深。
- 视频提示词产出：男人一动不动站着，右手插在夹克口袋又抽出，手持镜头轻微晃动，缓慢推进。第 3 秒切到男人眼睛特写，瞳孔里映着橱窗灯光。不要自动配乐。
- 关键决策：判定「雨夜深夜」同时承担时间与场景，因此不再单独写光位描述。

## A2 — 触发场景 (Future Trigger)

- 用户给了分镜表某一镜，要生成用的提示词。
- 用户说「我写的提示词生成出来总是不像」——需要回到四要素与外观短语检查。
- 用户想让 AI 自己切镜头、省下分段生成与剪辑的钱。
- 用户要把同一条意图在多个平台跑，需要按各平台改写。
- 用户抱怨生成结果「一会儿插画一会儿写实」——风格段缺失或太短。

## E — 可执行步骤 (Execution)

1. **读入意图与资产**：从分镜表取该镜的字段，从资产板取外观短语。
   *完成标准*：外观短语已原样待命，未被改写。
2. **填《产线事实表》**：目标平台、单段时长上限、是否支持参考引用、是否支持负向词、画幅选项。
   *完成标准*：表内字段已由用户确认或已标注为待确认。
3. **图片四要素核对**：逐格判定写或跳过，并写一句理由。
   *完成标准*：四格各有「写什么」或「为什么跳过」。
4. **组视频八字**：主体/动作/效果/节奏四段各到位；效果段含运镜与稳定性。
   *完成标准*：每个运镜有一句「什么变了」。
5. **按平台改写**：按事实表把通用短句改写成目标平台写法；没有把握的字段留白并标注待核。
   *完成标准*：未编造任何平台参数。
6. **配乐纪律确认**：文末显式写「不要自动配乐」。
   *完成标准*：配乐句在位。
7. **自检**：
   - [ ] 外观短语逐字未改；
   - [ ] 四要素均经判定而非默认全写；
   - [ ] 切镜头时间点精确到秒；
   - [ ] 未写死任何平台参数，全部落在事实表；
   - [ ] 已提示用户：生成前先看一遍内容与数量，确认后再执行付费生成。

## 输入契约

- 必需输入：一段文字意图（或分镜表某一行）。
- 可选输入：外观短语、画幅、时长、目标平台、参考图编号。
- 上游没给时的兜底：没有外观短语时，先按「主体 + 服装分层 + 一处辨识点」自行补一条最小短语，并标注为待确认；没有平台信息时按通用短句输出，并明确告知用户平台适配未做。

## 输出契约

- 交付物：`提示词-<镜头ID>.md`（四要素判定 + 图片提示词 + 视频提示词 + 事实表引用）。
- 交给下游必须附带：外观短语原文、事实表填了哪些字段、哪些字段待用户确认。
- 下游工位：S4 首尾帧衔接、S5 跨镜一致性、S6 成片装配。

## 本技能交付什么

把文字意图编译成可直接贴用的图片提示词与视频提示词：图片四要素核对、视频八字组词、内嵌切镜头、运镜与稳定性词汇，以及一张让用户一次性填好的产线事实表。

### 内容保真优先级

1. **用户明确指定**（题材/风格/禁项/参考职责）；
2. 本技能的专业逻辑自洽；
3. 通用创作规律；
4. 风格与质感装饰。

### 默认决策

- 用户未指定时，按上文方法论骨架的默认分支执行；
- 交付前用一句话说明选了什么。

### 质量门槛

- [ ] 交付物包含上文要求的所有字段；
