# 首尾帧与镜头衔接

## R — 原文要点 (Reading)

### 首尾帧定义卡

| 项 | 内容 |
|---|---|
| 是什么 | 你给出头一张、尾一张，中间画面由模型补全 |
| 为什么强 | 头尾越真实，中间越可控；模型的自由发挥被压在两端之间 |
| 关键约束 | 头尾必须是真实画面或已锁定的资产图，不是描述 |
| 常见失败 | 只用一张图加形容词让模型想象中间，人多细节多就失真崩坏 |

### 三种镜头衔接法选型表

| 方案 | 什么时候用 | 成本 | 需要后期砍帧 |
|---|---|---|---|
| 动接动 | 上下镜都在运动，且动作能接上 | 中：需实拍同一动作前后两段 | 需要 |
| 空镜转场 | 场景要切换但不想管动作衔接 | 低：只需两段空镜 | 不需要 |
| 循环 | 要无缝循环素材、动态壁纸、情绪包 | 低：一张图即可 | 需要（多份拼接时） |

## I — 方法论骨架 (Interpretation)

1. **真实画面比形容词可靠**。凡是必须保真的东西（人、手、持物、服装细节），想办法给它一张真图做锚点，不要试图用提示词描述住。这是整条短剧线最省钱的判断。
2. **动接动的条件是「同一个动作的前后两段」**。上镜在动、下镜也在动，还要能接上：钻进接钻出、跳起接落下、转圈开始接转圈结束。首尾帧取自同一动作的前后两个瞬间，视觉才滑。
3. **空镜转场是省力版**。让角色在第一段结尾走出画面，取此时空镜做头；第二段开机先拍一段空镜，取其中一帧做尾，然后角色再入画。不必管动作衔接，也不必砍帧——因为角色不在画面上，接缝看不出来。
4. **循环的设定是首帧等于尾帧**。中间随便怎么变，结尾必然回到开头，因此可以无限拼接。适合动态壁纸、循环背景、表情包、氛围垫层。
5. **砍重复帧是必做后处理**。模型生成的片段头尾偶尔会出现画面静止，直接拼接会在接缝处「卡两下」。必须逐段找出静止开头与结尾并剪掉。多份素材拼循环同理。
6. **时间静止（子弹时间）是作弊版无特效方案**。两个机位从正面和侧面同时抓同一瞬间，机位高度尽量一致，最好开慢动作便于挑帧；两段素材各挑一帧，且两帧的动作要相似。最后把生成的环绕片段插回两段实拍中间。
7. **简单纯运镜四秒就够**。一段环绕、一次推进，四秒已经说完；拉到十几秒只会暴露模型的匀速缺陷。
8. **模型默认匀速**。加减速的呼吸感在剪辑阶段做，不要在提示词里硬搓——那里搓不出来。

## A1 — 应用案例 (Past Application)

需求：两个场景之间要一个转场，一段在办公室，一段在深夜街头。

- 决策：选空镜转场。理由：两个场景的动作完全不同（一个坐着敲键盘，一个走路），做动接动需要补拍大量素材，不值。
- 执行：第一段结尾让角色起身离开画面，取空镜（显示器熄灭、只剩窗帘）作为头帧；第二段开机先拍一段空镜（街灯、空斑马线），取车灯扫过的一帧作为尾帧。
- 后处理：生成片段插入两段之间，检查头尾无静止帧，未做砍帧。
- 结果：转场发生在角色不在画面上，衔接无痕迹。

## A2 — 触发场景 (Future Trigger)

- 用户有两段素材要接在一起，说「接得好硬」。
- 用户要做无缝循环画面、动态壁纸、氛围背景。
- 用户想要「时间停住、镜头绕着人转」的效果，但不想上特效。
- 生成片段拼接后在接缝处出现卡顿或画面跳。
- 用户想让一段视频延长，需要先定「延长后那一帧」作为新尾帧。

## E — 可执行步骤 (Execution)

1. **读入两段素材与目标**：确认是衔接两段、还是要循环、还是要时间静止。
   *完成标准*：目标类型已明确。
2. **选衔接方案**：按选型表决定动接动 / 空镜 / 循环，并写一句选择理由。
   *完成标准*：方案与理由均已记录。
3. **取帧**：按方案取头帧与尾帧；动接动必须取自同一动作前后两段；空镜必须取自角色不在画面的画面。
   *完成标准*：头尾帧均为真实画面，且已编号。
4. **定时长与画幅**：简单运镜 4 秒起，勿默认拉长；画幅按平台现行规范。
   *完成标准*：时长与画幅写入《产线事实表》。
5. **写衔接提示词**：主体 + 动作 + 运镜 + 稳定性；不写自动配乐。
   *完成标准*：运镜有一句「什么变了」。
6. **砍重复帧检查**：逐段看头尾，找静止帧并剪掉；确认接缝无卡顿。
   *完成标准*：已给出砍帧清单（哪些秒到哪些秒被剪掉）。
7. **自检**：
   - [ ] 头尾帧是真实画面而非描述；
   - [ ] 空镜方案确认角色不在画面上；
   - [ ] 循环方案确认首帧等于尾帧；
   - [ ] 砍帧清单已列；
   - [ ] 时长未超过必要长度。

## 输入契约

- 必需输入：两段素材（或一段素材加一张目标场景图），以及目标类型。
- 可选输入：已生成片段、画幅要求、时长上限、角色资产编号。
- 上游没给时的兜底：只有一段素材时，按空镜方案处理——从该段取一帧空镜做头，自行给出一个目标场景图做尾，并在交付说明中标注场景图为待确认假设。

## 输出契约

- 交付物：`衔接方案-<编号>.md`（方案选型 + 头尾帧编号 + 衔接提示词 + 砍帧清单）。
- 交给下游必须附带：头尾帧编号、砍帧清单、时长与画幅、方案选择理由。
- 下游工位：S5 跨镜一致性（需要换背景/换光影时）、S6 成片装配（剪辑单的入出点取舍）。
