# 角色资产板

## R — 原文要点 (Reading)

角色资产板要解决的不是「画得好看」，而是**同一角色在不同镜头里必须是同一个人**。做法分两层：一层写进文件的事实（身份块），一层能原样贴进每条提示词的短语（外观短语）。

### 身份块六段（逐段填空，写不出就标「待定」）

```
IDENTITY  身份一句话：年龄感、身份、最突出的第一印象
BODY      体型与体态：身高比例、肩背、习惯姿态、走路方式
FACE      五官与辨识记点：脸型、眉眼神、一处不可复制的特征（痣/疤/旧伤）
ATTIRE    服装与配饰：分层写（内搭/外层/下装/鞋/随身物），颜色写实色不写形容词
LAYOUT    版面：画面怎么排（构图、留白、是否无文字无水印）
STYLE     风格与介质：写实/胶片/水彩、参考影调、成像基底
```

### 外观短语（整条跨镜逐字复用，一字不改）

> 「<年龄感>的<身份>，<体型体态>，<五官与辨识记点>，穿<服装分层描述>，<风格与介质>」

### 16:9 横版复合版面示意

```
+----------------------------------------------------------+
|  [ 头部特写 ]   |   正面全身   |   侧面全身   |  背面全身  |
|  （左 1/4）    |  （右 1/4）   |  （右 1/4）   | （右 1/4） |
+----------------------------------------------------------+
   纯色背景 · 无文字 · 无水印 · 全身留足，不被裁切
```

## I — 方法论骨架 (Interpretation)

1. **外观短语是唯一的「不可变部分」**。所有镜头、所有变体、所有补抽，都用同一条外观短语。改一个字就等于开一个新角色。
2. **身份块写事实，不写评价**。「忧郁」不是事实，「左眉尾一颗小痣、眼袋明显、下巴常内收」才是事实。评价型描述在模型那里会被翻译成完全不同的人。
3. **复合版面有风险，必须分级**。一张图里塞四个视角，在部分模型上会诱发水印脏字、肢体粘连、服装串形。因此必须选档：保守档 = 每个视角单独一张图，共用同一条外观短语；激进档 = 一次出复合版面，但生成后逐项核对。
4. **失败标准要提前写死**。五官、发型、服装任一处与外观短语不符即判失败。失败后回到保守档重锁，不许在原图上局部修修补补——那会把错误固化进后续所有镜头。
5. **服装分层写，不要笼统**。「一套黑衣服」在模型那里有几十种解释。分层写到能被指认：内搭什么、外层什么、袖口与下摆什么状态。
6. **成像基底锁定一个主机身**。默认一个相机型号贯穿全部素材，跨镜稳定；换机身必须说出创作理由（不同动态范围、不同肤色倾向、不同暗部表现）。为炫技堆多个机身在单集内是不成立的。
7. **资产板先行，提示词后写**。没有资产板就写镜头提示词，等于每镜都在重新掷骰子。

## A1 — 应用案例 (Past Application)

输入设定：「五十多岁的退非遗物修复师，寡言，手上功夫极稳」。

- 身份块产出（节选）：`BODY` = 中等身量微驼，手指粗大关节突出，动作时手臂不抬肩；`FACE` = 圆脸轮廓，眼袋明显，右眉尾一颗小痣，说话时不看人；`ATTIRE` = 深灰棉麻立领内搭，外罩洗旧的靛蓝粗布围裙（胸前两个大口袋，左边口袋插一支木柄笔），深色长裤，旧布鞋。
- 外观短语：「中等身量微驼的五十多岁退非遗物修复师，手指粗大关节突出，圆脸轮廓、眼袋明显、右眉尾一颗小痣，穿深灰棉麻立领内搭与洗旧的靛蓝粗布围裙（胸前两个大口袋，左边口袋插一支木柄笔），深色长裤旧布鞋，写实胶片质感」。
- 关键决策：选保守档——四张单独出图（正面/侧面/背面/头特写），共用上一条短语。理由：围裙口袋与木柄笔是强辨识点，复合版面极易把它们糊掉。

## A2 — 触发场景 (Future Trigger)

- 用户要做角色设定图、三视图、定妆照、角色档案。
- 用户反馈「同一个角色每张都长得不一样」「衣服颜色在跳」。
- 分镜表已出但缺参考图，需要补齐资产板才能进提示词编译。
- 用户要给同一角色出不同造型（年龄/季节/伤妆），需要保留身份块、只换服装分层。

## E — 可执行步骤 (Execution)

1. **读入角色设定或自行补全**：只有名字时，补出身份、身份动机、体态三层最小事实。
   *完成标准*：身份块六段均有内容，缺项标「待定」而非空着。
2. **把评价改写成事实**：逐段扫，凡形容词改为可见特征。
   *完成标准*：六段里没有「忧郁/冷酷/帅气」这类评价词。
3. **写外观短语**：六段压成一条，逐字确认。
   *完成标准*：短语内无同义反复、无空形容位。
4. **选档**：默认保守档；用户明确要求一张复合版面时选激进档并写清核对项。
   *完成标准*：档位已声明。
5. **锁定成像基底**：确定一个主机身型号，写进 STYLE 段。
   *完成标准*：STYLE 段含唯一主机身，跨镜不换。
6. **产出资产板**：编号、命名、归档，与外观短语一起入《产线事实表》。
   *完成标准*：每个资产有唯一编号与一条外观短语。
7. **自检**：
   - [ ] 外观短语可在后续所有提示词中原样粘贴；
   - [ ] 服装分层到能被指认；
   - [ ] 至少一处不可复制辨识点已写入；
   - [ ] 档位与失败标准已声明，失败路径明确。

## 输入契约

- 必需输入：角色文字设定（或分镜表中已定的角色）。
- 可选输入：参考图、目标画幅、风格倾向、同角色既有资产编号。
- 上游没给时的兜底：只有名字或一句话时，按「身份 / 体态 / 一处辨识点 / 服装分层」补出最小设定，并在交付说明中标明哪些是假设，请用户确认后再冻结。

## 输出契约

- 交付物：`资产板-<角色编号>.md`（身份块六段 + 外观短语 + 档位声明 + 失败标准）+ 生成用提示词一条。
- 交给下游必须附带：角色编号、外观短语原文、视角清单（保守档）、成型图编号（若已出图）。
- 下游工位：S3 提示词编译（每条镜头提示词必须粘贴外观短语）、S4 首尾帧衔接（真实参考图优先于形容词）、S5 跨镜一致性。

## 本技能交付什么

把一段角色设定变成可复用的资产板：身份块六段、一条跨镜逐字复用的外观短语、16:9 横版复合版面与保守/激进两档出图方案。

4. 风格与质感装饰。
