# 成片装配

## R — 原文要点 (Reading)

### 剪辑单字段（每一刀一行）

```
CUT-<编号> · <该刀的标题或内容>
- 来源：<素材编号> · <文件路径>
- 入点：<秒>
- 出点：<秒>
- 时长：<秒>
- 取舍：<为什么从这里进、为什么从这里出>
- 字幕：<本刀台词，逐字>
```

### 成片验收清单（交付前逐项打勾）

| 项 | 判据 |
|---|---|
| 台词完整 | 每一句字幕都能在剧本里逐字找到 |
| 接缝干净 | 无卡顿两下、无重复帧残留 |
| 节奏 | 撞击前有停顿，不是一路加速 |
| 响度 | 全片统一，不忽大忽小 |
| 字幕安全区 | 不被平台界面遮挡 |
| 首尾 | 第一秒有钩子，最后一帧有余波 |

## I — 方法论骨架 (Interpretation)

1. **剪辑单是成片的唯一事实来源**。每刀写清楚入点、出点、以及为什么选这里。没有取舍理由的剪辑单，改一次就全乱。
2. **字幕逐字取自剧本**。不要凭听写重打，也不要润色。错一个字，观众的信任就掉一格。
3. **音乐必须全片统一配**。每段素材各自配乐再拼起来会各想各的、非常混乱；正确做法是关掉生成时的自动配乐，成片阶段一次配好。
4. **响度统一是专业感最便宜来源**。观众说不出哪里不对，但会立刻感到「像手机拍的」。全片统一响度再导出。
5. **重复帧是接缝卡顿的元凶**。模型生成片段头尾偶发静止，拼接时会「卡两下」。剪辑前逐段清理。
6. **停顿是节奏的一部分**。撞击前留一次停顿，是让最后一刀有重量的唯一办法。没有停顿的加速只是吵闹。
7. **可回退优先**。每一步保留未混音版、未烧字幕版、原素材，任何一步不满意都能退回上一步，不要在成片上反复覆盖。

## A1 — 应用案例 (Past Application)

一条 45 秒短剧片段，八段素材。

- 剪辑单节选两刀：

```
CUT-EP001-006 · 敲门的手悬在半空
- 来源：MOTION-EP001-006 · 制作成果/video/MOTION-006.mp4
- 入点：1.20
- 出点：2.70
- 时长：1.50
- 取舍：开头 1.2 秒是镜头起幅的虚晃，从抬手那一刻进；实测动作收在 2.55，出点留到 2.70 让手完全落定
- 字幕：（无）

CUT-EP001-007 · 一行备注
- 来源：MOTION-EP001-007 · 制作成果/video/MOTION-007.mp4
- 入点：0.00
- 出点：3.00
- 时长：3.00
- 取舍：本刀是破裂位，取满 3 秒；字幕在 1.10 秒起，留一秒让画面先说话
- 字幕：请放在门口，不用打电话
```

- 关键决策：CUT-007 的字幕延后一秒出现，因为破裂位需要一秒静默才有重量。

## A2 — 触发场景 (Future Trigger)

- 用户手里有一串素材，说「帮我剪成一条」。
- 用户说成片「总感觉差点什么」——回到验收清单逐项查。
- 用户要把台词压成字幕，需要逐字对齐。
- 用户在接缝处看到画面跳——重复帧未清理。
- 用户要交付给甲方或发布，需要一份可回退的成品包。

## E — 可执行步骤 (Execution)

1. **收齐素材清单**：编号、路径、时长、对应镜头 ID。
   *完成标准*：清单与分镜表一一对应，缺素材已标注。
2. **逐段清理重复帧**：找每段头尾静止画面并记录砍掉区间。
   *完成标准*：砍帧清单完成。
3. **写剪辑单**：逐刀填来源、入点、出点、时长、取舍、字幕。
   *完成标准*：零空字段；每刀有取舍理由。
4. **配节奏**：按长—短—短—停—撞核对，撞击前有停顿。
   *完成标准*：停顿位存在。
5. **压字幕**：逐字取自剧本，检查安全区。
   *完成标准*：每句字幕可在剧本逐字检索到。
6. **统一响度并导出**：保留未混音版与未烧字幕版。
   *完成标准*：三版齐备，可回退。
7. **自检**：
   - [ ] 验收清单六项全绿；
   - [ ] 剪辑单每刀有取舍理由；
   - [ ] 未烧字幕版与未混音版已保留；
   - [ ] 交付前向用户展示成片与验收结果，未自行对外发布。

## 输入契约

- 必需输入：素材清单（编号、路径、时长）与分镜表（或剧本）。
- 可选输入：砍帧清单（来自 S4）、响度目标、字幕样式要求、平台导出规范。
- 上游没给时的兜底：只有素材没有分镜表时，先按素材顺序出一版临时镜序，并把「镜序为假设」标注在交付说明里，请用户确认后再压字幕。

## 输出契约

- 交付物：`剪辑单.md` + 成片文件 + 未混音版 + 未烧字幕版 + 验收清单结果。
- 交给下游（用户/甲方）必须附带：剪辑单、验收清单结果、哪些镜头是假设值待确认。
- 上游工位：S1 分镜表、S4 首尾帧衔接、S5 跨镜一致性。
