# 视频提示词八段结构公式

## R — 原文要点 (Reading)

来源方法（MIT，蒸馏自 seedance2-skill 中文版）：高质量视频提示词按公式组装——**[主体/人物设定] + [场景/环境] + [动作/运动描述] + [运镜语言] + [分时段描述] + [转场/特效] + [音频/音效设计] + [风格/氛围]**。超过 8-10 秒的视频推荐用分时段描述精确控场（0-3秒/3-6秒/6-10秒/10-15秒 各段写画面+运镜+动作）。风格与质感修饰词收尾：画面风格（电影级质感/胶片颗粒/浅景深、2.35:1 宽银幕 24fps、黑白水墨、动漫风、超写实等）、氛围情绪（紧张悬疑/温暖治愈/史诗恢宏等）、音频指导（BGM 情绪、音效清单、旁白音色、节拍贴合要求）。

## I — 方法论骨架 (Interpretation)

1. **顺序即优先级**：主体写最前（模型第一眼定基调），风格收尾（全局修饰）；跳段写会导致模型漏读关键信息。
2. **音频段不可省**：音效设计大幅提升成片质感——BGM 情绪、具体音效（脚步/人群/机械声）、旁白音色三选written全；「重视觉轻音频」是最常见短板。
3. **分时段是控场器**：长视频不分段=模型自由发挥中段；每段「画面+运镜+动作」三要素齐写。
4. **修饰词做减法**：风格词堆叠会互相冲突（写实 vs 动漫），一次任务选一个主风格族。

## A1 — 应用案例 (Past Application)

- 产品广告 15s 模板：0-3s 产品旋转入场特写 logo → 4-8s 多角度转场展示 → 9-12s 使用场景实拍 → 13-15s 定格+广告语+BGM 推高潮——八段俱全且时段清晰。
- 仙侠战斗 15s 模板：金红暖色调 + 分三段战斗推进 + 结尾定格牌坊剪影 + 音效从剑鸣收束为风声。

## A2 — 触发场景 (Future Trigger)

- 用户描述了画面想法，需要落成完整提示词。
- 已有提示词效果散乱，需要结构化重写。
- 影策 Agent 的提示词编译输出做结构校验。

## E — 可执行步骤 (Execution)

1. **八段清点**：对照公式逐段检查——主体/场景/动作/运镜/时段/转场/音频/风格，缺段先补。
   *完成标准*：八段齐全（短视频时段段可并入动作段并注明）。
2. **主体前置**：主体设定位于提示词开头。
   *完成标准*：第一句即主体。
3. **时长匹配分段**：估时长，>8s 拆分时段，每段含画面+运镜+动作。
   *完成标准*：分段数与时长匹配，段段三要素。
4. **音频补全**：写全 BGM 情绪/音效清单/旁白安排至少两类。
   *完成标准*：音频段非空。
5. **风格去冲突**：风格词同族收敛（写实族或动画族二选一为主线）。
   *完成标准*：无互相冲突的风格词并存。
