## I — 方法论骨架 (Interpretation)

很多社会现象（产品、谣言、犯罪率、健康行为）看似雷打不动，其实存在一个"引爆点"——从缓慢积累转为指数爆发的微小关键转折点，而且它**可被人为定位与操作**。

引爆靠三根杠杆同时作用，缺一不可、但任一单独放大都不够：
1. **个别人物法则**：传播由极少数特殊人格（联络员/内行/推销员）发起，而非大众。
2. **附着力因素法则**：信息本身是否"粘人"决定它能否被记住并行动，这是可重新设计的工程问题。
3. **环境威力法则**：人的行为被环境的微小信号支配，整治小失序、控制群体规模能放大或抑制流行。

应对任何"想让它火/想让它停"的问题，先别全面撒网，而是诊断这三根杠杆，把有限资源集中打到真正的引爆点——这是一种合法且高效的"取巧之计"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 乔治娅·萨德勒的乳腺癌健康传播
- **问题**: 护士萨德勒在黑人教堂办研讨会，只能留住 20/200 人，信息传不出小圈子。
- **方法论的使用**: 她同时动了三根杠杆——换环境（从教堂转到女性必待 2–8 小时的美容院）、换信使（培训发型师当联络员+推销员+内行）、改附着力（大字报、讲故事而非课堂式宣讲）。
- **结论**: 小改动能撬动大收获。
- **结果**: 低成本显著提升少数族裔女性的乳房 X 光与糖尿病筛查接受率。

### 案例 2: 后记中的"引爆点特许金"
- **问题**: 慈善家想用《引爆点》思路激发公共图书馆创新，但每笔钱很少。
- **方法论的使用**: 每笔≤1000 美元，只投"用到刀刃上"的微小杠杆（挂路标、教老年联络员上网）。
- **结论**: 集中有限资源打到关键处。
- **结果**: 近 10 万美元撬动 21 家图书馆的切实改变。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 要 launch 一个新产品/活动/内容，预算有限却想"引爆"传播。
2. 困惑"为什么我砸了钱做推广却没人理"，需要诊断失败原因。
3. 想推动组织/社区里的一种行为改变（健康、安全、合规）。
4. 面对一个突然刷屏的社会热点，想理解它为什么爆发。
5. 要遏制一场负面流行（谣言、事故模仿、不良行为蔓延）。

### 语言信号 (用户的话里出现这些就应激活)
- "怎么让它刷屏 / 走红 / 病毒式传播 / 引爆"
- "为什么突然火了 / 怎么突然传开了"
- "我推广了但没效果 / 砸钱也没用"
- "怎么让大家都养成 XX 习惯 / 改掉 XX"
- "how to make it go viral / spread / tip"

### 与相邻 skill 的区分
- 与 `connectors` / `mavens` / `salesmen`：本 skill 是总入口与诊断框架；那三个是"个别人物法则"内部的三类具体人，需要找具体某类人时转到它们。
- 与 `stickiness-factor`：本 skill 诊断三根杠杆；若已确定"信息记不住/没行动"，转 stickiness-factor。
- 与 `broken-windows` / `rule-of-150` / `power-of-context`：这些是"环境威力"的具体工具；当诊断指向"环境问题"时转它们。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **定位问题类型**
   - 完成标准: 明确用户是要"发起流行"还是"遏制流行"，对象是什么（产品/行为/信息）。
2. **三杠杆诊断**
   - 完成标准: 针对目标，分别回答——(a) 谁是关键的联络员/内行/推销员？(b) 信息的附着力够吗（会被记住并行动吗）？(c) 环境信号与群体规模在帮忙还是添乱？
   - 判停条件: 若三根杠杆都明显缺陷，先给"总诊断"再建议深入对应子 skill；若已聚焦某一杠杆，直接转入对应 skill。
3. **给出集中打点的方案**
   - 完成标准: 给出"把有限资源压在哪一点"的具体动作，而非全面清单。
4. **设定可观测的引爆指标**
   - 完成标准: 给出 1–3 个能判断是否到达引爆点的指标（如关键人采纳数、重复行为率）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 纯技术实现问题（怎么写代码/搭架构），与传播流行无关。
- 一次性信息查询（"引爆点是什么意思"可答，但若只是查定义而非要解决传播问题，不必整套流程）。
- 问题本质由"网络效应/平台算法"主导（如社交平台冷启动），三法则解释力有限，需结合网络规模逻辑。

### 作者在书中警告的失败模式
- 误以为"全面撒网+加大预算"就能引爆（反吸烟综合运动规模浩大却无效，见 stickiness-factor）。
- 忽略"信息交流免疫力"：渠道越泛滥人越屏蔽，覆盖广≠有效（见 maven-trap 动机）。

### 作者的盲点 / 时代局限
- 成书于 2000 年，案例多为前社交媒体时代；算法推荐、 influencer 经济需重新校准。
- 作者把"流行"多视作中性/正面，对"被恶意操纵的流行"（虚假信息、极端主义）缺乏方法论警惕。
- 三法则更偏"事后解释框架"，事前严格复制一场流行的因果证据有限，避免把它当万能配方。

### 容易混淆的邻近方法论
- 与"增长黑客/漏斗模型"混淆：本 skill 强调"关键少数+附着力+情境"，而非线性漏斗。
