## I — 方法论骨架 (Interpretation)

变现金字塔是一个三层递进的战略框架，不是5种赚钱方法的平级罗列。

Yangyi的5种方法映射到金字塔的三层：

1. **底层（流量型）** — 商单 + 广告分成。门槛最低，依赖粉丝基数和曝光量。广告分成需500蓝V+近3月5M曝光；商单价格取决于粉丝质量和近期数据。利润率低，受平台政策影响大。
2. **中层（产品型）** — 订阅 + 带货。自有课程、付费专栏、分销产品。毛利率高，一次创作可复用。订阅需2000蓝V开通。这是"把信任打包成产品"的层。
3. **顶层（服务型）** — 转私域（高端咨询/私教/定制社群）。客单价高，利润率超80%。IP粉丝自带信任，决策链路极短："关注你=信任你=愿意付费"。

关键洞察：**每层支撑上一层**——流量喂产品销售，产品口碑喂服务需求。IP路线可叠三层（从底层逐步爬到顶层），泛流量路线卡在底层（转化需反复种草，链路极长）。信任溢价使IP能直达顶层，这是金字塔层级递进而非方法平级罗列的核心原因。

## A1 — 书中的应用 (Past Application)

### 案例 1: AIP教程真实收益递进（月1两位数→月3五位数）
- **问题**: IP路线的变现加速是否真实可验证？
- **方法论的使用**: AIP教程分享了一个IP路线的真实变现递进案例，用金字塔模型解释：第一个月仅底层尝试（两位数），第二个月开始往中层推（4位数），第三个月触及顶层服务型变现（5位数）。信任资产积累到临界点后，转化链路极短，变现呈指数加速。
- **结论**: IP路线的复利效应使变现从底层向顶层加速递进，不是线性增长。
- **结果**: 3个月内从两位数变现到五位数，验证了"信任资产+复利效应"的变现加速逻辑。

### 案例 2: 乌云老师月入23万（顶层服务型变现）
- **问题**: IP路线的变现天花板能到多高？
- **方法论的使用**: 木马人引用乌云老师（@Pluvio0yte）月入23万的案例。当流量起来后，变现渠道（咨询、商单、线下合作）自然广阔——这正是金字塔顶层服务型变现的典型：IP信任资产缩短了转化链路，使高客单价服务成为可能。
- **结论**: IP路线的信任溢价能直达金字塔顶层，利润率远超底层流量型变现。
- **结果**: 单月变现23万人民币，是中推IP变现的经典案例。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **有一定粉丝量，规划变现路径** — 用户已有几百到几万粉，想知道"我该怎么变现""从哪开始变现"。
2. **判断是否够格开创作者收益/广告分成** — 用户想确认自己是否达到平台变现门槛（500蓝V+3月5M曝光）。
3. **决定卖什么产品/做什么服务** — 用户想从中层（课程/专栏）或顶层（咨询/社群）切入，需要判断该做哪层。
4. **变现方式单一/不稳定，想往上层走** — 用户目前只靠商单或广告分成，收入不稳定，想升级变现结构。
5. **评估泛流量账号的变现天花板** — 用户粉丝量大但变现差，想理解为什么卡在底层。

### 语言信号 (用户的话里出现这些就应激活)

- "怎么变现 / 如何变现 / 变现路径"
- "够不够格开创作者收益 / 广告分成门槛 / 5M曝光"
- "卖什么产品 / 该做课程还是咨询 / 付费专栏"
- "商单 / 广告分成 / 订阅 / 带货 / 转私域"
- "monetize / creator revenue / what to sell / monetization strategy / ad revenue sharing"

### 与相邻 skill 的区分

- 与 `x-positioning-tradeoff` 的区别: 定位权衡解决"该做IP还是泛流量"的战略选择（在变现之前）；变现金字塔解决"给定定位后怎么规划变现路径"。用户问"该做IP还是泛流量"→定位权衡；用户问"我有X粉怎么变现"→变现金字塔。
- 与 `x-account-setup` 的区别: 账号装修解决"怎么开蓝V/装修Profile/养号"的开业准备；变现金字塔解决"够不够格开收益/卖什么产品"的变现规划。用户问"蓝V怎么开"→账号装修；用户问"蓝V+500粉够不够开广告分成"→变现金字塔。
- 与 `x-cold-start-playbook` 的区别: 冷启动解决"没粉丝怎么办"的0→1增长；变现金字塔解决"有粉丝了怎么变现"的1→N收口。用户说"还没粉丝"→冷启动；用户说"有X粉怎么赚钱"→变现金字塔。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位用户当前在金字塔的哪一层**
   - 逐层检查：(a) 底层——有蓝V吗？500粉+3月5M曝光达标吗？有商单合作吗？(b) 中层——有自有产品（课程/专栏/电子书）吗？有分销/带货吗？有订阅频道吗？(c) 顶层——提供咨询/私教/高端社群吗？有私域流量池吗？
   - 完成标准: 明确标出用户当前已触达哪层、哪层尚未开启。

2. **将5种赚钱方法映射到3层金字塔，评估各层可行性**
   - 底层(商单+广告分成): 检查门槛是否达标（500蓝V+5M曝光）。若不达标，明确差距。
   - 中层(订阅+带货): 评估是否有可产品化的知识/技能。订阅需2000蓝V。
   - 顶层(转私域): 评估是否有高客单价服务能力（咨询/私教/定制）。
   - 完成标准: 每层给出"已开启/可开启/暂不具备条件"的判断。
   - 判停条件: 若用户粉丝量极低（如<100），直接建议先走冷启动（→x-cold-start-playbook），跳到步骤4。

3. **判断IP路线 vs 泛流量路线的变现天花板**
   - IP路线: 可叠三层——底层赚流量钱→中层卖产品→顶层做服务，信任溢价使顶层利润率>80%。
   - 泛流量路线: 卡底层——粉丝画像不精准，品牌方不买单，转化需反复种草（ce13）。
   - 完成标准: 明确告知用户其路线的变现天花板，若泛流量则提示"只能停底层"的风险。

4. **规划往上一层的路径**
   - 从底层往中层: 把内容沉淀成可复用产品（课程/专栏/电子书），用推文评论区引流。
   - 从中层往顶层: 用产品口碑筛选高付费意愿用户，导入私域做咨询/高端社群。
   - 完成标准: 给出"当前层→往上一层需要补什么"的具体行动建议，而非泛泛说"做内容"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **还没粉丝的冷启动阶段** — 0粉丝时谈不上变现规划，应先用 `x-cold-start-playbook` 涨粉。变现金字塔是"有粉后怎么收口"，不是"没粉怎么开始"。
- **选IP还是泛流量的战略定位决策** — 这是 `x-positioning-tradeoff` 的场景。变现金字塔在定位已确定后规划变现路径，不解决"该走哪条路"的问题。
- **开蓝V/装修Profile/养号的开业准备** — 这是 `x-account-setup` 的场景。变现金字塔可能提及"需500蓝V"作为门槛，但不指导怎么开蓝V。
- **内容数据复盘** — 用 `x-data-review` 分析内容表现，变现金字塔规划的是变现结构不是内容优化。

### 作者在书中警告的失败模式

- **泛流量只能停底层（ce13）**: 泛流量粉丝关注原因多样（娱乐/跟风），与创作者无信任关系。品牌方通过粉丝画像判断商业价值，泛流量画像模糊、转化率低，广告主不愿支付高价。变现需反复种草建立信任，成本远高于IP路线。泛流量账号即使粉丝量大，也难以突破到中层和顶层。
- **创作者收益门槛不稳定**: 500蓝V+3月5M曝光是时点数据，受平台政策影响大（BOOK_OVERVIEW批判: 阈值会漂移）。Yangyi明确标注"受官方政策影响较大，收入不稳定"，中文区广告分成一般在100-200美元左右，订阅收入"中文区基本没有显著收入"。不应将底层广告分成视为稳定收入来源。

### 作者的盲点 / 时代局限

- **幸存者偏差**: 乌云月入23万、AIP三月达五位数是成功案例，缺对照组——同等努力但没起来的案例未被纳入。这些案例展示了天花板而非中位数。
- **门槛数据时效性**: 500蓝V、5M曝光、2000蓝V订阅等门槛是2025-2026年的时点数据，平台随时可能调整。
- **部分作者有商业动机**: 推荐付费群/工具时可能利益相关，变现案例可能被选择性呈现。

### 容易混淆的邻近方法论

- **x-positioning-tradeoff（不可能三角+IP vs泛流量）**: 最易混淆。区分口诀: 问"该做IP还是泛流量"用定位权衡，问"有粉了怎么变现"用变现金字塔。定位权衡是"选哪条路"，变现金字塔是"路上怎么收口"。
- **x-account-setup（开店模型）**: 都涉及蓝V。区分: 问"蓝V怎么开/切日区"用账号装修，问"蓝V+500粉够不够开广告分成"用变现金字塔。
