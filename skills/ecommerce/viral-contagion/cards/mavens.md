## I — 方法论骨架 (Interpretation)

内行是"个别人物法则"的第二类关键人：对某领域研究极透、且**乐于无偿分享**信息，被朋友当作"数据库"来咨询。他们的传播力来自**被信任，而非被羡慕**——和联络员（连人）、推销员（说服）都不同。

判断要点：
- 不是"权威/专家/大V"，而是"爱收集+爱分享具体数据"的普通人。
- 影响力源于"我信他说的准"，不是"我崇拜他"。
- 他们通常会主动给身边人建议（买电脑、选耳机、挑餐厅），是购买/采纳决策的源头。

要发动口碑，找到内行比找名人更有效：他们的一句话能在朋友圈里持续发酵。

## A1 — 书中的应用 (Past Application)

### 案例 1: 马克·阿尔珀特作技术内行
- **问题**: 理解"谁在真正驱动产品口碑"。
- **方法论的使用**: 阿尔珀特对技术产品研究极透，朋友买电脑耳机都问他；他无偿分享，是周围人的数据库。同一人也可兼具联络员属性。
- **结论**: 内行靠"数据+信任"成为信息源，不靠地位。
- **结果**: 印证内行是口头传播浪潮的发起者之一。

### 案例 2: 吸烟"啜饮者"(chippers) 中的数据视角
- **问题**: 解释为何有人每天少量吸烟却不上瘾。
- **方法论的使用**: 书中以"内行式"的数据拆解（贝诺维茨尼古丁门槛研究）揭示行为粘性机制。
- **结论**: 内行/数据视角能戳破"吸烟必上瘾"的常识误区。
- **结果**: 为附着力门槛策略提供依据（见 stickiness-factor）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 想为一款小众/技术产品找"会自发推广"的人。
2. 需要专业背书，但明星/KOL 不精准或太贵。
3. 想判断"某品类里谁的话最有分量"。

### 语言信号 (用户的话里出现这些就应激活)
- "找懂行的人帮我推 / 做口碑"
- "这个领域谁最专业、大家信谁"
- "怎么找 KOC / 真实内行"
- "想让懂行的人先试用"
- "who is the maven / go-to expert for X"

### 与相邻 skill 的区分
- 与 `connectors`：内行"供数据/专业建议"，联络员"连人/跨圈扩散"；要扩散网络用 connectors，要专业种草用 mavens。
- 与 `maven-trap`：本 skill 识别"什么是内行、怎么用他们"；maven-trap 解决"内行藏得深、怎么主动钓出来"。
- 与 `salesmen`：内行靠信息准确取胜，推销员靠情绪感染成交。

## E — 可执行步骤 (Execution)

1. **界定目标领域的内行画像**
   - 完成标准: 写出"在 XX 领域爱钻研、爱无偿给朋友建议"的具体人群特征。
2. **从弱信号定位内行**
   - 完成标准: 通过社群/论坛/评论区找"高频给出具体数据建议、被他人 @ 求助"的人。
3. **给早期访问与细节资料**
   - 完成标准: 提供内行在乎的"深度信息/试用资格"，而非泛泛宣传物料。
4. **让内行成为朋友圈数据库**
   - 完成标准: 设计便于他们转述的话术/数据卡，让建议自然流出。
   - 判停条件: 若找不到现成内行，转 maven-trap 设计"陷阱"把隐藏内行钓出。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 要广泛跨圈扩散而非专业种草——用 connectors。
- 要临门一脚成交而非前期影响——用 salesmen。
- 内行根本不现身、难以识别——转 maven-trap。

### 作者在书中警告的失败模式
- 把"大V/名人"当内行：内行靠信任与数据，名人靠曝光，二者不同。
- 用"地位"定义影响力：内行靠朋友圈特殊地位崭露头角，不是靠收入/学历。

### 作者的盲点 / 时代局限
- "内行靠爱分享驱动"偏理想化；现实中有偿测评/利益披露会让内行动机复杂化，需识别利益绑定。

### 容易混淆的邻近方法论
- 与 maven-trap 混淆：识别 vs 主动钓出，是前后衔接但不是同一动作。
