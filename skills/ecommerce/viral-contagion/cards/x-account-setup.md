## I — 方法论骨架 (Interpretation)

把做IP账号当开一家店——发内容前必须完成三步开业准备，顺序不能乱：

**第一步：装修门面（Profile四要素）。** 头像首选真人半身照（建立信任最快），昵称用"关键词+身份"格式（如"小陈聊AI"），简介写一句话价值承诺（你是谁+发什么+关注有什么好处），背景图做简介的视觉延伸。装修不是美化，是转化——它是涨粉漏斗的第3步（推文曝光→展开完读→进Profile看门面→关注），门面不行则前两步的流量全漏掉。

**第二步：办蓝V（Premium）。** 蓝V=营业执照。不开=评论被折叠进垃圾区（别人看不到就不关注）+涨粉受限+无广告分成。开中间档Premium，不开Basic（没用），不必Premium+（新人没必要）。

**第三步：养号。** 新号初始权重低、易被判机器人。先浏览3天（老号1-2天），每天约1小时，不急于点赞/评论/关注，关注数不要远多于粉丝数。养完再发内容。

核心洞察：装修为转化而非美化；蓝V是基础设施而非可选增值；养号是发内容前的安全期，不是发内容后的补救。

## A1 — 书中的应用 (Past Application)

### 案例 1: 木马人没开蓝V卡在2500粉

- **问题**: 为省每月8刀蓝V月费，账号从0做到2500粉后长期停滞，怎么也涨不动
- **方法论的使用**: 开店模型第二步缺失——没办"营业执照"。无蓝V导致评论被系统折叠进垃圾评论区，别人看不到也就不关注；同时无曝光加成、无法参与广告分成，形成恶性循环
- **结论**: 没开蓝V是涨粉卡2500的核心原因，"这钱真不要省"
- **结果**: 黑五开了蓝V，当天涨100粉，后面一周涨粉数量比之前一个月都多

### 案例 2: 装修四要素对标案例

- **问题**: 路人刷到推文后点进Profile，什么决定他要不要关注
- **方法论的使用**: 四要素到位——@canghe苍何、@lxfater铁锤人用真人头像建立真实感与信任；@bozhou_ai泊舟、@servasyy_ai黄瑟瓦简介清晰传递"我是谁、发什么、你能拿到什么"；@zstmfhyAI奶爸、@berryxia神佬用背景图做视觉延伸加深印象
- **结论**: 真人头像+关键词昵称+价值承诺简介+风格统一背景图=路人3秒内理解"关注有什么好处"→关注
- **结果**: 这些账号因装修到位被教程选为推荐对标案例

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新号刚注册或老号刚解冻，不知道第一天该干什么——需要开店模型全套流程
2. 纠结要不要开蓝V/Premium，觉得月费贵——需要蓝V血泪教训和档位选择
3. 账号Profile需要装修或重装（头像/昵称/简介/背景图）——需要装修四要素清单
4. 新号不知道怎么养号、怕被判机器人——需要养号具体操作和红线
5. 已有账号但Profile一直没管，想系统补上门面——需要装修四要素自查

### 语言信号 (用户的话里出现这些就应激活)

- "新号第一天该干什么" / "新注册的号怎么开始"
- "要不要开蓝V" / "蓝V值不值" / "should I get Premium" / "Twitter Blue worth it"
- "怎么装修主页" / "头像用什么好" / "昵称怎么取" / "简介怎么写" / "how to set up X profile"
- "新号怎么养号" / "养号几天" / "warm up new account"
- "背景图怎么设计" / "profile banner"
- "刚注册的号能直接发推吗"

### 与相邻 skill 的区分

- 与 `x-cold-start-playbook` 的区别: 本skill是"开业准备"——发内容前的装修+蓝V+养号；cold-start是"开业后获客"——已有内容但没流量时的六策略+漏斗诊断。用户说"新号第一天"→本skill；用户说"发了推文没流量"→cold-start。
- 与 `x-account-pitfalls` 的区别: 本skill是"预防"——开业前准备清单；pitfalls是"治疗"——已出问题（限流/封号/标签）后的排查与申诉。用户说"要不要开蓝V"→本skill；用户说"被限流了怎么办"→pitfalls。
- 与 `x-benchmark-research` 的区别: 本skill装修自己的"店面"；benchmark是去看别人的"店"怎么开的（找对标）。二者可配合：先找对标定方向，再按本skill装修。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **装修门面四要素**
   - 头像: 选真人清晰半身照/正面照（首选），或风格化AI头像（备选）。禁止: 风景照、纯文字、品牌Logo、模糊/马赛克图
   - 昵称: 格式=关键词+身份/名字（如"小陈聊AI""Emily AIGC设计""跨境电商Leo"）。禁止: 纯数字、无意义字符（如"abc123""用户6688"）
   - 简介: 写清身份定位+内容方向+受众价值，一句话价值承诺。参考模板:"专注AI工具测评与行业资讯 | 帮助创意者提升效率"。可附链接（linktr.ee/bento.me等）
   - 背景图: 与头像/昵称风格色调统一，融入核心领域/价值主张/代表作，视觉动线终点引导至关注按钮。用Canva搜"twitter banner"（1500×500模板）
   - 完成标准: 四要素全部到位，路人3秒内能回答"你是谁、发什么、关注有什么好处"

2. **办蓝V (Premium)**
   - 开Premium（中间档），不开Basic（没有蓝标和流量加成），不必Premium+（新人没必要）
   - 开通后审核期间绝对不改头像/昵称/简介（改资料触发重新审核，蓝V掉落、评论被折叠）
   - 完成标准: 蓝标显示，账号处于正常状态

3. **养号**
   - 新号: 至少3天，每天浏览约1小时（浏览对标账号，边养边学）
   - 老号解冻: 至少1-2天
   - 禁止: 频繁点赞/评论、一次性关注太多账号、关注数远多于粉丝数（如关注100人但只有1个粉丝）
   - 判停条件: 若用户已是运营中的老号（非新注册/非解冻），则跳过本步直接到步骤4
   - 完成标准: 养号期结束后才开始发内容和主动互动

4. **进入发内容阶段**
   - 养号完成后，开始发第一条内容
   - 完成标准: 发布第一条推文，之后转入 `x-cold-start-playbook` 做冷启动获客

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已运营账号的日常发内容/选题/写推文——本skill是"开业准备"，不是日常内容运营
- 账号被限流/封号后的排查与申诉——应转 `x-account-pitfalls`（那是"治病"，本skill是"防病"）
- 发了内容但没流量/没粉丝的诊断——应转 `x-cold-start-playbook`（那是"开业后获客"问题，非"开业前准备"问题）
- 纯粹找对标/研究竞品账号——应转 `x-benchmark-research`（本skill的装修需对标先行，但找对标本身是另一个skill）

### 作者在书中警告的失败模式

- **ce01 — 没开蓝V卡2500粉**: 为省月费不开蓝V，评论被折叠进垃圾区，涨粉卡死在2500。开蓝V当天涨100粉，一周超之前一月。蓝V是基础设施不是可选增值。
- **ce04 — 蓝V审核期改资料掉标**: 开了蓝V后改头像/昵称/简介，触发重新审核，蓝V掉落、评论被折叠、触达不稳定。审核期绝对不动资料。
- **ce20 — 新号不养号直接互动判机器人**: 新号注册后立即大量点赞/评论/关注，被系统判定机器人，限流或冻结。养号是不可跳过的安全期。

### 作者的盲点 / 时代局限

- 蓝V各区价格/开通步骤时效性强（日区¥428、礼品卡支付等具体操作会随平台调整），具体数字仅作参考
- 养号"3天""每天1小时"是经验值，非X官方公开规则，平台观察期机制可能变化
- "不开蓝V评论被折叠"基于2024-2026观察，平台规则可能调整
- 博弈算法的技巧（控关注粉丝比防判机器人）可能随反作弊进化失效（ce21: 平台收紧后整套打法可能过时）
- 作者为成功幸存者，存在幸存者偏差——同等努力但没起来的案例未展示

### 容易混淆的邻近方法论

- **养号 vs 冷启动**: 养号是发内容前的"安全期"（模拟真人浏览，建立账号权重），冷启动是发内容后的"加热期"（主动互动突破初始流量池）。二者时序不同，不可混用。
- **装修 vs 对标研究**: 装修是"装修自己的店"（Profile四要素），对标研究是"去看别人的店怎么开的"（找3-5个对标账号拆解）。配合使用：先对标定方向，再装修落地。
