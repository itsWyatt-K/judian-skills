## I — 方法论骨架 (Interpretation)

内容深度、传播力、变现力构成不可能三角——三者无法同时最大化。深度内容受众少但转化高；泛流量触达广但转化差；高变现需要信任而信任限制触达。你必须主动放弃一个角，而不是幻想三者兼得。

**选择路线 = 选择放弃哪个角：**

- **IP路线**：选深度+变现，放弃泛传播。建个人影响力，粉丝精准但不多，信任缩短转化链路（关注=信任=付费）。具三大优势：抗周期（人换平台粉丝跟走）、高商业化（信任溢价，变现金字塔可叠三层）、复利（内容/粉丝/影响力持续积累）。
- **泛流量路线**：选传播，放弃深度和单客变现。做矩阵涨粉快、易造势，但粉丝画像模糊、品牌匹配度低，变现卡在底层（广告/流量主）。

**反常识洞察："泛流量不值钱"。** 泛流量粉丝关注原因多样（娱乐、跟风），与创作者无信任关系，广告主通过画像和转化率判断价值，泛流量账号画像模糊、转化链路极长，广告主不愿支付高价。IP粉丝自带信任，决策链路极短。

核心原则：先定你放弃哪个角，再选内容策略。不是"先做内容再想变现"，而是"先看变现模式决定定位"。

## A1 — 书中的应用 (Past Application)

### 案例 1: Yangyi 先精准IP再泛化增长

- **问题**: 新号做X，该追粉丝数还是做精准IP？
- **方法论的使用**: 选IP路线（深度+变现），前3万粉全部精准定位创业/赚钱/营销赛道，用不可能三角主动放弃泛传播——先建信任资产，不追求泛化涨粉
- **结论**: IP路线前期涨粉慢但粉丝精准、转化高，信任积累到临界点后可泛化扩展
- **结果**: 2个月做到2万精准IP粉；之后泛化增长，4个多月从3万到10万粉。验证了"先做精准IP粉再泛化"的路径

### 案例 2: AIP教程IP路线真实收益递进

- **问题**: IP路线的变现能力到底比泛流量强多少？
- **方法论的使用**: 用不可能三角对比——IP选深度+变现，粉丝自带信任，决策链路极短（关注=信任=付费）；泛流量需"反复种草-建立信任-刺激下单"，链路极长
- **结论**: IP路线的信任资产产生复利效应，变现加速到临界点后爆发
- **结果**: AIP教程记录的真实收益案例——第一个月变现两位数，第二个月4位数，第三个月5位数。3个月内从两位数到五位数，验证IP路线信任积累到临界点后转化链路极短

### 案例 3: IP三大优势体系化论证

- **问题**: 为什么IP路线优于泛流量？
- **方法论的使用**: AIP教程从三个维度论证IP优势：(1)抗周期——用户认的是你的专业/人格/价值观，换平台粉丝跟走；(2)高商业化——信任溢价使变现路径从底层（广告）到顶层（咨询，利润率>80%）层层递进；(3)复利——内容一次创作多次复用，老粉带新粉，越积累越容易获得资源倾斜
- **结论**: IP构建"信任资产+人格壁垒+可复用影响力"，不随算法/周期波动贬值，反而持续放大
- **结果**: 成为AIP教程推荐IP路线的核心论据，配合Yangyi案例和真实收益递进形成完整证据链

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新号启动或老号重新定位，不知道该做IP还是泛流量——需要不可能三角做战略选择
2. 纠结"做X赚钱该追粉丝数还是做IP"——需要用变现模式倒推定位
3. 已有粉丝但变现差，质疑"泛流量不值钱吗"——需要理解泛流量变现差的机制
4. 在内容深度和传播力之间权衡，不知道该写深度还是追热点——需要先定放弃哪个角
5. 已有产品/服务/咨询能力，想知道X账号该怎么定位配合变现——需要选IP路线

### 语言信号 (用户的话里出现这些就应激活)

- "做X赚钱该追粉丝数还是做IP" / "IP还是泛流量" / "should I chase followers or build IP"
- "定位怎么选" / "账号定位" / "positioning strategy" / "niche vs mass traffic"
- "深度和传播怎么权衡" / "内容该写深度还是追热点"
- "泛流量不值钱吗" / "为什么泛流量变现差" / "why generic traffic doesn't monetize"
- "我有产品/服务，X账号怎么定位" / "selling consulting on X"
- "该做矩阵还是做个人IP" / "matrix accounts vs personal brand"

### 与相邻 skill 的区分

- 与 `x-monetization-pyramid` 的区别: 本skill是"选哪条路线"的战略定位（IP vs 泛流量，用不可能三角定方向）；monetization是"选定路线后怎么变现"的具体路径（金字塔三层+5种赚钱方法）。用户说"该做IP还是泛流量"→本skill；用户说"我3万粉了怎么变现"→monetization。
- 与 `x-benchmark-research` 的区别: 本skill是"定自己的定位"（深度/传播/变现三角取舍）；benchmark是"研究别人的定位"（找3-5个对标账号拆解）。二者可配合：先用本skill定路线方向，再用benchmark找该路线的对标。
- 与 `x-content-archetypes` 的区别: 本skill是"账号级战略定位"（选IP还是泛流量）；archetypes是"内容级功能分类"（资源入口/工具教程/AI发现/普通表达）。定位决定内容倾向，但二者层级不同。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **用不可能三角定位：你为哪个顶点优化？**
   - 画出三角的三个角：内容深度、传播力、变现力
   - 问用户的核心变现模式是什么：
     - 卖产品/服务/咨询/课程 → 选深度+变现（IP路线），放弃泛传播
     - 靠广告/流量主/平台分成 → 选传播（泛流量路线），放弃深度和单客变现
   - 完成标准：能明确回答"我放弃哪个角、保留哪两个角"

2. **选择路线并理解代价**
   - IP路线：保留深度+变现，放弃泛传播。代价=前期涨粉慢、受众窄。优势=抗周期/高商业化/复利，信任缩短转化链路
   - 泛流量路线：保留传播，放弃深度和单客变现。代价=转化差、变现卡底层（广告）、粉丝画像模糊。优势=涨粉快、易造势
   - 判停条件：若用户已有明确变现产品/服务/咨询能力 → 直接选IP路线，跳到步骤3
   - 完成标准：用户理解所选路线的代价和优势，确认选择

3. **根据路线定内容策略方向**
   - IP路线：内容聚焦垂直领域，建差异化人格（核心是"你这个人"的独特经验/视角/价值观，不是抄对标）；信任资产优先于流量数字；可先用精准IP粉建信任，到临界点后泛化扩展（Yangyi路径）
   - 泛流量路线：追热点、做搬运整合、扩大触达；接受变现天花板在底层（广告/流量主）；矩阵化操作
   - 完成标准：能回答"我放弃哪个角、选哪条路线、因此内容策略的大方向是什么"。之后转入具体内容生产类skill或benchmark-research找对标

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已有明确定位的日常内容生产/选题/写推文——本skill是"选定位"不是"做内容"。已有定位后应转内容创作类skill
- 已有粉丝想知道具体怎么变现/有哪些赚钱方法——应转 `x-monetization-pyramid`（本skill只定"选哪条路线"，不定"怎么变现"）
- 找对标账号研究竞品——应转 `x-benchmark-research`（本skill定自己的方向，benchmark是看别人怎么做的）
- 账号被限流/封号后的排查——应转 `x-account-pitfalls`

### 作者在书中警告的失败模式

- **ce13 — 泛流量变现极差**: 追求泛流量路线追求粉丝数量，但粉丝画像不精准，品牌方不买单，商单价格低，变现转化链路极长。泛流量粉丝关注原因多样（娱乐、跟风），与创作者无信任关系，广告主通过画像和转化率判断价值，泛流量账号画像模糊、转化率低，广告主不愿支付高价。变现需反复建立信任，成本远高于IP路线。
- **ce19 — 盲目模仿对标缺乏差异化**: IP路线的核心是"差异化人格"——个人经验、独特视角、真实使用感。完全模仿对标账号的内容风格和选题，缺乏个人差异化，沦为"千篇一律的营销号"，用户无理由关注你而非原版。IP路线≠抄对标，而是"借别人验证过的流量逻辑，找别人没填的空"。

### 作者的盲点 / 时代局限

- **假设IP路线一定优于泛流量**——取决于赛道与目标。做媒体/段子/资讯号，泛流量可能更优（BOOK_OVERVIEW批判阶段指出："假设IP路线一定优于泛流量——取决于赛道与目标"）。段子手、新闻资讯、娱乐内容的变现模式本就依赖传播力而非深度，不可能三角的取舍方向因赛道而异。
- **幸存者偏差**：Yangyi、AIP教程作者都是成功者自述，未展示同等努力但没起来的案例。IP路线的"3个月两位数到五位数"是个例，非保证结果。
- **"泛流量不值钱"是趋势性判断**——具体取决于平台广告分成政策、品牌方预算变化。2025年X算法调整后广告分成门槛和比例可能变化。
- **IP三大优势（抗周期/高商业化/复利）是逻辑论证非对照组实验**——无数据证明IP路线在所有赛道都优于泛流量。

### 容易混淆的邻近方法论

- **不可能三角 vs 变现金字塔**：不可能三角是"选定位"的战略框架（深度/传播/变现三角取舍）；变现金字塔是"选定位后的变现路径"（底层广告→中层产品→顶层服务）。先不可能三角定路线，再金字塔定变现层。
- **IP路线 vs 对标研究**：IP路线的核心是"差异化人格"（你这个人独特的经验/视角/价值观）；对标研究是"借别人验证过的流量逻辑"。IP路线≠抄对标，而是用对标验证需求方向后填别人没填的空。
- **不可能三角 vs 内容原型分类**：不可能三角是账号级战略定位（选IP还是泛流量）；内容原型是内容级功能分类（资源入口/工具教程等）。定位决定内容倾向，但层级不同。
