## I — 方法论骨架 (Interpretation)

当目标群体与源头群体是**两个不同的世界**时，光靠联络员（连人）不够——信息会被"翻译失败"挡在门外。需要**中转员/译码者**：把信息/文化重构成目标群体能理解、向往的形式，从而跨越边界。

区别：
- 联络员：连接"人"（谁认识谁）。
- 中转员：翻译"信息/文化"（同一内容换成另一群人听得懂、想要的语言）。

判断要点：你的目标群体和你当前的受众"语言/审美/价值观"差异越大，越需要中转员而非单纯铺渠道。中转员往往本身就"脚踏两个世界"，能自然 reframe。

## A1 — 书中的应用 (Past Application)

### 案例 1: Hush Puppies / 云中漫步
- **问题**: 濒临死亡的品牌如何重获流行？
- **方法论的使用**: 先被纽约少数"酷青年"穿红，再由中转员把其"翻译"成主流能接受的样子，跨入大众市场。
- **结论**: 跨边界扩散靠译码者，不靠硬广。
- **结果**: 品牌起死回生，成为流行符号。

### 案例 2: 兰姆西斯模仿功夫片
- **问题**: 产品如何打动一个特定爱好者群体？
- **方法论的使用**: 革新者喜欢功夫片，兰姆西斯公司把广告"翻译"成功夫片语言。
- **结论**: 用目标群体熟悉的文化形式重构信息。
- **结果**: 实现对目标子群体的有效触达。

### 案例 3: 谣言的译码传播
- **问题**: 一条流言为何能跨社群扩散？
- **方法论的使用**: 靠中转员把它重述成每个群体关心的样子，不同群体有不同"译本"。
- **结论**: 中转员决定谣言能否跨圈。
- **结果**: 揭示跨边界扩散的译码机制。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要 this skill?
1. 技术/小众产品想打进时尚/大众/年轻圈层。
2. 一个圈层的梗/价值观要被另一圈层接受。
3. 跨国/跨文化背景的内容本地化重构。

### 语言信号 (用户的话里出现这些就应激活)
- "怎么打入 XX 圈 / 新市场"
- "他们听不懂我们的话 / 不买账"
- "怎么让这个圈层接受"
- "需要有人帮我们'翻译'给年轻人"
- "translator / reframe for a tribe / cross-group diffusion"

### 与相邻 skill 的区分
- 与 `connectors`：connectors 连"人"，translator 译"信息/文化"；跨陌生文化社群时优先本 skill，再借 connectors 扩散。
- 与 `mavens`：内行提供专业可信度，中转员提供跨边界的可接受性，二者互补。
- 与 `stickiness-factor`：若在同一群体内"记不住"，用 stickiness；若"换群体就不灵"，用本 skill。

## E — 可执行步骤 (Execution)

1. **识别两个世界的差异**
   - 完成标准: 写出源头群体与目标群体在语言/审美/价值观/渠道上的关键差异。
2. **找脚踏两界的中转员**
   - 完成标准: 定位"既懂你又懂他们"的人（跨界 KOL、社区桥梁者）。
3. **重构信息为对方语言**
   - 完成标准: 把卖点/内容重写成目标群体向往的形式（如功夫片语言、圈层梗）。
4. **先在小核心验证再放大**
   - 完成标准: 在目标群体小核心测共鸣，再借 connectors 扩散。
   - 判停条件: 若目标群体与源头本就同温层、无需翻译，则直接用 connectors / stickiness-factor。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用 this skill
- 目标群体与源头同温层、只需扩散——用 connectors。
- 只需专业背书——用 mavens。
- 只需临门一脚——用 salesmen。

### 作者在书中警告的失败模式
- 以为"渠道铺够就能跨圈"：没有译码，信息在边界失效。
- 找错"中转员"：必须真脚踏两界，否则翻译走样。

### 作者的盲点 / 时代局限
- 书中案例偏消费/文化；B2B 或强监管行业的"翻译"还受合规约束，需兼顾准确与合规。

### 容易混淆的邻近方法论
- 与 connectors 混淆：连人 vs 译信息，常需组合而非二选一。
