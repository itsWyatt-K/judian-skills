## I — 方法论骨架 (Interpretation)

一条信息能不能被人记住并行动，不取决于"说了多少遍"或"花了多少钱"，而取决于它的**包装方式**——这是可以被重新设计的工程问题。

可操作的附着力手法：
1. **重复曝光**：一次不够，《蓝狗线索》把同一集连放 5 遍才学会。
2. **简化到具体**：把抽象说教变成具体可模仿的行为。
3. **给可执行步骤**：人愿意做"可操作性强"的事（莱文瑟实验：加一张地图，行动率 3%→28%）。
4. **制造互动**：让人参与进来（旺德曼金盒子：观众变成互动广告的一部分）。
5. **适配受众认知**：《芝麻街》大鸟须与成人同框，儿童才当真。

进阶视角"附着力门槛"：行为粘性有临界值（如尼古丁成瘾门槛），低于门槛行为不固化——可用于降低有害行为粘性、提高有益行为粘性。

## A1 — 书中的应用 (Past Application)

### 案例 1: 《蓝狗线索》重复播放
- **问题**: 儿童教育节目看完一集学不会重点。
- **方法论的使用**: 制作方打破"每集只播一次"惯例，把同一集连续放 5 遍。
- **结论**: 重复曝光是可控的附着力因素。
- **结果**: 孩子真正记住并参与，节目大获成功。

### 案例 2: 旺德曼金盒子
- **问题**: 哥伦比亚唱片邮购广告回应率低，传统大预算广告也救不了。
- **方法论的使用**: 在广告里藏"金盒子秘诀"，找到者免费得唱片，把观众变成互动体系的一部分。
- **结论**: 互动+具体奖励比单纯曝光更有附着力。
- **结果**: 回应率 80% vs 对手 19.5%。

### 案例 3: 尼古丁门槛（附着力门槛）
- **问题**: 青少年吸烟率飙升，反吸烟综合运动却无效。
- **方法论的使用**: 把尼古丁压到"烟瘾门槛"之下，吸烟就只像普通感冒（来得易去得易）。
- **结论**: 粘性有门槛，干预要打在门槛连接点。
- **结果**: 指出反吸烟运动应聚焦"附着力引爆点"而非全面撒网。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 推送的内容/活动没人记住或转化。
2. 培训材料员工学完就忘。
3. 警示/号召信息发了却没人行动。
4. 想降低某种有害行为、或提高某种有益行为的粘性。

### 语言信号 (用户的话里出现这些就应激活)
- "怎么让人记住 / 记不住 / 看了就忘"
- "发了没人行动 / 转化低"
- "培训没用 / 学完就忘"
- "怎么让这个口号/信息粘住"
- "how to make it stick / why no one acts on it"

### 与相邻 skill 的区分
- 与 `connectors` / `mavens`：若"压根没人收到/不信"，是人或信任问题，转它们；若"收到了但不记不住/不动"，是本 skill。
- 与 `fear-appeal`：恐惧诉求是附着力的一条专项技法（高恐惧+步骤），本 skill 是总框架；只涉及"恐吓却无效"时转 fear-appeal。
- 与 `broken-windows`：本 skill 改"信息本身"，broken-windows 改"环境信号"；常配合。

## E — 可执行步骤 (Execution)

1. **诊断粘性缺口**
   - 完成标准: 明确是"记不住"（认知）还是"不行动"（行为）还是"不固化"（习惯）。
2. **选 redesign 手法**
   - 完成标准: 从[重复曝光/简化具体/给步骤/制造互动/适配受众]中选 1–3 项，写清改法。
3. **降门槛给步骤**
   - 完成标准: 提供"立刻能做、低摩擦"的具体动作（如地图、按钮、模板）。
4. **加互动参与**
   - 完成标准: 设计让受众动手/决策/反馈的环节，而非单向灌输。
5. **测行为而非曝光**
   - 完成标准: 用"是否行动/复购/复述"而非"阅读量"衡量效果。
   - 判停条件: 若受众根本没收到信息，转 connectors；若发了仍不转化且因"不信任"，转 mavens。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 信息压根没人收到——先解决传播（connectors/mavens）。
- 受众不信任内容——先建信任（mavens）。
- 行为由环境失序/群体规模驱动——转 broken-windows / rule-of-150。

### 作者在书中警告的失败模式
- 误以为"多说几遍/加大预算"就有附着力（砸钱广告败给金盒子）。
- 全面撒网却没打到附着力引爆点（反吸烟综合运动无效）。
- 只恐吓不给步骤——恐惧反而让人回避（见 fear-appeal）。

### 作者的盲点 / 时代局限
- 附着力结论多来自电视/纸媒时代；短视频/算法feed 的"重复与互动"机制已变，需重校准节奏。

### 容易混淆的邻近方法论
- 与 fear-appeal 混淆：fear-appeal 是附着力的一条子法则，不是全部。
