## I — 方法论骨架 (Interpretation)

冷启动不是"发好内容等它自然火",而是新号没粉丝时按边际回报排序主动投时间。两个工具配合使用:

**涨粉四步漏斗(诊断工具)**: 推文曝光→展开/完读→进Profile看门面→关注。每步都有流失。先诊断你丢在哪步:推文没曝光(用策略1抢大V评论区借大V的流量)/展开了不进Profile(推文没引导"看我主页"的钩子)/进了不关注(门面四要素没到位,转x-account-setup)。

**六策略(按边际回报排序)**:
1. 大V评论区抢占(最高)——关注10个1w-10w中小V,开通知,5分钟内评论,模板=重述观点+补充经验,每天10条
2. 引用转发+深度观点(同级)——Quote大V推文+300字增量观点
3. 每日发推——每天1-3条,先跑起来不追求完美
4. 互关社区——前3天快速获30-50粉,但每天≤15人防风控
5. 热门蹭流量——搜索+trending
6. 互动率优先——积极回复每条评论

**前24h加热机制**: 帖子发出后系统给一点初始曝光,前几小时如果有互动就进入更大流量池;安安静静就沉了。发完不能不管——主动找朋友转、社群加热、大V帮忙转。

核心决策逻辑:把有限时间投到边际回报最高的地方(评论区抢占+引用转发>被动发推),而非均匀分配。

## A1 — 书中的应用 (Past Application)

### 案例 1: 木马人21天0→4200(起号帖28万曝光靠朋友帮转)

- **问题**: 被封号后新号重启,0粉丝,怎么度过冷启动?
- **方法论的使用**: 用前24h加热机制——起号帖发出后靠朋友们(社群成员)互相转发加热,主动突破初始流量池;配合装修好主页+开蓝V,让漏斗第3步Profile门面能接住流量。他付费加入Panda老师增长群,群内小伙伴互相加热帖子快速过渡冷启动。
- **结论**: 冷启动期主动找人帮忙转比被动等自然流量有效得多;前几小时的社群加热能突破初始池,让帖子进入更大推荐池。
- **结果**: 起号帖28万曝光,粉丝从16涨到700+,21天做到4200粉,成功度过冷启动。

### 案例 2: 向阳乔木被tw93和宝玉推荐涨到1万Followers

- **问题**: 冷启动期最早的1万粉从哪来?
- **方法论的使用**: 策略1(大V评论区抢占)+策略5(引用转发)的变体——坚持每天刷Product Hunt、海外Newsletter,测试AI工具写反馈,通过"准备干货+被动传播+主动评论"让KOL看到优质内容并主动转发。tw93和宝玉转发他的内容后,粉丝涨到1万。
- **结论**: 大V评论区抢占的本质不是"蹭",而是在有大V曝光的地方展示增量价值,让KOL主动注意到你并帮你放大——冷启动期的被动传播来自主动准备。
- **结果**: 被tw93和宝玉推荐后涨到1万Followers,完成冷启动。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **新号没粉丝,发了推文没人看**——需要漏斗诊断丢在哪步+六策略选优先级。
2. **有少量粉丝(几十到几百)但帖子曝光仍然很低**——判断是否还在冷启动期+选策略突破。
3. **发完推文不知道要不要主动加热/怎么加热**——需要前24h加热机制的具体操作。
4. **时间有限,冷启动阶段不知道该优先做什么**——需要按边际回报排序策略组合。
5. **互关社区/社群加热想用但怕触发风控**——需要安全红线(每天≤15互关)和正确用法。

### 语言信号 (用户的话里出现这些就应激活)

- "没粉丝怎么办" / "帖子没人看" / "0粉丝怎么起号"
- "冷启动怎么过" / "怎么起量" / "怎么破零"
- "发了推文没人理" / "曝光个位数" / "新号没流量"
- "互关群有用吗" / "要不要找朋友帮转" / "发完推文要做什么"
- "0 followers" / "no engagement" / "cold start" / "new account no views" / "how to get first 100 followers"

### 与相邻 skill 的区分

- 与 `x-account-setup` 的区别: account-setup是"开业前准备"(装修四要素/蓝V/养号),本skill是"开业后获客"(已有内容但没流量时的六策略+漏斗诊断)。用户说"新号第一天该干什么"→account-setup;用户说"发了推文没流量"→本skill。时序上account-setup完成后衔接本skill。
- 与 `x-comment-engagement` 的区别: comment-engagement是全面的评论互动方法论(六法+Repost vs Quote+坎宁汉姆定律);本skill把"大V评论区抢占"作为六策略之一使用,不展开评论技巧本身。用户问"怎么评论获曝光又不被当蹭流量"→comment-engagement;用户问"冷启动该做什么策略"→本skill。
- 与 `x-foryou-algorithm` 的区别: foryou-algorithm解释"为什么"冷启动难(OON占比/候选隔离/初始流量池机制);本skill是"怎么破"冷启动(六策略+前24h加热)。用户问"算法怎么推荐内容"→foryou-algorithm;用户问"怎么度过冷启动"→本skill。
- 与 `x-longtail-strategy` 的区别: longtail是心态(别赌单条爆,系统提高进前10%概率);本skill是行动(前24h主动加热突破初始池)。用户问"连发20条没爆该不该放弃"→longtail;用户问"新号怎么获取第一批粉丝"→本skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **漏斗诊断:定位丢在哪一步**
   - 逐一检查: (a) 推文有没有曝光?如果没有→推文没进流量池,用策略1大V评论区抢占借大V的曝光 (b) 有曝光但用户不展开/不完读?→内容Hook不够,优化首行3秒钩子(可转x-short-content-craft) (c) 展开了但不进Profile?→推文没有引导"看我主页"的钩子,加CTA (d) 进了Profile但不关注?→门面四要素没到位,转x-account-setup修门面
   - 完成标准: 明确定位丢在哪一步,并给出对应修复方向

2. **按边际回报排序选策略投时间**
   - 最高优先(投60%时间): 策略1大V评论区抢占——关注10个1w-10w中小V,开通知,5分钟内评论,模板=重述观点+补充经验,每天10条;策略5引用转发+深度观点——Quote大V推文+300字增量观点(与策略1同级)
   - 中优先(投30%时间): 策略2每日发推(每天1-3条,先跑起来不追求完美);策略6互动率优先(积极回复每条评论,主动@相关账号)
   - 低优先(投10%时间): 策略3互关社区(前3天快速获30-50粉,但每天≤15人防风控);策略4热门蹭流量(搜索+trending)
   - 完成标准: 给出符合用户时间预算的策略组合,标注每条策略的预期效果和执行量
   - 判停条件: 若用户账号未开蓝V,先建议开蓝V(转x-account-setup),否则评论会被折叠进垃圾区,策略1无效;若用户门面未装修,先修门面再谈获客

3. **前24h主动加热**
   - 每条推文发出后: (a) 前1小时盯反馈,零互动则主动找人帮忙转 (b) 找粉丝量比你大的人帮忙转(效果最明显,木马人起号帖28万曝光靠此) (c) 社群互相加热(付费增长群/互关社区成员帮转) (d) 自己在高流量帖下发高质量评论导流(回复曝光算自己曝光)
   - 完成标准: 每条推文都有明确的加热计划,不是"发完就不管"
   - 判停条件: 若帖子已过24h且零互动,判定已沉,不再投入加热,转入下一条内容生产

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **新号开业前准备阶段**——装修/蓝V/养号未完成时,应先用 `x-account-setup`。门面没装修好,冷启动漏斗第3步(进Profile看门面)必然流失,六策略效果打折。
- **已有稳定粉丝(500+)的日常内容运营**——日常选题/写推文/数据复盘属于 `x-short-content-craft` / `x-data-review`,不是冷启动问题。冷启动解决0→1,不解决1→N的持续增长。
- **被限流/封号后的排查与申诉**——应转 `x-account-pitfalls`。限流会导致帖子没人看,但根因是账号状态而非冷启动策略不对。
- **纯评论互动技巧咨询**——应转 `x-comment-engagement`。本skill把评论区抢占作为策略之一使用,不展开评论方法论(坎宁汉姆定律/A-B引战/Repost vs Quote等)。

### 作者在书中警告的失败模式

- **ce05 — 发完不管错过黄金窗口**: 帖子发出去后不跟进互动,错过前1-24h冷启动黄金窗口。前几小时如果安安静静,系统判定"没人感兴趣",帖子沉底。发完必须主动加热——这是冷启动与日常发帖最大的行为差异。
- **ce11 — 互关过度每天超15触发风控**: 每天互关超过15人,触发反作弊系统,账号被限流或打"互关机器人"标签。互关社区有用但必须控量,关注数不要远多于粉丝数(ce17)。
- **ce21 — 博弈算法的打法平台收紧后失效**: 互关+评论区抢占+社群加热本质是博弈当前算法,平台一旦收紧(打击互关、降权Quote、限制同质搬运),整套打法可能失效。真正可迁移的是内容能力本身,技巧是过渡手段不是长期战略。

### 作者的盲点 / 时代局限

- **幸存者偏差**: 木马人21天0→4200、向阳乔木被KOL推荐涨1w都是成功案例,缺对照组——同样用六策略但没起来的案例未展示。六策略是必要条件参考,不是充分条件保证。
- **时点数据**: "每天10条评论预期日涨5-15粉""互关≤15""前24h黄金窗口"等阈值是2024-2026的时点数据,平台反作弊会进化,具体数字会漂移。
- **博弈算法风险**: 六策略中互关/评论区抢占/社群加热本质是博弈算法,平台收紧后可能失效(ce21)。作者自己也说"刚起号阶段可以通过技巧过渡,但长期来看好内容才是硬道理"。

### 容易混淆的邻近方法论

- **冷启动 vs 养号**: 养号是发内容前的"安全期"(模拟真人浏览建立账号权重,控关注粉丝比),冷启动是发内容后的"加热期"(主动互动突破初始流量池)。时序不同,不可混用——养号期不能大量互动,冷启动期必须主动互动。
- **冷启动 vs 长尾心态**: 冷启动是"前24h主动加热突破零"的行动(解决0→1);长尾是"别赌单条爆,系统提高进前10%概率"的心态(管理1→N的预期)。二者互补:长尾心态让你不因单条没爆而放弃,冷启动行动让你在每条发布后都尽力加热。
