## I — 方法论骨架 (Interpretation)

对自杀、自伤、暴力等**可模仿的负面行为**，媒体/传播的戏剧化呈现会诱发**模仿传染**——这叫维特效应（社会学家菲利普斯统计：名人自杀报道后，社会自杀率显著上升，最高 +12%）。

机制：戏剧性案例给旁观者提供了"越轨行为的许可"与"可模仿的脚本"。一旦进入某个封闭/与世隔绝的社群（如密克罗尼西亚青少年、校园枪击后的模仿者），会形成长期的仪式化传染——不是外部犯罪潮，而是内部规则的自我复制。

应用边界（伦理）：报道/传播此类事件时，**方式决定传染强度**。避免提供可模仿脚本、不置于头版、附求助资源，是对"引爆点"负面流行的必要克制。

## A1 — 书中的应用 (Past Application)

### 案例 1: 菲利普斯统计（梦露效应）
- **问题**: 名人自杀是否影响公众？
- **方法论的使用**: 菲利普斯比对名人自杀新闻见报时间与社会自杀率。
- **结论**: 报道后自杀率显著上升，证明媒体提供"越轨许可"。
- **结果**: 确立维特效应的实证基础。

### 案例 2: 密克罗尼西亚青少年自杀潮
- **问题**: 为何一座岛出现长达 10 年的青少年模仿自杀？
- **方法论的使用**: 鲁宾斯坦研究：一起戏剧性三角恋自杀+葬礼，引发封闭青少年文化内的长期模仿。
- **结论**: 破坏性流行遵循传染逻辑，根植于社群内部规则。
- **结果**: 说明"与世隔绝社群"最易被仪式化传染。

### 案例 3: 校园枪击与可乐歇斯底里（后记）
- **问题**: 科伦拜恩后为何各地模仿枪击？比利时"可乐中毒"是什么？
- **方法论的使用**: 枪击是封闭青少年社群内部的仪式化模仿（非更大犯罪潮）；可乐事件是想象性威胁引发的集体身心反应（群体性歇斯底里）。
- **结论**: 同属"与世隔绝/传染"的流行逻辑。
- **结果**: 警示媒体对可模仿行为的渲染后果。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要 this skill?
1. 作为媒体/运营要报道一起自杀、自伤、暴力、事故。
2. 担心某个负面事件被模仿扩散（校园、社群、平台）。
3. 做危机公关，需遏制负面行为的二次传播。

### 语言信号 (用户的话里出现这些就应激活)
- "怎么报道自杀/事故才不引发模仿"
- "维特效应 / 媒体模仿"
- "担心被模仿 / copycat"
- "怎么遏制这种负面传染"
- "responsible reporting / Werther effect / copycat risk"

### 与相邻 skill 的区分
- 与 `fear-appeal`：fear-appeal 用恐惧推动**正向**行动（要配步骤）；werther-effect 是**负向**行为的传染风险，要克制渲染。
- 与 `broken-windows`：若负面流行靠"小失序信号"蔓延，用 broken-windows；若靠"媒体/故事模仿"，用本 skill。
- 与 `tipping-point`：本 skill 是"如何遏制一场负面流行"的专项。

## E — 可执行步骤 (Execution)

1. **评估可模仿性**
   - 完成标准: 判断该行为是否"具体、可操作、有戏剧性脚本"——越高危越要克制。
2. **去除可模仿脚本**
   - 完成标准: 不写具体方法/地点/时间线/遗书细节，不渲染英雄式叙事。
3. **降版面、加资源**
   - 完成标准: 不置头版/首页，文末附求助热线与积极资源。
4. **监测二次传播**
   - 完成标准: 跟踪评论区/转发是否形成模仿讨论，必要时限流。
   - 判停条件: 若已出现真实模仿事件，转危机公关流程并联动 broken-windows 修环境信号。

## B — 边界 (Boundary) ★

### 不要在以下情况使用 this skill
- 要推动正向健康行为——用 fear-appeal / stickiness-factor。
- 要正面信息传播——用 connectors / mavens。
- 纯学术讨论维特效应本身（可答，但不必整套流程）。

### 作者在书中警告的失败模式
- 把校园枪击误归为"更大犯罪潮"：实为与世隔绝社群内部传染，外部归因会开错药方。
- 渲染细节=提供可模仿脚本，直接放大传染。

### 作者的盲点 / 时代局限
- 书侧重"报道引发模仿"，对"平台算法主动放大负面"的机制着墨少；当代需叠加算法治理视角。

### 容易混淆的邻近方法论
- 与 fear-appeal 混淆：方向相反（一个克制负向传染，一个推动正向行动）。
