## I — 方法论骨架 (Interpretation)

推销员是"个别人物法则"的第三类关键人：靠**生物性的情绪传染**让他人行动——表情、姿态、能量的同步（镜像式模仿）让人"莫名被说服"，而非靠话术或逻辑。

判断要点：
- 说服力来自"能量外溢 + 可被模仿"，不是雄辩。
- 人会自动模仿对方表情/情绪（书中有表情模仿实验支撑），所以高能量者能"传染"决心。
- 在传播链里，联络员把信息送到、内行建立信任、**推销员负责最后让人动起来**。

应用：需要转化/动员时，把"呈现者/沟通者"换成高能量、易被情绪模仿的人，比堆话术更有效。

## A1 — 书中的应用 (Past Application)

### 案例 1: 汤姆·高的"超感染力"
- **问题**: 理解"为什么有些人一开口别人就愿意照做"。
- **方法论的使用**: 金融顾问汤姆·高被描述为典型推销员，和他交谈后对方莫名被说服；这源于表情/动作/情绪的同步，而非话术。
- **结论**: 推销员是可识别的一类人，其能力是生物性的情绪传染。
- **结果**: 印证"个别人物法则"第三类发动者真实存在。

### 案例 2: 旺德曼金盒子的互动式说服（隐含）
- **问题**: 直销广告如何让观众从"看"到"行动"。
- **方法论的使用**: 金盒子把观众变成互动广告的一部分，本质上制造了"参与即被说服"的体验。
- **结论**: 让对方参与/被情绪卷入，比单向灌输更能促成行动。
- **结果**: 回应率远超传统广告（见 stickiness-factor）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 销售/路演/融资需要临门一脚转化。
2. 动员团队或社群采取某个行动。
3. 沟通总"说得对但推不动"。

### 语言信号 (用户的话里出现这些就应激活)
- "怎么说服他 / 怎么让人答应"
- "临门一脚 / 成交 / 转化上不去"
- "怎么让人当场行动"
- "我的话没人听 / 推不动"
- "how to persuade / close / get them to act"

### 与相邻 skill 的区分
- 与 `connectors`：推销员负责"说服行动"，联络员负责"送达信息"；送达后不转化时转本 skill。
- 与 `mavens`：推销员靠情绪感染，内行靠信息准确；前期影响用 mavens，成交用 salesmen。
- 与 `stickiness-factor`：若问题是"记不住/没行动"源于信息包装，用 stickiness-factor；若源于"缺最后一推"，用 salesmen。

## E — 可执行步骤 (Execution)

1. **识别推销员型呈现者**
   - 完成标准: 找出"高能量、表情生动、易被对方模仿情绪"的人来承担关键沟通。
2. **设计可被情绪卷入的互动**
   - 完成标准: 用演示/现场体验/故事让人参与，而非只读稿。
3. **对齐非语言信号**
   - 完成标准: 检查语速/目光/姿态是否传递确定性与热情（可被模仿的能量）。
4. **在信任建立后施加临门一脚**
   - 完成标准: 先由 mavens/connectors 建立认知与信任，再由 salesmen 收口。
   - 判停条件: 若受众根本没收到信息（送达失败），先转 connectors；若不信内容，先转 mavens。

---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 信息还没送达/没人知道——先用 connectors。
- 内容本身不可信/不专业——先用 mavens 建信任。
- 纯信息查询或逻辑决策，不需要情绪推动。

### 作者在书中警告的失败模式
- 以为"好话术"=说服力：真正变量是情绪传染与可被模仿的能量。
- 跳过信任直接推销：没有 mavens/connectors 铺垫，推销员也推不动。

### 作者的盲点 / 时代局限
- 情绪传染在面对面最强；纯文字/异步沟通中推销员效应被削弱，需借助视频/直播等富媒介。

### 容易混淆的邻近方法论
- 与 stickiness-factor 混淆：一个解决"信息粘住"，一个解决"人被动起来"，常需配合。
