## I — 方法论骨架 (Interpretation)

联络员是"个别人物法则"的第一类关键人：**交友极广、且跨圈层**，能把互不相识的不同世界连成一张网。他们不是"地位高/有权"的人，而是"连接不同世界"的节点。

判断要点：
- 认识的人数量多且**分布在不同领域**（不是同一行业的熟人堆）。
- 有"把人介绍给彼此"的本能冲动（社会黏合剂）。
- 他们一旦传递信息，就有无数异质节点同时接收——这是口碑传播的真正发动机。

相关原理"弱关系"：带来新信息、新机会的，往往不是密友（强关系信息重叠），而是不太熟的人（弱关系 bridging 不同网络）。所以找传播突破口，优先激活联络员与弱关系。

## A1 — 书中的应用 (Past Application)

### 案例 1: 保罗·里维尔骑马夜行
- **问题**: 独立战争前需一夜间动员新英格兰民兵防备英军。
- **方法论的使用**: 信使里维尔是典型联络员，跨村镇熟人网络；另一信使道斯（非联络员）走同样路线却几乎无人响应。
- **结论**: 同一条信息，经联络员传播 vs 普通人传播，效果天差地别。
- **结果**: 里维尔成功点燃民兵网络，道斯路线基本无效。

### 案例 2: 罗杰·霍肖 / 洛伊丝·韦斯伯格
- **问题**: 理解"谁在真正驱动口头传播"。
- **方法论的使用**: 作者用"电话簿姓氏测试"量化社交广度；韦斯伯格能把政客、艺术家、商人、记者这些互不往来的世界连成网。
- **结论**: 联络员价值在"跨世界连接"而非"认识权贵"。
- **结果**: 印证联络员是流行潮发起者的核心。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 要 launch 新品/活动，预算少，想靠口碑而非广告。
2. 一条重要信息需要"破圈"传到陌生群体。
3. 想扩大自己/品牌的人脉辐射，却苦于圈层封闭。

### 语言信号 (用户的话里出现这些就应激活)
- "怎么让这个消息/产品传开"
- "预算有限，想靠口碑引爆"
- "找行业里认识人最多的人帮我推"
- "怎么触达我够不到的圈子"
- "who are the connectors / hubs I should target"

### 与相邻 skill 的区分
- 与 `mavens`：联络员"连人"（社交广），内行"供数据"（某领域专家、被信任）；找背书/专业建议用 mavens，找扩散网络用 connectors。
- 与 `salesmen`：联络员负责"把信息送达到"，推销员负责"让人行动上"（说服）；送达后不转化时转 salesmen。
- 与 `translator-role`：联络员连"人"，中转员译"信息/文化跨越边界"；跨陌生文化社群时转 translator-role。

## E — 可执行步骤 (Execution)

1. **列出目标网络的 hubs**
   - 完成标准: 写出 3–10 个"在目标人群里认识人极广、跨子圈子"的具体对象或角色。
2. **验证跨圈层属性**
   - 完成标准: 确认这些人连接的是异质子群体（非同一行业同温层）；必要时用弱关系思路找"不太熟但跨圈"的人。
3. **设计给联络员的"可转发载体"**
   - 完成标准: 提供具体、低门槛、值得分享的内容/样品/邀请，让联络员容易传递。
4. **先集中打动少数联络员**
   - 完成标准: 资源压到前几名 hubs 的体验/邀请上，而非广撒网。
   - 判停条件: 若目标群体本就在一个紧密圈内、不需要跨圈，则本 skill 收益低，考虑 stickiness-factor 或 salesmen。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 信息本身记不住、没附着力——找到联络员也白搭，先转 stickiness-factor。
- 只需专业背书而非广泛扩散——那是 mavens。
- 需要临门一脚说服转化——那是 salesmen。

### 作者在书中警告的失败模式
- 把"地位高的人"当联络员：联络员看跨圈层连接力，不是头衔。
- 误以为"覆盖大众"即可：真正发动者是极少数 hubs。

### 作者的盲点 / 时代局限
- 前社交媒体时代案例；如今"算法 hub / 超级 KOL"可能替代部分联络员功能，但弱关系 bridging 逻辑仍在。

### 容易混淆的邻近方法论
- 与 maven-trap（如何"钓出内行"）混淆：connectors 找广连接者，maven-trap 找隐藏专家，目标人物不同。
