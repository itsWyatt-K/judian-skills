## I — 方法论骨架 (Interpretation)

不诚实会传染，但**不是按频次传染，是按身份传染**。

这是本 skill 唯一但极重要的反直觉发现：看见有人作弊，你会不会跟着作弊，
取决于那个人**是不是你的同类**。

- 内群体成员公开作弊 → 旁观者作弊率**显著上升**。机制是重新校准了社会规范：
  "原来我们这种人是可以这么做的。"
- 外群体成员做同样的事 → 旁观者作弊率**反而下降**。机制是身份区隔：
  "那是他们才干的事，我们不一样。"

这条方向性差异推翻了三个常见的管理直觉：

1. **"用内部违规案例做警示教育"** —— 危险。你把一个内群体成员的作弊行为
   公开演示给了所有人。教育的意图是威慑，实际的效果是示范。
   反之，用**外部**丑闻做警示，是有效的（它触发的是区隔而非模仿）。

2. **"抓住害群之马，处罚了就好了"** —— 不够。处罚金额不改变已经完成的传播。
   真正需要的是**切断其内群体身份认同**——让组织清晰地把那个人识别为"不是我们这类人"，
   而不只是"犯了错的自己人"。

3. **"高管的小额违规无关紧要"** —— 恰恰相反。高层是最典型的内群体高可见成员，
   其小额违规的破坏力远超同等金额的外部欺诈。上行下效不是修辞，是实验结论。

治理的核心因此不是**惩罚强度**，而是**身份边界的管理**：谁被算作"我们"，
以及"我们"这类人做什么、不做什么。

## A1 — 书中的应用 (Past Application)

### 案例 1：卡内基梅隆的 T 恤实验

- **问题**：目睹他人作弊会让人更想作弊，还是更不想？
- **方法论的使用**：在卡内基梅隆大学做矩阵作弊测试。安排一名演员在开始后不久
  就大摇大摆地站起来宣称自己全部做对、领走全额奖金后离场——公然且不可能真实的作弊。
  两个条件的唯一差别是这名演员穿的 T 恤：一件印卡内基梅隆（本校，内群体），
  一件印匹兹堡大学（对手校，外群体）。
- **结论**：若传染只与"看见作弊"有关，两个条件应当结果相同。
- **结果**：内群体条件下，其他学生的作弊显著**上升**；
  外群体条件下，作弊反而**下降**。同一行为，身份不同，方向相反。

### 案例 2：不诚实的渐进感染

- **问题**：为什么一个组织会从"个别人越界"演变成"大家都这样"？
- **方法论的使用**：艾瑞里把它类比为病毒——每一次目睹内群体的不道德行为，
  都把观察者对"什么是可接受的"的判断稍微推移一点。
- **结论**：单次移动很小，本人不会察觉；但多次叠加会重设整个群体的规范基线，
  而重设之后，这个基线本身又成为新人加入时的标准。
- **结果**：解释了为什么某些行业的灰色操作能在从业者主观上"完全不觉得有问题"的状态下
  长期存在——他们的基线已经被集体移动过了。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **一个人带头之后一片跟进**：某销售开始虚报，半年后整个团队都在虚报。
2. **要做警示教育**，纠结用内部案例还是外部案例、要不要点名通报。
3. **高管/骨干出现小额违规**，想评估真实代价并决定处理力度。
4. **"这是行业惯例"**：整个行业的灰色操作，想判断能否在自己组织内切断。
5. **社区/游戏/平台的作弊成风**，想知道公示与封禁该怎么设计。
6. **新人入职后迅速被同化**，怀疑规范基线已经被集体移动。
7. **并购或团队合并后风气变化**，两个群体的身份边界正在重组。

### 语言信号

- "一个人带坏了一群人"
- "大家都这么干，法不责众"
- "这是行业惯例，我们不做就吃亏"
- "要不要开会通报一下这个案例"
- "新人来了两个月就学会了"
- "上梁不正下梁歪"
- "everyone does it / bad apple / culture of cheating / should we make an example of him"

### 与相邻 skill 的区分

- 与 `fudge-factor-integrity`：那个处理**个体**为什么会在能自认为好人的范围内小骗，
  杠杆是合理化空间与心理距离；本 skill 处理**群体间的传播**，杠杆是身份边界。
  二者常需组合：先用那个收窄个体空间，再用本 skill 切断传播路径。
- 与 `social-market-norm-switch`：那个关注"标价会不会摧毁社会规范"；
  本 skill 关注"社会规范的内容本身被谁重设了"。
- 与 `manipulation-matrix-ethics`：那是产品伦理自查，不涉及组织内传播。
- 与 `meaning-recognition-motivation`：那处理动机与认可，与诚信治理无直接关系，
  但组织文化议题上容易被混用——若诉求是"团队没干劲"而非"团队在违规"，用那个。

## E — 可执行步骤 (Execution)

1. **确认这是传染，不是并发**
   - 检查：违规是否有**时间上的先后与扩散路径**？能否指出最早的可见案例
     以及后续跟进者与他的关系（同组、同级、同期入职、共同社交圈）？
   - 若各违规彼此独立、无共同源头 → 是个体合理化问题，转 `fudge-factor-integrity`。
   - 完成标准：画出扩散时间线与关系链，或明确否定传染假设。

2. **界定群体边界：谁被算作"我们"**
   - 关键不是组织架构图，而是**当事人主观的身份认同圈**：
     同一职能？同一届？同一个城市办公室？同一个微信群？同样的从业年限？
   - 完成标准：写出 2–3 个真实运作的身份圈，并标出违规源头位于哪个圈内。

3. **评估高可见成员的示范权重**
   - 列出该身份圈中"最被看见的人"（管理者、明星员工、老资格、群里最活跃的人）。
   - 若违规源头是其中之一 → **优先级最高**，其小额违规的传播成本远超金额本身。
   - 完成标准：明确标出源头的可见度等级，并据此定处理优先级。

4. **执行身份区隔，而非单纯处罚（核心动作）**
   - 目标不是让人怕，是让人**不认为那个人是自己的同类**。
   - 有效动作：
     - 在沟通中明确表述"**我们这类人不这么做**"，而不是"这么做会被罚"；
     - 让处理结果与**身份变化**挂钩（退出核心圈、取消代表资格），而不只是罚款；
     - 由**同一身份圈内受尊敬的成员**表态，而非只由 HR/合规部门发文
       （合规部门是外群体，其表态对圈内规范的影响力弱）。
   - 完成标准：处理方案中含身份层面的动作，而不只是金额与处分。

5. **重新设计警示教育的素材来源**
   - **禁止**：把本组织、本团队的违规案例做成公开演示（等于示范）。
   - **推荐**：使用**外部**（竞对、其他行业、其他国家）的丑闻案例，
     配合"我们和他们不一样"的区隔叙事。
   - 若必须处理内部案例：不做行为细节的公开复述，只公布身份层面的后果。
   - 完成标准：警示材料的案例来源被明确为外部，或内部案例的行为细节已被剥离。

6. **切断"行业惯例"的引用链**
   - 当组织内出现"同行都这么干"的辩护时，这是外群体被误认成内群体的信号。
   - 动作：主动把同行**重新框定为外群体**（"他们是那种公司，我们不是"），
     并给出本组织独有的身份叙事。
   - 完成标准：有一句可被员工复述的、区分自己与同行的身份表述。

7. **监测基线漂移**
   - 定期问新人：**你入职以来，看到过什么让你当时觉得不太对、现在已经习惯的事？**
     新人是唯一还能看见基线的人，入职 3–6 个月后这个窗口就关闭了。
   - 完成标准：建立一个针对入职 1–3 个月员工的定期询问机制。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **蓄意的、有组织的欺诈团伙**：那不是规范漂移，是共谋，需要法律与审计手段。
- **身份区隔会演变成排挤或歧视**：本 skill 的"切断内群体认同"针对的是**行为**，
  绝不能滑向对个人特征（地域、性别、学历、出身）的标签化。
  一旦方案中出现按人群特征划线，立即停止。
- **只有一次孤立事件且无扩散迹象**：过度反应本身会把一件小事升格为群体事件，
  反而提高其可见度。
- **组织正在经历合法的规范变革**（如新合规要求落地）：此时的"大家都还没适应"
  是执行问题，不是传染。

### 作者在书中警告的失败模式

- **用内部案例做警示教育 = 公开示范**。这是本 skill 最重要、也最反直觉的一条。
  通报批评在提高威慑的同时，也向所有人展示了"我们这类人里有人这么做"。
- **只处罚不区隔**：罚款与处分改变不了已经完成的规范移动。
  被罚的人如果仍被视为"自己人，只是运气不好被抓了"，传播不会停止。
- **低估高层小额违规**：领导报销一顿超标的饭，其传播代价可能高于一笔大额外部欺诈。
- **知道不等于免疫**：告诉员工"你们会被同事影响"，不会减少影响。
  干预必须落在身份叙事与结构上。

### 作者的盲点 / 时代局限

- ⚠️ **本书证据基础存在重大可靠性风险**：艾瑞里团队的部分不诚实研究已卷入
  数据造假争议（签名前置实验已撤稿，详见 `fudge-factor-integrity` B 段）。
  T 恤实验的**方向性结论**（内群体上升、外群体下降）与社会认同理论、
  社会规范理论的大量独立文献一致，因此本 skill 保留其方向而不引用精确效应量。
- T 恤实验的群体身份是大学校际对立——一种极其鲜明、低成本、无利益冲突的身份。
  真实组织中的身份边界更模糊、更多重（既是本部门的人，也是公司的人，也是行业的人），
  外推时需要第 2 步的实证界定。
- 全书写于社交媒体与远程办公普及之前。今天的"内群体"很大程度上由线上社群构成，
  可见度机制与线下不同，书中无对应讨论。
- 书中未讨论**正向传染**（诚实行为是否同样按身份传播）。理论上应当对称，
  但缺少实验支持，本 skill 未据此给出建议。

### 容易混淆的邻近方法论

- **破窗理论**：环境失序线索→犯罪上升。与本 skill 相似之处是"信号改变规范"，
  但破窗不区分信号发出者的身份，而身份恰恰是本 skill 的核心变量。
- **社会证明（影响力）**：那说明"多数人怎么做"会影响个体，
  本 skill 补充了关键限定——**是"我这类人"怎么做，而不是"多数人"怎么做**。
- **一颗老鼠屎理论（Bad Apple）**：那假定移除个体即可解决；
  本 skill 指出移除不够，还需切断身份认同并修复已漂移的基线。
