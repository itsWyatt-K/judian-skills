## I — 方法论骨架 (Interpretation)

人类的交换有两套彼此不兼容的操作系统。

**社会规范**：不即时结算、不明码标价、以互惠与身份维系。帮朋友搬家、深夜替同事顶班、
给社区写开源代码。它的回报是模糊的、延迟的、有时永不兑现的，而这恰恰是它的力量所在——
因为没有价格，投入就没有上限。

**市场规范**：明码标价、即时对等、以成本收益衡量。它高效、清晰、可扩展，但投入严格封顶在
"我付了多少钱"的水平上。

关键结论有三条：

1. **两套规范不能混用。** 一旦为一段社会规范关系标了价，它就切换成了市场规范。
2. **切换是单向的。** 移除价格后，社会规范不会自动回来——愧疚一旦被交易赎买过一次，
   就很难重新长出来。
3. **市场规范的价格上限往往低于社会规范的自愿投入。** 所以标价常常是**降级**：
   你用一笔小钱，买断了一份原本无价的投入。

判据只有一条：**这段关系是否依赖"不即时结算的互惠"？** 是 → 绝不能付钱，
应给礼物、认可、意义或身份。礼物之所以有效，正因为它不报价——一旦你说出"这瓶酒 500 块"，
它立刻变回市场规范。

## A1 — 书中的应用 (Past Application)

### 案例 1：以色列托儿所的迟到罚款

- **问题**：家长接孩子经常迟到，老师被迫加班。托儿所决定对迟到征收小额罚款。
- **方法论的使用**：罚款给"迟到"这件事标了价。原本家长迟到时的心理活动是
  "我让老师为难了"（社会规范），标价后变成"我付费购买了额外看护时间"（市场规范）。
- **结论**：一旦愧疚可以被赎买，且价格便宜，理性的选择就是多买。
- **结果**：迟到人数**上升**。更严重的是，托儿所随后取消罚款，迟到率仍然居高不下——
  社会规范被挤走后没有回来。

### 案例 2：岳母的感恩节晚餐

- **问题**：艾瑞里设想在丰盛的家宴结束后，起身称赞厨艺，然后掏出钱包问"这顿饭值多少钱？
  300 够吗？400 怎么样？"
- **方法论的使用**：这是一个纯粹的思想实验，用来暴露两套规范的不可混用。
  从市场规范看，付钱是对劳动的公允补偿，甚至慷慨。
- **结论**：但在社会规范下，掏钱这个动作本身即是侮辱——它宣告这段关系可以被结算清零。
- **结果**：关系被摧毁，且无法通过"我不是那个意思"修复。

### 案例 3：律师与退休者协会

- **问题**：美国退休人员协会请律师以每小时 30 美元的**折扣价**为贫困退休者服务，律师们拒绝了。
- **方法论的使用**：换一种问法——能否**免费**为贫困退休者提供服务？
- **结论**：30 美元/小时把请求放进了市场规范（对律师而言这是极差的交易）；
  "免费"则把它放进社会规范（这是一件值得做的好事）。
- **结果**：绝大多数律师同意了免费方案。价格从 30 降到 0，参与率反而大幅上升。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **要不要给志愿者/社群成员发钱或补贴**，担心不发不公平、发了又变味。
2. **打算用罚款纠正行为**：迟到、爽约、逾期归还、群里发广告。
3. **发了钱之后反而更差**：给了加班费之后没人自愿加班了；给了推荐奖金之后推荐质量下降。
4. **亲友帮忙后要不要给报酬**，以及给什么形式。
5. **组织内部要不要引入结算**：部门间调用资源开始收内部服务费，跨组协作开始记工时。
6. **员工"只做份内事"**：想知道为什么加薪没有换来主动性。

### 语言信号

- "要不要给他们发点钱/补贴"
- "我们设个罚款吧"
- "自从发了钱，反而没人主动做了"
- "朋友帮了大忙，给钱是不是不太好"
- "员工只做份内的，多一点都不肯"
- "should we pay volunteers / add a late fee / why did the bonus backfire"

### 与相邻 skill 的区分

- 与 `zero-price-transaction-utility`：那个处理**产品对外**收不收费的转化与珍惜度问题
  （交易层）；本 skill 处理**关系性质**会不会被标价永久改变（关系层）。
- 与 `incentive-inverted-u`：那个假定已在市场规范内，只讨论金额高低对认知任务的影响；
  本 skill 讨论**该不该进入市场规范**这个前置问题。
- 与 `meaning-recognition-motivation`：那个是社会规范内的具体工具（认可、可见性、意义）；
  本 skill 是判断该用哪套规范的**分诊层**。判定为社会规范后，通常应转入该 skill 取具体动作。
- 与 `ultimatum-fairness-leverage`：那个是价格变动已引发公开愤怒后的灭火；
  本 skill 是标价之前的预防。

## E — 可执行步骤 (Execution)

1. **判定当前关系运行在哪套规范上**
   - 检查三个特征：①回报是否延迟且模糊？②参与者是否会说"这是应该的"？
     ③有没有人明确谈过价格？
   - 三项中命中两项以上 → 社会规范。
   - 完成标准：给出明确判定，并指出判据。

2. **如果是社会规范，先算"标价的不可逆成本"**
   - 问：如果这套付费/罚款机制推行半年后效果不好，撤销它，行为会回到今天的水平吗？
   - 参照托儿所结论：**默认答案是"不会"**。把这条写进方案的风险栏。
   - 完成标准：不可逆成本被显式写出，而不是被假设为零。

3. **优先寻找非货币替代物（按强度排序）**
   - ①**认可与可见性**：署名、公开致谢、在成果上留下名字（成本最低，效果被实验反复验证）。
   - ②**礼物**：实物或体验，**绝不透露价格**。一旦标价即失效。
   - ③**身份与归属**：内测资格、核心成员标识、决策参与权。
   - ④**意义叙事**：让贡献者看见自己的产出被谁用了、改变了什么。
   - 完成标准：至少给出两个具体可执行的非货币方案。

4. **如果必须付钱，做干净的切换而不是混合**
   - 混合最糟：既谈感情又谈钱，两套规范互相污染。
   - 干净切换的三条要求：①明确宣布关系性质变了（转为正式合作/雇佣）；
     ②价格给到市场公允水平以上（廉价的市场规范比社会规范差得多，见律师案例）；
     ③把社会性内容单独保留在不涉及结算的场合。
   - 完成标准：方案里不存在"象征性给一点"这种最差解。

5. **若目标是纠正不良行为，用非价格信号替代罚款**
   - 可选：公示（不点名的统计）、事后补偿性劳动、当面告知影响、默认值调整、
     或增加一个决策停顿点（见 `ulysses-self-control-architecture`）。
   - 完成标准：方案不含"小额罚款"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **本来就是纯商业关系**：供应商、外包、标准雇佣。这里没有社会规范可保护，
  谈钱是唯一诚实的做法，硬套"给认可不给钱"是剥削。
- **金额足以改变对方生活**：对经济困难的参与者谈"给认可不给钱"是残忍且伪善的。
  规范判断不能凌驾于基本报酬公平之上。
- **法律与安全要求必须有惩戒**：合规、安全生产、金融风控中的罚则有威慑与追责的独立功能，
  不能仅因"会挤出社会规范"就取消。

### 作者在书中警告的失败模式

- **罚款让行为变得更糟且不可逆**（托儿所实验）：标价把愧疚换成了交易，且取消价格后
  愧疚不会回来。这是本 skill 最重要的一条警告。
- **廉价的市场规范比社会规范糟得多**：30 美元/小时被拒绝，免费被接受。
  如果给不起市场公允价，宁可完全不给。
- **知道这个道理并不能免疫**：艾瑞里指出，即便清楚两套规范的区别，
  人在设计激励时仍会本能地"加一点钱"。因此本 skill 的输出必须是一份**方案改写**，
  而不是一句提醒。

### 作者的盲点 / 时代局限

- 托儿所实验样本量有限（以色列 10 家托儿所），效应方向被广泛接受，
  但具体幅度不宜外推。
- 书中对"什么金额算公允"缺少操作定义，而这恰恰是实践中最难的一环——
  本 skill 的第 4 步只能给方向，无法给数字。
- 讨论集中在西方组织与家庭场景。在人情与结算高度交织的文化中（如中式职场的
  "帮忙"与"欠人情"），两套规范的边界更模糊，判定需要更多本地证据。
- 零工经济、创作者经济、开源商业化等混合形态（同时依赖热情与收入）在书中几乎未被讨论，
  这是本 skill 最需要谨慎外推的领域。

### 容易混淆的邻近方法论

- **过度理由效应 / 内在动机挤出**：机制高度相关（外部奖励削弱内在动机），
  但那关注**个体动机来源**；本 skill 关注**关系的规范性质**，且强调不可逆性。
- **互惠原理（影响力）**：那是利用互惠促成顺从的说服技术；
  本 skill 是保护互惠不被货币化的防守视角。
