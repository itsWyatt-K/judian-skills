## I — 方法论骨架 (Interpretation)

面对两拨人互相敌视，几乎所有人的第一反应都是"让他们多接触、多沟通、多了解"。这条直觉叫**接触假说**，它是错的——更准确地说，它漏掉了唯一起决定作用的那个变量。

作者给出的是完整的条件化公式：

- 接触 + **竞争结构** = 敌意加深
- 接触 + **共同目标与相互依赖** = 好感产生

关键在于**结构**，不在**频次**。所谓结构，指的是一件具体的事：**双方的成果是否绑在同一个指标上，以及一方能否在缺少另一方的情况下完成自己的部分**。

- 如果 A 部门达成目标不需要 B，甚至 A 的成功以 B 的资源为代价，那么每一次接触都在提供新的摩擦证据。
- 如果 A 必须拿到 B 的中间产物才能推进，且两人被同一个结果计分，接触才会转化成好感。

这套判据来自谢里夫的强盗洞营地实验：两组男孩先被人为造成竞争，随后研究者**增加接触**（一起吃饭、一起看电影）——结果不是和解，是食物大战。真正扭转局面的是一系列**必须两组合力才能解决**的困境（供水管道故障、卡车抛锚需要一起拉）。

阿伦森的拼图教室把这个结构做成了可复制的教学法：把学习材料切成若干块，每个学生只拿到其中一块，考试考全部内容——于是每个人**必须**从别人那里获取自己缺的部分。种族偏见与学业成绩同时改善。

一句话判据：**改结构，不是加频次。** 团建、破冰、面对面沟通全都只是"频次"，它们在竞争结构下无效甚至有害。

## A1 — 书中的应用 (Past Application)

### 案例 1: 谢里夫的强盗洞夏令营

- **问题**：两组素不相识的男孩被人为制造出敌意后，如何让他们和解？
- **方法论的使用**：第一阶段用竞赛制造对立（成功）。第二阶段尝试**增加愉快的接触**——一起吃饭、一起看电影、一起放烟花。第三阶段改为设置只有两组合作才能解决的问题：营地供水系统故障需要多人沿管线排查；运送食物的卡车抛锚，需要所有男孩一起用绳子把它拉动。
- **结论**：第二阶段是接触假说的直接检验，结果证伪。
- **结果**：第二阶段的接触**升级为食物大战与互相辱骂**；第三阶段之后，跨组友谊显著增加，敌对称呼消失。

### 案例 2: 美国校园种族融合的追踪研究

- **问题**：取消种族隔离、让不同族裔学生同班，能否减少偏见？
- **方法论的使用**：对融合后的学校进行大规模追踪，测量族裔间的态度变化。
- **结论**：课堂是典型的**竞争结构**——评分曲线、举手抢答、排名，使接触发生在互相争夺稀缺认可的条件下。
- **结果**：作者引用的研究显示，单纯的同班并未普遍减少偏见，**部分情形下反而加剧**。这是接触假说在真实社会尺度上的失败。

### 案例 3: 阿伦森的拼图教室

- **问题**：如何在同一间教室里把竞争结构改成合作结构？
- **方法论的使用**：把当天的学习材料分成 6 份，6 人小组里每人只拿到 1 份，必须向组内其他人讲述自己那份，也必须听别人的才能掌握全部；考试考全部内容。
- **结论**：这就是"相互依赖 + 成果共享"的最小实现——每个人都成为别人的必需品。
- **结果**：跨族裔的喜欢程度上升，少数族裔学生成绩提高，且效果在多所学校复现。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 销售与技术、产品与研发、运营与客服互相甩锅。
2. 团队内部小圈子分化、新老员工对立。
3. 并购或重组后两支队伍融合不良。
4. HR 打算用团建/破冰/沟通培训解决对立（本 skill 常用于**否决**这类方案）。
5. 家庭或班级中两个孩子长期争执。
6. 合作方之间互相防备、信息不共享。
7. 设计新组织架构或考核指标时，预判会不会造出对立。

### 语言信号 (用户的话里出现这些就应激活)

- "两个部门互相甩锅 / 谁也不服谁"
- "要不要搞个团建 / 组织一次面对面沟通"
- "多接触多了解就好了"
- "跨部门壁垒 / 各自为政"
- "他们俩合不来 / 一见面就吵"
- "team building / silo / cross-functional conflict / break the ice"

### 与相邻 skill 的区分

- 与 `liking-paths` 的区别：**先后关系**。本 skill 处理的是**结构性对立**（有竞争、有利益冲突）；`liking-paths` 处理的是**单条关系好感不足**（无对立，只是不熟）。诊断一问："他们之间有没有争夺同一份稀缺资源/认可/预算？"有 → 本 skill；无 → `liking-paths`。
- 与 `single-point-help` 的区别：那处理"人多但没人动"（无对立，是责任分散）；本 skill 处理"人有动但互相拆台"。
- 与 `social-proof-conditions` 的区别：那利用群体行为作为信息；本 skill 改造群体的**激励结构**，不涉及信息传递。
- 与既有 skill `nih-co-creation-buyin` 的区别：那解决"我的方案对方不接受"（单向推动）；本 skill 解决"双方互相敌视"（双向结构）。若对立表现为一方否定另一方的方案，两者可叠加。

## E — 可执行步骤 (Execution)

1. **判定是不是结构问题**：问三句——(a) 双方是否在争夺同一份稀缺资源（预算、名额、话语权）？(b) 一方达成目标是否会让另一方更难达成？(c) 两边的考核指标是不是不同甚至冲突？
   - 完成标准：三问各有明确答案。
   - 任一为"是" → 确认为竞争结构，继续；三个都是"否" → 转 `liking-paths`。

2. **否决纯频次方案**：明确写出"团建/破冰/多开会"在当前结构下的预期效果——无效或负效（并说明谢里夫第二阶段的证据）。
   - 完成标准：给出一句可以对上级说明的否决理由。
   - 注意：这一步的价值往往高于后面所有步骤——它避免了一次昂贵且反效果的干预。

3. **找一个真实的共同目标**：必须是**双方都真的在乎**、且**单靠一方无法达成**的结果。宁可小而真实，不要大而空洞（"公司发展"不算）。
   - 完成标准：目标可被量化，且能说明为什么单方做不到。
   - 反例：一起爬山、一起吃饭、一起喊口号。
   - 正例：共同承包一个客户从签单到回款的全流程。

4. **绑定同一个指标**：把考核从各自的局部指标（签单量 / 上线数）改为同一个结果指标（回款 / 客户续约）。
   - 完成标准：至少有一项奖金或评价挂在共同指标上。
   - 若无权改考核 → 至少让两边的汇报合并成一份，由同一个人评价。

5. **造出拼图式的相互依赖**：设计流程，使 A 的中间产物是 B 的必要输入，反之亦然。让"绕过对方"在物理上不可能。
   - 完成标准：能画出一条双向依赖的流程线。

6. **确保成果共享与共同署名**：胜利必须是"我们的"，不能是"某一方的"。公开表彰时两边同时出现。
   - 完成标准：存在一次双方共同署名的交付或公开肯定。

7. **从小规模开始并验证**：先用一个低风险的真实任务跑通，观察互动质量变化，再扩大。
   - 完成标准：一次完整的合作周期与一次复盘。
   - 判停条件：若合作**失败**，敌意会被加剧（见 B 段）——因此第一个任务必须选**成功概率高**的。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **合作失败风险高**：谢里夫的救援之所以奏效，是因为每次协作**都成功了**。一次失败的强制合作会让双方获得新的甩锅证据，比不合作更糟。第一个任务必须几乎稳赢。
- **对立源于真实的利益不可调和**（真在抢同一个岗位、同一笔预算的零和分配）：结构改不动时，本 skill 无解，需要的是决策与切割，不是合作。
- **一方存在实质性过错未处理**（欺凌、违规、损害）：先处理是非，合作不能替代问责，否则受害方会被二次伤害。
- **对方明确抵触被安排**：强推合作会触发逆反，先看 `scarcity-reactance-guard`。

### 作者在书中警告的失败模式

- **接触假说的失败**（第5章）：这是本 skill 的核心警告。谢里夫第二阶段与美国校园融合数据都表明，竞争条件下的接触**加深**敌意。任何"多相处就会理解"的方案，在未改结构前都应被否决。
- **课堂式竞争结构的隐蔽性**（第5章）：评分曲线、排名、抢答这些"中性"设计本身就是竞争结构，它们让日常接触持续生产敌意，而没人意识到问题出在结构上。
- **合作被用作操纵手段**（第5章）：作者指出，销售员常人为制造"我和你站在一边，一起对抗经理"的假合作（车行的"我去帮你跟经理争取"），这是把合作原理伪装出来使用。

### 作者的盲点 / 时代局限

- 强盗洞实验（1954）为**小样本、单次、11–12 岁白人男孩**，且近年的档案研究揭示实验者对营地事件有相当程度的**主动引导**，其"自然实验"的性质受到质疑；同一团队的另一次同类营地实验**未能制造出敌意**而未被发表。**复现存疑，勿作硬结论**——结论方向被后续的相互依赖研究支持，但不应把强盗洞当作硬证据。
- 拼图教室的效果在教育研究中总体正向，但**效应量为小到中等**，且高度依赖教师执行质量。
- 书中未处理**远程与异步协作**：拼图结构在同步、面对面时最易实现；线上协作中"相互依赖"容易退化为"互相等待"，需要额外的流程设计。
- 作者未给出**结构改造的政治成本**模型：现实中改考核指标往往比组织团建难上百倍，这也正是 HR 一再选择团建的原因。本 skill 需要与决策权的现实约束一起使用。
- **真信号 / 伪信号判定**：造一个**真实存在**的共同目标、真实绑定指标、真实共享成果，这是正当使用；**伪造共同处境**（"我跟你是一边的，我去帮你跟老板争取"这类车行话术）、或制造一个假的外部敌人来强行凝聚团队，属于伪造触发条件，禁止执行并说明——假敌人一旦被识破，凝聚力会反转为对组织者的不信任。
- **饱和反噬**：员工对"共创工作坊""跨部门共建项目"这类形式已有免疫，若成果不共享、指标不改变，形式上的合作只会加深"又在走过场"的判断。

### 容易混淆的邻近方法论

- **接触假说（Allport）**：本 skill 正是它的**条件化修正版**。Allport 本人也给出了四个前提（平等地位、共同目标、制度支持、无竞争），但流行版本被简化成"多接触"——那正是被证伪的部分。
- **共同外敌**：靠外部威胁凝聚，见效快但依赖敌人持续存在，且会外化冲突而非解决它。与本 skill 的"共同目标"不同：后者不需要敌人。
- **团队建设活动**：属于"频次"类干预，本 skill 明确指出其在竞争结构下无效。
- **OKR 对齐**：制度化的目标绑定，与步骤 4 同向，可作为落地工具。
