## I — 方法论骨架 (Interpretation)

动机不是由报酬水平决定的，而是由一个极小的信号决定的：
**我的产出，是否被承认存在过？**

这个信号小到可以是"交上去后有人看了一眼并签了个名"。它不需要表扬，
不需要奖励，甚至不需要评价——只需要**证明它没有立刻消失**。

艾瑞里的乐高实验把这条轴的两端都测了出来：

- **被保留**条件：组装好的作品被收走保存 → 平均组装 **10.6 个**后停止。
- **西西弗斯**条件：组装好的作品**当着参与者的面被拆散**、零件放回去重用 → 平均 **7.2 个**。

金钱报酬完全相同，唯一差别是产出的去向。同样的机制在另一组"折纸/找字母"实验中重复出现：

| 条件 | 处理方式 | 产出 |
|---|---|---|
| **认可** | 交上去，有人看一眼、点头、签名 | 最高 |
| **忽视** | 交上去，直接堆在一边不看 | 中等 |
| **摧毁** | 交上去，当面送进碎纸机 | 最低 |

**关键结论：忽视比认可差，摧毁比忽视差得多。**
"被看一眼"与"被忽视"之间的落差，几乎相当于给对方涨了一大笔钱的效果，成本却是零。

由此得到本 skill 的操作核心——不是"如何激励"，而是**"停止摧毁"**。
大多数组织的动机问题不是缺乏激励，而是在系统性地执行西西弗斯条件：
需求做完就被砍、方案汇报完再无下文、代码合进去无人使用、
报表每周提交从没人读、项目上线三个月被下线且无人告知。

## A1 — 书中的应用 (Past Application)

### 案例 1：乐高比奥尼克（Bionicle）实验

- **问题**：报酬相同的情况下，产出的去向会不会改变劳动意愿？
- **方法论的使用**：请参与者组装乐高机器人，每组装一个获得递减的报酬
  （第一个 2 美元、第二个 1.89 美元……），随时可以停止。
  两个条件：**保留组**——完成品被放在桌上；
  **西西弗斯组**——参与者在组装下一个时，研究员当着他的面把上一个拆散、零件放回盒子。
- **结论**：若人是按边际收益决定何时停手，两组应在同一报酬点停止。
- **结果**：保留组平均组装 10.6 个，西西弗斯组只有 7.2 个。
  更值得注意的是：**热爱乐高的人在保留组表现最好，但在西西弗斯组，
  这种热爱带来的优势完全消失了**——摧毁不仅降低产出，还抹平了内在兴趣的作用。

### 案例 2：找字母任务的三条件

- **问题**：认可需要多强？表扬？评价？还是只要被看见？
- **方法论的使用**：参与者在纸上找出重复字母对，交给研究员。
  条件 A：研究员看一眼、点头、放进一摞（**认可**）；
  条件 B：研究员不看，直接放进一摞（**忽视**）；
  条件 C：研究员不看，直接放进碎纸机（**摧毁**）。同样报酬递减、随时可停。
- **结论**：如果只有报酬起作用，三组应无差别。
- **结果**：认可组坚持最久，忽视组次之，碎纸机组最快放弃。
  **区分"认可"与"忽视"的动作，仅仅是看一眼并点头。**

### 案例 3：碎纸机条件下的作弊反转

- **问题**：碎纸机条件除了打击动机，还有什么效应？
- **方法论的使用**：在碎纸机条件下，参与者知道没人会检查他的答卷。
- **结论**：无人核验既降低了意义感，也移除了被核查的可能。
- **结果**：碎纸机组的产出报告出现了更多不实——
  **摧毁产出的同时也摧毁了诚实的理由**。这条把本 skill 与
  `fudge-factor-integrity` 连了起来：无意义的工作会同时降低投入与诚信。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **团队士气下滑但薪酬没问题**，说不出具体原因。
2. **项目被砍/需求被推翻后**，团队明显缓不过来。
3. **远程或分布式团队**成员感到自己的工作"消失在系统里"。
4. **执行层看不到成果的去向**：写的报告没人读、做的功能没人用、
   提的建议没有回音。
5. **开源/社群/志愿者贡献者流失**，且不能用钱留人。
6. **重复性工作**（客服、审核、数据处理）的意义感缺失。
7. **加薪留不住人**：钱给到位了，人还是走。
8. **家庭与教育场景**：孩子做的东西被随手丢掉、家务劳动无人察觉。

### 语言信号

- "团队最近没什么劲"
- "做了半天，最后也没人看"
- "又白干了 / 项目又黄了"
- "加薪也留不住人"
- "远程之后大家都没归属感"
- "我不知道我做的东西有什么用"
- "team morale / no one uses what I build / why bother / recognition"

### 与相邻 skill 的区分

- 与 `incentive-inverted-u`：那个处理**钱给多少**；本 skill 处理**钱之外的杠杆**。
  典型顺序：先用那个把奖金做稳，把省下的预算与注意力转到本 skill。
- 与 `social-market-norm-switch`：那个判断**该用哪套规范**；
  本 skill 是判定为社会规范后的**具体工具箱**。若还在纠结"要不要发钱"，先用那个。
- 与 `ability-simplification` / `bmat-behavior-diagnosis`：
  若人是**做不到**（流程太麻烦、不知道怎么做）而非**不想做**，
  用那两个，本 skill 无效。分诊在前。
- 与 `nih-co-creation-buyin`：那个让对方**参与生成方案**以获得认同（说服场景）；
  本 skill 让对方**看见自己产出的去向**（持续动机场景）。
- 与 `variable-reward-design`：那是产品给用户的酬赏机制（不可预测性）；
  本 skill 是组织给成员的意义信号（可见性），不可混用。

## E — 可执行步骤 (Execution)

1. **先做西西弗斯审计（最重要的一步）**
   - 不要先想"加什么激励"，先找**正在摧毁产出的地方**：
     - 有哪些交付物提交后从未被打开？（周报、日报、复盘文档、需求文档）
     - 有哪些工作成果被反复推翻或砍掉，且**没有人告知原因**？
     - 有哪些功能上线后无人使用，团队也从不知道使用数据？
     - 有哪些提案石沉大海，提出者至今没收到任何回复？
   - 完成标准：列出 3–5 条正在执行的西西弗斯条件，按人数×频率排序。

2. **停止摧毁，优先于增加激励**
   - 对第 1 步清单逐项处理，优先级高于任何新激励方案：
     - 没人读的报告 → **取消它**（取消比继续要求提交更能恢复动机）；
     - 被砍的项目 → 必须**当面说明原因**，并说清其中哪些部分被保留/复用了；
     - 无人使用的产出 → 把使用数据回传给做的人，哪怕数字很难看。
   - 完成标准：清单中每一项都有"取消"或"回传"的处置。

3. **把"忽视"升级为"认可"（零成本动作）**
   - 认可不需要表扬，只需要**证明被看见**：
     - 在成果上留下**做的人的名字**（文档署名、提交记录、发布说明致谢）；
     - 收到交付时给一句**具体的**确认（"看了第 3 节的方案，用了那个思路"），
       泛泛的"辛苦了"效果接近忽视；
     - 公开场合复述时，说出原始贡献者的名字。
   - 完成标准：至少落地两项常态化的署名/确认机制，写进流程而非依赖记忆。

4. **补上产出的下游可见性**
   - 让做的人看到**产出被谁用了、改变了什么**：
     - 客服看到自己处理的工单最终结果；
     - 后端看到自己接口支撑的业务数据；
     - 内容作者看到读者的具体反馈而非仅仅阅读量；
     - 志愿者看到受助者的回音。
   - 完成标准：每个角色都有一条明确的"下游反馈回路"。

5. **保护完整性：让劳动有终点**
   - 参照宜家效应的硬边界（见 `nih-co-creation-buyin`）：**未完成的劳动不产生依恋**。
   - 动作：把长期无终点的工作切分成有明确交付物的阶段；
     每个阶段有一个可保留、可展示的产物。
   - 完成标准：每个成员在任意时点都能指出"我最近完成并留存下来的一件东西"。

6. **最后才考虑增加激励**
   - 若第 1–5 步全部落实后仍有动机问题，再考虑物质激励，
     并按 `incentive-inverted-u` 的规则设计额度。
   - 完成标准：能说明为什么非货币杠杆已用尽。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **报酬明显不公或低于市场**：用"意义感"替代应得的报酬是剥削。
  本 skill 的所有工具都以公平报酬为前提。
- **问题出在能力或流程**：人想做但做不到（工具难用、审批太长、信息不通），
  再多认可也无用。先用 `ability-simplification`。
- **人已经决定要走**：认可机制是长期投入，不是挽留话术。
- **认可被用作绩效考核的替代品**：署名和公开表扬一旦与考评强绑定，
  会退化成新的市场规范（见 `social-market-norm-switch`），失去社会规范的力量。

### 作者在书中警告的失败模式

- **忽视的代价被严重低估**：管理者通常认为"没批评就是默认认可"，
  实验证明忽视的效果接近摧毁那一端，而非接近认可那一端。
- **摧毁会抹平内在兴趣**：西西弗斯条件下，原本热爱乐高的人的优势**完全消失**。
  这意味着"招热爱这份工作的人"无法对冲结构性的意义摧毁。
- **无意义的工作同时侵蚀诚信**：碎纸机条件下作弊上升。
  动机问题与合规问题在此处同源。
- **未完成的劳动不产生依恋**：让人投入却不让他完成，比不让他投入更糟。

### 作者的盲点 / 时代局限

- 乐高与折纸实验都是**短时、低利害的实验室任务**，
  与真实职场中长达数年的意义感形成机制有距离。方向可信，幅度不可外推。
- 艾瑞里团队的部分研究已卷入数据可靠性争议（详见 `fudge-factor-integrity` B 段）。
  但"认可提升产出"这一方向在组织行为学中有大量独立文献支持
  （Hackman-Oldham 工作特征模型等），本 skill 的核心结论不依赖单一来源。
- 书中未讨论**认可的通货膨胀**：当署名与表扬变得廉价且普遍时，
  其信号价值会衰减。实践中需要控制频率与具体性。
- 未讨论**负面反馈**的作用。本 skill 只覆盖"被看见"，
  不覆盖"被批评"的动机效应。
- 远程与异步协作是当代最典型的西西弗斯高发场景，
  但成书时这类工作形态尚未普及，书中无对应案例。

### 容易混淆的邻近方法论

- **马斯洛需求层次 / 赫兹伯格双因素**：那些是需求分类的框架；
  本 skill 给出的是一个**极小且可操作的单一信号**——产出是否被承认存在。
- **游戏化（Gamification）**：那用积分徽章制造外部反馈，
  容易滑入市场规范；本 skill 强调的是真实产出的真实去向。
- **表扬与正向反馈技巧**：那关注**怎么说**；本 skill 指出关键不在措辞，
  而在**产出有没有被保留和使用**这一结构事实。
