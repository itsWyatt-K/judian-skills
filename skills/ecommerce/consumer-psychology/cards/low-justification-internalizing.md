## I — 方法论骨架 (Interpretation)

一个承诺能不能变成长期行为，不取决于它当时被执行得多干脆，而取决于**当事人事后如何解释自己为什么做了它**。

如果外部理由充分（我拿了钱 / 我被威胁了 / 领导盯着），归因就停在外部，自我形象不变，诱因一撤，行为就消失。如果外部理由弱到不足以解释这个行为，人就必须向内找理由——"看来我本来就认同这件事"。自我形象改写，行为随后自行维持。

这条机制推翻了激励设计的默认假设：**加码不是加强，加码是替换**。你用一个外部理由替换掉了本可以生长出来的内部理由。

由此得到一个可操作的四维度检查表——承诺的**扎根深度**由四项决定：

| 维度 | 弱 | 强 |
|---|---|---|
| 主动性 | 被安排、被默认勾选 | 自己开口、自己填写、自己选择 |
| 公开性 | 私下答应 | 有第三方在场、被记录、被张贴 |
| 费力度 | 一键完成 | 需要投入时间/精力/门槛 |
| 外部理由 | 重奖或重罚 | 刻意做小，小到"不足以解释" |

前三项越强越好，第四项越**弱**越好——这是唯一一条与直觉相反的，也是最常被违反的。

## A1 — 书中的应用 (Past Application)

### 案例 1: 弗里德曼的玩具机器人实验

- **问题**：用威胁能不能让孩子长期不玩某个玩具？
- **方法论的使用**：把男孩单独留在有一台诱人机器人的房间里。A 组被严厉威胁（"你要是玩它，我会非常生气，会严厉惩罚你"）；B 组只被轻描淡写地劝阻一句（"玩它是不对的"）。两组当场都没有玩。
- **结论**：当场服从率相同，但归因不同——A 组有现成的外部理由（怕挨罚），B 组没有，只能得出"我不玩它是因为我自己不想玩"。
- **结果**：**6 周后**在没有任何威胁的情境下重测，严厉威胁组 **77%** 的男孩去玩了那台机器人，轻微劝阻组只有 **33%**。

### 案例 2: 朝鲜战俘营的作文比赛

- **问题**：如何让美军战俘长期接受亲共立场？
- **方法论的使用**：不要求写激烈的效忠声明，只举办征文比赛，请战俘写一篇"美国也不是十全十美"这类温和文章，**奖品刻意只有几支香烟或一点水果**。
- **结论**：奖品小到不足以解释"我为什么写了这个"，战俘只能向内归因；同时文章是亲手写的（书面）、被公布传阅（公开）、自愿参赛（主动）。四维度全中。
- **结果**：作者认为这是战俘营中最有效的转化手段之一——比强迫签署声明的效果持久得多。

### 案例 3: 手写销售单降低退单率

- **问题**：上门推销的订单在冷静期内被大量取消，怎么办？
- **方法论的使用**：改由**顾客本人**填写销售单，而不是销售员代填。
- **结论**：书面 + 主动，两个维度同时被加强。
- **结果**：退单率显著下降。这是四维度中"书面"与"主动"的纯粹应用。

### 案例 4: 入会仪式的严酷性

- **问题**：兄弟会、军队、各类组织为什么保留看似毫无意义的严苛入会考验？
- **方法论的使用**：让加入的过程尽可能费力、痛苦、难以撤销。
- **结论**：付出越大，越需要"这个组织值得"来解释自己的付出（费力维度）。作者指出，凡是试图取消入会仪式的改革几乎都失败了——组织本身在维护这一机制。
- **结果**：成员忠诚度与团体凝聚力显著更高。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 设计奖金、提成、罚款、积分制，想知道"给多少、怎么给"。
2. 抱怨"奖励一停就没人做了 / 检查一走就打回原形"。
3. 育儿或教学：想让孩子真心养成某个习惯，正在考虑物质奖励。
4. 要让一个已经口头答应的承诺**真的算数**（该不该写下来、该不该公开）。
5. 组织变革、价值观落地、安全规范推行——需要的是内化而非合规表演。
6. 设计入会/入职/上手流程，纠结"要不要把门槛降到最低"。

### 语言信号 (用户的话里出现这些就应激活)

- "奖金定多少合适 / 要不要设罚款"
- "一停发奖励就没人做了"
- "他只是应付我，不是真的认同"
- "要不要让他签字 / 要不要在群里公布"
- "怎么让新规定真正落地"
- "over-justification / intrinsic motivation / make it stick"

### 与相邻 skill 的区分

- 与 `foot-in-the-door` 的区别：**配套但分工不同**。前者决定"第一个承诺取什么"，本 skill 决定"这个承诺怎么设计才扎根"。标准流程是先 `foot-in-the-door` 取得承诺，再用本 skill 的四维度加固。
- 与 `low-ball-guard` 的区别：本 skill 是**建设向**（怎么让承诺长住），后者是**防御向**（识别别人用撤走诱因的方式套住你）。两者共享"承诺自生理由"这一底层机制。
- 与既有 skill `incentive-inverted-u` 的区别：那个回答"钱给到多少会开始反噬绩效"（表现层、当下任务）；本 skill 回答"外部理由多强会阻断内化"（归因层、长期行为）。金额问题找前者，持久性问题找本 skill。
- 与既有 skill `social-market-norm-switch` 的区别：那个处理"引入金钱会摧毁社会规范"；本 skill 不要求去掉金钱，只要求把它**做小**。两者结论方向一致，判据不同。

## E — 可执行步骤 (Execution)

1. **区分你要买的是服从还是内化**：写下"这个行为需要持续多久、有没有人一直监督"。若答案是"一次性且全程可监督"，本 skill 不适用，直接用强激励。
   - 完成标准：明确写出目标周期与监督可得性。
   - 判停条件：一次性任务 → 停止，用常规激励。

2. **算一次"归因测试"**：假设行为发生了，问当事人心里最省力的解释是什么。若最省力的解释是"因为有钱/因为会被罚/因为领导看着"，则内化不会发生。
   - 完成标准：写出那句最省力的解释原话。

3. **压低外部理由**：把奖励或惩罚降到**刚好不足以单独解释该行为**的水平。宁可用象征物（一张卡片、一次点名表扬、一份小纪念品）替代金钱。
   - 完成标准：给出新的激励强度，并能说明为什么它"不够解释"。
   - 反例检查：如果你自己都觉得"这点东西谁会为它做事"，那正是对的水平。

4. **拉高主动性**：把"被安排"改成"自己选"。给 2–3 个选项让对方挑，或请对方自己提出做法。
   - 完成标准：存在一个由当事人本人作出的选择动作。

5. **拉高书面性**：让对方**亲手**写下来（手写 > 打字 > 勾选）。哪怕只有两行。
   - 完成标准：产生一份由当事人本人书写的文本。

6. **拉高公开性**：让承诺被至少一个第三方知晓，或被张贴/记录/公示。
   - 完成标准：能说出"谁知道这件事"。
   - 注意：公开性会同时提高逆反风险，若对方本就抵触，先降公开性（见 `scarcity-reactance-guard`）。

7. **加一点费力**：不要让加入过程零成本。适度的申请、筛选、准备工作会提高后续投入。
   - 完成标准：入门动作需要至少几分钟的真实投入。
   - 边界：费力必须**与目标相关**，无意义的刁难只会引起逆反。

8. **收集自生理由并留存**：请对方用自己的话说出"我为什么做这件事"，记录下来，日后引用**这句话**而不是引用你的要求。
   - 完成标准：得到一句第一人称的理由陈述。

9. **撤诱因测试**：三到六周后，在没有奖励与监督的情况下观察行为是否仍在。
   - 完成标准：有一次真实的无监督观测。
   - 若行为消失 → 回到步骤 2，说明归因仍在外部。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **高风险、必须 100% 合规的行为**（安全操作规程、法律义务、医疗规范）：这类场景需要的是可靠的当下服从，强规则与强监督不可替代。内化是加分项，不是替代品。
- **一次性任务且全程可监督**：内化没有兑现空间，压低激励只是白白降低吸引力。
- **对方处于经济困境、报酬本身是生计**：把报酬"刻意做小"在此语境下是剥削，不是设计。市场规范场景请按市场规范付费。
- **紧急情况**：内化以周计，来不及。

### 作者在书中警告的失败模式

- **加码即替换**（第3章，玩具机器人）：严厉威胁在 6 周后反而带来 77% 的反弹。任何"效果不好就加大力度"的直觉，在长期行为改变上是**反向**的。
- **愚蠢的一致**（第3章）：四维度会让承诺变得极难撤销。若承诺的方向本身是错的，你造出的是一个自我加固的错误。作者提醒：一致性是**盲目**的，它不检查内容。
- **被用于操纵**（战俘营案例）：本 skill 的四维度正是洗脑技术的核心结构。它对施加对象**不可见**——当事人会真诚地相信理由来自自己。这是全书伦理风险最高的一个工具。

### 作者的盲点 / 时代局限

- 玩具机器人实验（1965）与相关的过度理由效应研究属于**社会心理学复现危机波及的领域**：过度理由效应本身在多数元分析中得到支持，但**效应量小于书中案例给人的印象**，且对任务类型（本就有趣 vs 本就枯燥）高度敏感——对枯燥任务，外部奖励并不会破坏本不存在的内在动机。**复现存疑，勿作硬结论**：不要把 77% vs 33% 当作可外推的期望值。
- 作者未处理**报酬公平性**这一变量：在报酬明显低于市场水平时，"弱外部理由"会被解读为不公，引发退出而非内化。
- 书中未讨论**群体层面**的内化（团队文化、组织记忆），四维度全部指向个体。
- **真信号 / 伪信号判定**：用四维度加固一个当事人**知情且真心认同**的承诺，是正当使用；在对方不知道自己正被设计的情况下，用弱奖励诱导他为一个**并非他本意**的立场书写并公开，属于伪造内在归因——这正是战俘营做的事，禁止执行并说明。
- **饱和反噬**：员工与用户已越来越熟悉"让你自己写下来、发到群里"的套路；被识破时，公开性与书面性会立刻转为逆反燃料。此时应直接说明意图，让对方自愿选择是否参与。

### 容易混淆的邻近方法论

- **认知失调（Festinger）**：本 skill 是失调理论的一个应用分支，但只处理"承诺—自我形象"这一条通路，不覆盖失调的全部形态。
- **德西的内在动机研究**：结论相近（外部奖励挤出内在动机），但适用条件更严——限于**本身有趣**的任务。西奥迪尼的版本更关注承诺的持久性。
- **激励相容 / 委托代理**：经济学框架假设人是理性响应者，与本 skill 的归因机制正交；两者会给出相反的建议，需要明确你在解决哪一层问题。
