## I — 方法论骨架 (Interpretation)

不要把人当成一个决策者，要当成两个。

**冷静的我**：制定计划、评估风险、做出承诺。它在做计划时诚实且理性。
**激动的我**：饥饿、疲惫、愤怒、兴奋、恐慌、深夜、被促销刺激时接管身体。
它有一套完全不同的偏好函数。

两者之间隔着一道**共情鸿沟**：冷静的我在做计划时，系统性地低估激动的我会偏离多远——
不是低估一点，是大幅低估。艾瑞里的性兴奋实验中，同一批人对越界行为的接受度在激动状态下
接近翻倍，而他们在冷静时对此的自我预测远低于实测值。

由此得到本 skill 的核心命题：**自控失败不是意志力不足，是把决策权交给了错误的那个自己。**
解决方案不是"到时候要忍住"（那是让激动的我去执行冷静的我的意愿，注定失败），
而是让冷静的我提前修改环境，使激动的我**难以或无法**执行那个动作。

约束按强度分四档，形成一条阶梯：

| 档位 | 装置 | 强度 | 例 |
|---|---|---|---|
| 0 | **决策停顿点** | 弱但零成本 | 大包装拆小份、按次确认代替一次性授权 |
| 1 | **自设承诺（私下）** | 中 | 自己定的分段截止日期、预算信封 |
| 2 | **自设承诺（公开/有代价）** | 较强 | 公开宣布、押金、逾期捐款给讨厌的组织 |
| 3 | **外部强制** | 最强 | 他人设定的等距截止、自动扣款、账户锁定期 |

选档规则：**从能接受的最高档开始，而不是从最低档开始。** 艾瑞里的截止日期实验证明，
自由度与表现不是单调关系——被强制等距设定截止日期的班级成绩最好，自设的次之，
完全自由的最差。人们讨厌被限制，但被限制时表现更好。

## A1 — 书中的应用 (Past Application)

### 案例 1：三个班级的截止日期实验

- **问题**：学生总把论文拖到最后一刻，质量受损。艾瑞里想知道自由度与表现的关系。
- **方法论的使用**：三个班分别采用——A 班由教师强制规定三次等距截止日期；
  B 班学生学期初自行设定三个截止日期（一经设定不可更改，逾期扣分）；C 班只有期末一个总截止。
- **结论**：如果人是理性的，C 班（自由度最高、无额外约束）应当不差于其他班。
- **结果**：成绩排序为 A > B > C。**自设约束优于无约束，但仍不如外部强制。**
  值得注意的是 B 班中把三个日期都设在最后一周的学生，成绩最差——
  自设约束只有在真正分散时才有效。

### 案例 2：艾瑞里的干扰素治疗

- **问题**：治疗丙肝需连续 18 个月每周自行注射干扰素，副作用是当晚剧烈发热与呕吐。
  同期患者依从率极低。
- **方法论的使用**：他没有依靠意志力，而是把注射与一件**只在注射当晚才允许做的、
  自己极度期待的事**绑定——攒下一周想看的电影，注射后立刻观看，让电影覆盖掉发作前的时段。
- **结论**：把即时的痛苦与即时的奖励在时间上重叠，抵消激动的我对"今晚跳过一次"的强烈偏好。
- **结果**：他是该实验中唯一完成全程治疗的患者。

### 案例 3：小包装的停顿点

- **问题**：人在看电视时会无意识吃完整袋零食，事后惊讶于总量。
- **方法论的使用**：把同样总量的零食分装成若干小包。信息、口味、总量都没变，
  变的只是"要继续吃就必须拆开一个新包装"这一个动作。
- **结论**：拆包装这个动作不做任何判断，它只是把无意识行为重新提交给意识。
- **结果**：摄入量显著下降。同一原理适用于预算信封、按次授权、分批采购。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **反复拖延**：明知重要，总在截止前才动手，且每次都发誓下次提前。
2. **冲动消费/超支**：深夜下单、促销失守、信用卡账单超预期。
3. **饮食、饮酒、屏幕时间**等在特定情境下必然失守的行为。
4. **情绪化决策**：吵架时发消息、生气时回邮件、恐慌时抛售。
5. **长期依从**：吃药、复健、锻炼、储蓄、写作日更。
6. **给团队设计交付节奏**：要不要设中间里程碑、让成员自设还是统一规定。
7. **给产品设计防后悔机制**：撤销窗口、二次确认、冷静期。

### 语言信号

- "我知道该做，就是做不到"
- "每次都拖到最后一晚"
- "忍不住就下单了"
- "一到晚上就控制不住"
- "怎么逼自己坚持下去"
- "中间要不要设几个 deadline"
- "self-control / procrastination / commitment device / impulse buying"

### 与相邻 skill 的区分

- 与 `bmat-behavior-diagnosis`：那是**分诊**——判断缺的是动机、能力还是触发。
  如果诊断结果是"动机存在但被冲动覆盖"，才进入本 skill。诊断在前，本 skill 在后。
- 与 `ability-simplification`：那个**减少**摩擦让行为更容易发生；
  本 skill 常常要**增加**摩擦让行为更难发生。方向相反，不可混用。
- 与 `commitment-escalation`：那个是对**他人**用小行动撬动态度改变（说服）；
  本 skill 是对**自己**（或自愿参与者）设置事后难以撤销的约束（自控）。
- 与 `decision-pause-point`（已并入本 skill 第 0 档）：停顿点是本阶梯中最弱但成本最低的一档。
- 与 `mental-accounting-envelope`：那个聚焦金钱的分账户；本 skill 提供的是通用约束阶梯，
  金钱信封是其在财务领域的一个实例，两者常组合使用。

## E — 可执行步骤 (Execution)

1. **定位"热态"的具体触发条件**
   - 不要接受"我自控力差"这种描述。追问：**上次失守是什么时候？当时几点？在哪里？
     刚发生了什么？身体状态如何？**
   - 完成标准：写出 2–3 个可识别的具体情境（如"晚上 11 点后、在床上、刷完工作消息之后"），
     而不是笼统的性格描述。
   - 判停条件：若失守没有可识别的情境规律，而是全天弥漫，可能是动机或能力问题，
     转 `bmat-behavior-diagnosis` 重新分诊。

2. **确认这是冷热冲突，而不是偏好冲突**
   - 问：**冷静时的你，真心希望不做这件事吗？** 如果冷静时也觉得"其实做了也挺好"，
     那不是自控问题，是目标不清。
   - 完成标准：能明确说出冷态的我的意愿，且它与热态行为确实冲突。

3. **按阶梯从高到低选装置（不要从低往高试）**
   - 先问：**能不能上外部强制（第 3 档）？** 能，就用。自动扣款、他人代管密码、
     账户锁定期、由主管统一规定的等距里程碑。
   - 不能，退到第 2 档：公开承诺 + 有代价（押金、逾期捐款、向具体某人报备）。
   - 再退到第 1 档：私下自设，但**必须真正分散**（截止日期实验中把三个日期堆在最后的学生成绩最差）。
   - 兜底第 0 档：在行为流中插入停顿点——拆小包装、取消免密支付、把 App 移出首屏、
     一次性授权改按次确认。
   - 完成标准：选定档位并写出**具体到可执行的动作**（谁、什么时候、改哪个设置）。

4. **给约束加一个即时的正向配对（可选但强烈推荐）**
   - 参照干扰素案例：把不得不做的痛苦动作，与一件**只有做了才能享受的即时愉悦**绑定。
   - 完成标准：写出配对的具体内容，且该愉悦不能在不做痛苦动作时获得。

5. **设计撤销成本，而不是依赖记忆**
   - 好的约束装置有一个共同特征：**热态的我要撤销它，需要付出可观的代价或时间。**
   - 检验：设想热态的我此刻要绕过它，需要几步？如果一键即可，等于没设。
   - 完成标准：明确写出撤销路径与其代价。

6. **不要用"我会注意的"结尾**
   - 若最终方案里出现"提醒自己""下次注意""增强意识"，判定为无效方案，返回第 3 步。
   - 完成标准：方案中至少有一项是**环境或默认值的物理改变**。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **对方并不想改变**：给不想戒的人上锁是控制而非帮助。约束装置必须由**冷静状态下的当事人
  自愿选择**，这是尤利西斯契约的伦理前提（尤利西斯是自己下令把自己绑上桅杆的）。
- **成瘾或临床问题**（物质依赖、进食障碍、赌博障碍、抑郁）：这些超出行为设计范畴，
  需要专业医疗干预。本 skill 的装置可作为辅助，不能作为方案。
- **需要灵活应变的工作**：给探索性研发、危机响应、创意工作设置刚性里程碑，
  可能牺牲掉必要的调整空间。约束适用于**已知该做什么但做不到**，不适用于**还不知道该做什么**。
- **约束会伤害他人**：例如为了自己不回消息而关掉紧急联系人的通道。

### 作者在书中警告的失败模式

- **自设约束若不分散就无效**：截止日期实验中，B 班里把三个日期全设在最后一周的学生，
  成绩甚至不如平均水平。自设的自由度容易被热态的我提前滥用。
- **"知道"完全不足以改变行为**：艾瑞里在多处强调，把偏差讲清楚给受试者听，
  行为不会改变。因此本 skill 明令禁止以"提高意识"作为方案。
- **免费/无痛的选项会绕过所有约束**：任何"先用后付""免密支付""无限量"的设计
  都会在热态下自动失守，必须优先处理。

### 作者的盲点 / 时代局限

- ⚠️ **自我损耗（Ego Depletion）机制存疑**：册4 第 5 章"疲惫会让我们受骗上当"
  依赖"自控是可耗尽的有限资源"这一理论。该理论在 2016 年由 23 个实验室联合复制**未能复现**。
  因此本 skill 的机制表述刻意改为"**预设规则以降低对当场决策质量的依赖**"，
  不依赖自我损耗假设。"别在疲惫时做决定"这条经验法则仍有睡眠剥夺与认知负荷等
  其他证据支持，但不应以意志力耗尽为解释。
- 艾瑞里团队的部分不诚实研究已卷入数据可靠性争议（详见 `fudge-factor-integrity` B 段），
  引用其实验数字时宜作方向性证据。
- 截止日期实验为单一课程、单一学期的课堂研究，效应方向可信，具体幅度不宜外推到职场。
- 书中的装置以个人为单位设计，对"多人共享的约束"（团队纪律、家庭规则）讨论不足。

### 容易混淆的邻近方法论

- **时间管理 / 番茄工作法**：那是效率工具，假定人愿意开始；本 skill 处理的是
  **开始不了**与**中途失守**。
- **助推（Nudge）**：机制相近（改变环境而非说教），但助推通常由第三方对大众实施；
  尤利西斯契约由当事人对自己实施，伦理性质不同。
- **意志力训练**：本 skill 明确不采用该路径。
