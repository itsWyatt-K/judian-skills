## I — 方法论骨架 (Interpretation)

主流的合规直觉来自贝克尔的理性犯罪模型（SMORC）：
**作弊量 = f(收益, 被抓概率, 惩罚强度)**。加大监控、提高罚则，作弊就会减少。

艾瑞里系统地操纵了这三个变量，结果是：**三个都不显著改变实际作弊量。**
把被抓概率降到接近零，人们并没有多骗；把单题奖金提高，人们也没有多骗。

真正决定作弊量的是另一个东西——**经验系数（Fudge Factor）**：
一个人在**仍能把自己视为好人**的前提下，所能作弊的最大幅度。

这个模型有三条重要推论：

**推论一：分布是长尾的反面。** 不是少数人偷很多，而是**大多数人偷一点点**。
所有小偷小摸的总和远超那几个大盗。因此把审计火力全押在大额异常上，
会漏掉主体损失。

**推论二：与真钱的每一层距离都会放大作弊。** 代币实验中，仅仅让人先赢代币、
再去几步之外换成现金（金额、匿名度、被抓概率完全不变），谎报量**翻倍**。
麻省理工冰箱实验更直白：公共冰箱里的 6 罐可乐 72 小时内全部消失，
而放在旁边的 6 张 1 美元纸币一张未动。**现金出现得越少，道德滑坡越快。**

**推论三：自我形象是连续的，第一次破例的成本远超其表面金额。**
戴冒牌太阳镜的受试者，在完全不相关的后续任务中作弊率显著更高——
一旦给自己贴上"我是个会造假的人"的标签，防线就整体后撤。

由此，治理杠杆有且只有三处：**①收窄合理化空间；②缩短与真钱的心理距离；
③保护"我还是个诚实的人"这一自我叙事的完整性。** 惩罚不在其中。

## A1 — 书中的应用 (Past Application)

### 案例 1：矩阵测试证伪 SMORC

- **问题**：人到底是按成本收益权衡决定要不要作弊，还是另有机制？
- **方法论的使用**：给受试者 20 道找数字配对题，限时后自报答对数领钱。
  设置多个条件：把答卷放进碎纸机（被抓概率≈0）、提高每题奖金、改变监督强度。
- **结论**：若 SMORC 成立，无监督组与高奖金组应显著多报。
- **结果**：碎纸机条件下人们平均多报约 2 题（而非全报满分）；
  提高奖金没有增加作弊；提高被抓风险也没有减少作弊。
  作弊量稳定在"还能自认为诚实"的那条线上。

### 案例 2：代币中介实验

- **问题**：作弊与金钱之间隔一层，会发生什么？
- **方法论的使用**：同样的矩阵测试，但答对后先领代币，再走到几步外的桌子兑换成等额现金。
  金额、匿名性、被抓概率均不变，只多了一个兑换动作。
- **结论**：若人是按经济账作弊，多一个兑换步骤应无影响。
- **结果**：谎报数目是直接领现金组的**两倍**。一步中介 = 两倍作弊。

### 案例 3：冒牌太阳镜

- **问题**：一次小小的自我妥协是否会外溢？
- **方法论的使用**：给受试者发放太阳镜，一组被告知是正品，一组被告知是仿冒品
  （实际都是正品），随后做无关的作弊测试。
- **结论**：如果自我形象是分领域的，戴什么眼镜不该影响做题诚实度。
- **结果**：被告知戴仿冒品的一组作弊比例显著更高。
  艾瑞里称之为"去他的效应"——自我标签一旦松动，整体防线就后撤。

### 案例 4：创造力与不诚实

- **问题**：什么样的人更会作弊？智力还是别的？
- **方法论的使用**：同时测量受试者的智力与创造力，再与作弊量做关联。
- **结论**：作弊需要的不是聪明，而是**为自己编出一个合理故事的能力**。
- **结果**：创造力与作弊量显著正相关；智力与作弊量无显著相关。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill

1. **报销/费用造假屡禁不止**，金额都不大但覆盖面广。
2. **加大处罚没用**：已经上了更严的罚则和更多监控，违规量没变。
3. **要设计一套代币、积分、额度、虚拟资产、期权机制**，想预判舞弊风险点。
4. **数据注水**：KPI 上报、实验数据、内容原创性、工时填报。
5. **灰色地带太多**：规则模糊、可解释空间大的岗位（市场、创意、投行、销售）。
6. **想给自己设诚信防线**：知道自己在某些场景下容易"稍微放宽一点"。

### 语言信号

- "罚也罚了，查也查了，就是管不住"
- "都是小钱，但加起来很吓人"
- "这个规则解释起来弹性太大"
- "积分/代币被薅了"
- "报销单看着都合规，但就是不对劲"
- "why don't penalties work / expense fraud / small-scale cheating / integrity design"

### 与相邻 skill 的区分

- 与 `dishonesty-contagion-governance`：本 skill 处理**个体的合理化空间与心理距离**；
  那个处理**群体身份如何传播作弊**。若线索是"某人带头之后大家都开始了"，用那个。
- 与 `conflict-of-interest-design`：那个处理**建议者因利益关联而无意识偏移**
  （不是有意作弊），且专门指出"披露"无效。若问题是顾问/评审/测评的可信度，用那个。
- 与 `manipulation-matrix-ethics`：那是判断"这个产品设计该不该做"的伦理自查；
  本 skill 是诊断与治理已经发生的不诚实。
- 与 `incentive-inverted-u`：那个处理奖金额度与绩效的关系；
  本 skill 明确指出**提高奖金并不增加作弊**，两者结论不冲突但主题不同。

## E — 可执行步骤 (Execution)

1. **先否定 SMORC 假设**
   - 检查现有方案里有多少资源投在"提高被抓概率"和"加重处罚"上。
   - 明确告知：这两项在实验中均**无显著效果**。若现有方案 80% 是这两项，
     判定为方向性错误。
   - 完成标准：现有治理投入被分类为"惩罚型"与"结构型"，并给出比例。

2. **测量分布形态，而非最大单笔**
   - 统计：参与轻微违规的**人数比例**，而非最大金额。
   - 若"很多人小额"→ 经验系数问题，继续本 skill。
   - 若"极少数人大额"→ 可能是普通舞弊或内控漏洞，转常规审计与风控，本 skill 不适用。
   - 完成标准：得到人数占比与金额分布两张图，并做出判定。

3. **画出心理距离地图（核心动作）**
   - 列出组织内所有"**不是现金但等价于现金**"的东西：报销额度、积分、代币、
     内部币、优惠券、期权、加班调休、公司资产、云资源配额、试用样品、
     素材版权、他人工时。
   - 每一项标注它与真实现金之间隔了几层。**层数越多，风险越高。**
   - 完成标准：得到一张按距离排序的风险清单，这就是舞弊高发区地图。

4. **缩短距离（对高风险项逐项处理）**
   - **现金化**：把代金券改为现金报销，把内部币改为真实预算科目。
   - **显性化**：在使用界面上显示等值人民币金额（"本次云资源消耗 ¥312"）。
   - **缩链条**：减少兑换、转手、代办的中间步骤。
   - **实名化**：让消耗与具体的人和用途绑定。
   - 完成标准：至少对清单前三项给出具体改造动作。

5. **收窄合理化空间**
   - 找出所有"**说得过去**"的模糊表述：合理范围内、视情况而定、
     必要的业务招待、约等于、大致。
   - 逐条改为可判定的具体标准，或要求事前留痕（先申报再发生）。
   - 关键点：创造力高的团队（市场、创意、投行）**需要更硬的结构约束而非更多培训**，
     因为他们编故事的能力最强。
   - 完成标准：模糊条款清单 + 逐条改写方案。

6. **保护自我形象的完整性**
   - 有效方向：让人在**行动发生的当下**接触到自己的身份标识
     （实名、署名、与自己名字绑定的界面）；避免匿名化与批量化的操作界面。
   - 避免的方向：道德说教、价值观培训、签署冗长的承诺书——
     证据不支持这些能改变行为。
   - ⚠️ **明确禁用**：不要采用"把承诺签名栏移到表单开头"这一广为流传的干预
     （原因见 B 段）。
   - 完成标准：方案中含至少一项身份可见性设计，且不含被撤稿的签名前置方案。

7. **切断第一次破例的外溢**
   - 参照冒牌太阳镜结论：组织中被默许的"无害小灰色地带"会外溢到关键领域。
   - 动作：识别当前被默许的最小违规（早退打卡、私用打印、虚报小额餐费），
     评估是否值得清理——清理的价值不在追回金额，而在维护"我们这里不这么干"的自我叙事。
   - 完成标准：列出被默许项，并对是否清理给出理由。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **面对的是有组织的、蓄意的、大额的欺诈**：职业骗子不受"想当好人"的约束，
  对他们只有传统的风控、审计与法律手段有效。本 skill 针对的是普通人的小额高频不诚实。
- **法律与监管要求必须有惩戒**：本 skill 说"惩罚不是有效杠杆"，
  不等于"可以取消惩罚"。罚则有威慑之外的追责、赔偿与合法性功能。
- **纯技术性作弊**（脚本刷单、羊毛党工作室、自动化攻击）：那是对抗性技术问题，
  不是心理学问题。

### 作者在书中警告的失败模式

- ⚠️⚠️ **【严重】"签名前置"实验已因数据造假被撤稿。**
  "把'我保证以上信息属实'的签名栏从表单末尾移到开头，可显著降低谎报"
  是本书传播最广的可执行建议之一。该研究的原始数据被独立分析认定为**伪造**，
  论文已撤稿，多次大规模重复实验也未能复现效应。
  **任何以此为核心的合规方案不得采用。** 若已在实施，应停止依赖它并重新评估。
- **加大惩罚与监控无效**（矩阵实验）：这是本 skill 的起点，也是最容易被组织忽略的一条。
- **主体损失来自多数人的小骗**：只盯大额异常的审计策略会系统性漏掉主要损失。
- **创造力越强越会作弊**：把高创造力团队等同于高道德水准是危险的假设。
  越鼓励创新，越要同步收窄可解释空间。
- **信息与培训不改变行为**：讲清楚道理不会减少作弊。干预必须落在结构上。

### 作者的盲点 / 时代局限

- ⚠️ **本书的证据基础存在重大可靠性风险。** 除签名前置实验撤稿外，
  艾瑞里团队的其他若干研究也受到质疑。本 skill 刻意只保留了**被独立复现或方向稳健**的部分
  （心理距离效应、长尾分布、群体归属方向性），并对具体效应量不作精确引用。
  使用者引用本书数据时应加注来源争议。
- **自我损耗（Ego Depletion）机制不成立**：册4 第 5 章"疲惫让我们受骗上当"
  依赖该理论，2016 年多实验室联合复制未能复现。相关内容已从本 skill 中剔除，
  详见 `ulysses-self-control-architecture` 的 B 段。
- 实验对象以美国大学生为主，跨文化外推需谨慎。
- 全书写于加密货币、虚拟资产、AI 生成内容大规模普及之前。
  这些恰恰是"心理距离"被拉到极致的新场景——本 skill 的第 3 步在今天比书中更重要，
  但书里没有对应案例。

### 容易混淆的邻近方法论

- **舞弊三角（Fraud Triangle：压力/机会/合理化）**：三要素中的"合理化"与经验系数重叠，
  但舞弊三角主要用于解释**重大舞弊**；经验系数解释**普遍的小额不诚实**，
  且明确否认"机会"（被抓概率）是主要变量。
- **破窗理论**：与"第一次破例的外溢"相似，但那是环境线索→犯罪的社会学假说，
  本 skill 是自我标签→跨领域行为的心理机制。
- **道德许可效应（Moral Licensing）**：做了好事之后允许自己做坏事。
  这是经验系数的另一面，在 `conflict-of-interest-design` 中被用于解释披露悖论。
