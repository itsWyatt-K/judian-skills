# 新手场景推荐表（说人话 → 装哪个工位）

> 用法：左边是用户会说的原话，右边是应对工位。**一次只装需要的**，不够用再加。
> 不知道从哪开始？先装门房「`选包门房`」，三问定位。
>
> 安装方式：种子市场 / 技能商店搜**中文名**即装；或 GitHub 装
> （仓库 `itsWyatt-K/judian-skills`，工位在 `skills/singles/ecommerce/<目录名>/`）。
>
> **诚实声明**：全部工位为 **E4 级**——成熟专业方法的重铸，未经当前模型实测，
> 推荐时不要暗示"已验证有效"。

## 两条纪律

1. **先预览、确认、再掏钱**：任何工位调用付费生成前，先把本批内容、数量、参数、参考摊开给用户看，取得确认再执行。
2. **平台参数不写死**：白底占比、占画比、时长上限等，一律以目标平台现行文档为准，拿不准的标「待复核」，不写估算值。
