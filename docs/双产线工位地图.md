## 一、总原则（两线共用）

1. **先预览、确认、再掏钱。** 任何调用付费生成接口之前，先把本批的内容、数量、参数、参考、输出摊开给用户看，取得明确确认再执行。这条是硬纪律，写进了每个工位。
2. **真实画面比形容词可靠。** 凡是必须保真的东西（人、手、持物、商品形状），给它一张真图做锚点，不要试图用提示词描述住。
3. **不可变短语跨镜逐字复用。** 角色外观、商品造型，各写一条短语，改一个字等于开新角色/新 SKU。
4. **一次只换一层参数。** 环境、背景、影调是可分别替换的三层；同时改会互相打架。
5. **平台参数不写死。** 时长上限、尺寸、白底占比等，一律进《产线事实表》现填现用，以目标平台现行文档为准。
6. **模型按任务挑。** 平面感/排版任务选擅长排版的模型；光影氛围任务选擅长光的模型。选错模型，返工两次抵掉全部收益。

## 二、AI 短剧产线（6 工位）

```
一句话创意 / 原著 / 剧本
        │
        ▼
 [S1] 短剧分镜表 ──────────► 节拍图 + 12 字段镜头卡 + 直出指令
        │
        ├─► [S2] 角色资产板 ──► 身份块六段 + 外观短语 + 两档出图方案
        │
        ▼
 [S3] 影视提示词编译 ──────► 图片提示词 + 视频提示词（按平台改写）
        │
        ▼
 [S4] 首尾帧与镜头衔接 ────► 三种衔接法选型 + 砍帧清单
        │
        ▼
 [S5] 跨镜一致性锁定 ──────► 换背景/换光影/动作迁移/前后向延长
        │
        ▼
 [S6] 成片装配 ────────────► 剪辑单 + 字幕 + 响度 + 验收清单
```

| 工位 | 目录 | 什么时候用 |
|---|---|---|
| S1 | `jd-drama-shot-list` | 有文字素材，要排镜头 |
| S2 | `jd-drama-asset-board` | 要角色设定图、三视图、角色档案；或角色老是变形 |
| S3 | `jd-drama-prompt-compile` | 要把意图写成提示词；或生成结果不稳定 |
| S4 | `jd-drama-frame-bridge` | 两段要接、要转场、要循环、要时间静止 |
| S5 | `jd-drama-consistency` | 换人、换背景、氛围不对、故事要接着演 |
| S6 | `jd-drama-assembly` | 素材齐了，要剪成片并交付 |

## 三、AI 电商产线（7 工位 + 1 公共附录）

```
一张原始商品照
        │
        ▼
 [E1] 电商主图 ───────────► 干净商品图 + 打光 + 合规主图/副图
        │
        ├─► [E2] SKU 变体矩阵 ─► 配色/材质/款式变体登记表
        │
        ├─► [E3] 产品三视图 ───► 多视角图 + 十六宫格粗筛
        │
        ├─► [E4] 场景植入与氛围 ► 使用场景图 + 氛围参考图换影
        │
        ├─► [E5] 平面海报排版 ─► 海报/详情图/社媒图（含文案位）
        │
        ├─► [E6] 产品运镜视频 ─► 环绕展示/迭代变形/节奏走秀
        │
        └─► [E7] 详情页长图 ───► 竞品拆解 → 模块规划 → 逐模块带字生成 → 750 宽拼接

 [E0] 画质净化（公共附录）──► 任何工位的产出出现油腻画质时先过本卡
```

| 工位 | 目录 | 什么时候用 |
|---|---|---|
| E1 | `jd-ec-main-image` | 只有手机随手拍，要上架主图 |
| E2 | `jd-ec-variant-matrix` | 要多个配色/材质/款式 |
| E3 | `jd-ec-triview` | 要多角度图、三视图 |
| E4 | `jd-ec-scene-infuse` | 商品要进场景、氛围要高级 |
| E5 | `jd-ec-key-visual` | 要海报、详情图、社媒图 |
| E6 | `jd-ec-product-video` | 静态图要变成产品短片 |
| E7 | `jd-ec-detail-page` | 商品资料要做成一条完整详情长图（含竞品拆解） |
| E0 | `jd-ec-quality-scrub` | 画面油腻/塑料感/AI 味/噪点（公共附录，双轨净化 + 平台分档） |
