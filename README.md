# judian-skills（剧典 · 工业级 AI 影像 Agent 产线系统）

> **v3.2.0 · 2026-09-23 · 双产线工位版**  
> **核心定位**：这不是简单的提示词合集，而是一套**驱动多智能体（Multi-Agent）在复杂视听生产中自主协同、受控交互与确定性交付的工业级 Agentic Workflow 运行时系统**。

## 架构总览：从「技能堆叠」到「工业级 Agent 交互系统」

传统 AI 创作往往面临三大困境：**Agent 自说自话导致算力滥用**、**过大技能池导致模型幻觉与乱选**、**长上下文导致产品关键信息漂移**。

## 核心技术创新点

### 1. 引导式人机协同对话（Guided Human-in-the-Loop Dialogue）
- **根除 Agent 失控**：通过 `ask_user` 与 Agent System Policy 深度机制化，Agent 在面对模糊任务时主动进行引导式对齐，首轮确认意图与目标产线。
- **透明决策门禁**：在每一道产生实际资产或消耗算力的工序前，Agent 必须将结构化方案（分镜、画面参数、提示词、排版版面）清晰呈现在用户面前，获得确认后方可执行。

### 2. Agent 自主技能装配与精准激活（Autonomous Skill Orchestration）
- **缩容即聚焦**：从历史 759 张分散卡收敛为 14 个原子化核心工位。降低模型的上下文噪音，将检索空间缩小到极致。
- **契约式工位调用**：每个工位配备清晰的输入、前置依赖、输出契约与证据链，使 Agent 具备自我判断“当前阶段需要调用哪个专业工位”的自主决策能力，而非僵硬的硬编码调用。

### 3. 选包门房与场景配方路由（Scene-Recipe Concierge Routing）
- **业务场景与技术参数解耦**：用户说“帮我做一个代步车宣传”或“我想拍个反转短剧”，门房中枢仅通过三个业务问题，即可精准推荐 1 个主工位 + 最多 2 个辅助工位。
- **场景配方预设（Presets）**：结合平台层预设能力，一键装配端到端产线，将多工位串联为流畅的工作流。

### 4. 渐进式参数提炼（Progressive Fact-Sheet Extraction）
- **反传统表单困境**：不强迫用户在启动时填写冗长问卷。
- **状态流转中枢**：依托轻量化《产线事实表》，从初始资料中先提取不可变基础事实（如产品不可变短语、角色外观锁、视觉调性），并在后续各工位流转中逐步追加衍生数据，彻底解决长周期对话中的特征漂移难题。

### 5. 行为遥测与数据驱动推荐（Telemetry & Dynamic Recommendation）
- **全链路使用量洞察**：设计了与平台底层紧密咬合的 usage 遥测统计机制，实时监控各工位的调用频次与流转瓶颈。
- **自适应热度与推荐**：以实测调用数据驱动技能市场的搜索排序与门房路由权重更新，让最有效、最经过实战检验的工位自然浮现。

## 三十秒上手（新手友好路径）

1. **装门房**：种子市场搜「`选包门房`」并激活。不知道从哪开始时，它会用三个问题把你送到对的工位。
2. **装产线预设**：搜「短剧产线起步」或「电商产线起步」一键挂齐整条线；或逐个搜工位中文名安装。
3. **按工位走**：打开《双产线工位地图》→ 填一次《产线事实表》→ 从该产线的第一个工位开始，一个工位一个交付物。
4. **纪律只有一条**：每个工位在调用付费生成前，都会先把本批内容 / 数量 / 参数 / 参考摊开给你看，**取得确认才执行**。

## 工位一览（中文真名在前，括号内为目录名）

### 短剧产线（S1–S6）

| 工位 | 技能名（目录名） | 职责边界与交付物 |
|---|---|---|
| S1 | `短剧分镜表`（`jd-drama-shot-list`） | 文本素材转化为标准化景别、机位、运镜分镜脚本 |
| S2 | `角色资产板`（`jd-drama-asset-board`） | 提取角色六段身份块与外观锚定短语，生成多视角设定图 |
| S3 | `影视提示词编译`（`jd-drama-prompt-compile`） | 影视工业级专业提示词编译与负向调控 |
| S4 | `首尾帧与镜头衔接`（`jd-drama-frame-bridge`） | 镜头转场、动势延续、前后帧无缝接合 |
| S5 | `跨镜一致性锁定`（`jd-drama-consistency`） | 视频主体、光影调性与场景的跨镜头一致性保持 |
| S6 | `成片装配`（`jd-drama-assembly`） | 镜头资产综合剪辑、节拍校准与成片交付 |

### 电商产线（E0–E7）

| 工位 | 技能名（目录名） | 职责边界与交付物 |
|---|---|---|
| E1 | `电商主图`（`jd-ec-main-image`） | 手机原图锚定保真，生成商用白底图与场景主图 |
| E2 | `SKU变体矩阵`（`jd-ec-variant-matrix`） | 严格保持商品几何结构，矩阵式批量衍生配色/材质 |
| E3 | `产品三视图`（`jd-ec-triview`） | 规范化工业多角度视图（正/侧/背）精确透视 |
| E4 | `场景植入与氛围`（`jd-ec-scene-infuse`） | 商业空间融入、光影投射对齐与高级质感渲染 |
| E5 | `平面海报排版`（`jd-ec-key-visual`） | 商业 KV 排版、主副标题排布与营销视觉整合 |
| E6 | `产品运镜视频`（`jd-ec-product-video`） | 静态高保真图驱动产品动势运镜视频生成 |
| **E7** | `详情页长图产线`（`jd-ec-detail-page`） | 竞品对标与长图模块化拆解，产出完整上架级详情长图 |
| E0 | `画质净化公共卡`（`jd-ec-quality-scrub`） | 消除画面油腻塑料感、AI 伪影与噪点（公共净化附录） |
| 门房 | `选包门房`（`scene-recipe-concierge`） | 需求意图分发中枢，模糊需求定位与工位指路 |

> **检索提示**：技能商店 / 种子市场搜**中文名**（如「电商主图」「短剧分镜表」）即装；
> 英文目录名仅用于 GitHub 安装路径，不要当检索词用。

## 证据等级（如实说明）

> **两套编号不要混**：`E0–E7` / `S1–S6` 是**工位号**；`E1–E5` 是**证据等级**（E1 最高）。

| 等级 | 含义 | 本库现状 |
|---|---|---|
| **E1** | 当前版本 + 当前模型 + 真实交付物验证 | 工位 E1 主图 / E4 场景植入 / E5 平面海报 / E7 详情长图产线（2026-09-23 安途代步椅真实案例） |
| E2 | 跨版本/跨模型真实成片 | 暂无 |
| E3 | 可复现工作流，未复渲染 | 暂无 |
| **E4** | 成熟专业方法（出版书/行业方法）重铸 | 其余工位 + E0 公共附录 |
| E5 | 启发/未验证技巧 | 无（不得虚标） |

- 口径引自 `docs/PACK-UPGRADE-CONTRACT.md` v1.0；**没有 E1/E2 证据的卡必须标 E4 或 E5，不得虚标**——虚标比不标更糟。
- 电商线以「真实交付物」对应口径中的「真实成片」。
- 没有「装上就提升成片质量」的承诺。v2.0.0 时代的 A/B 记录留档在 `benchmarks/`，边界说明见各报告原文。
