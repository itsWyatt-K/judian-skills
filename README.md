## 三十秒上手（新手友好路径）

1. **装门房**：种子市场搜「`选包门房`」并激活。不知道从哪开始时，它会用三个问题把你送到对的工位。
2. **装产线预设**：搜「电商产线起步」一键挂齐 E1–E6；或逐个搜工位中文名安装。
3. **按工位走**：打开《电商产线工位地图》→ 填一次《产线事实表》→ 从 E1 主图开始，一个工位一个交付物。
4. **纪律只有一条**：每个工位在调用付费生成前，都会先把本批内容 / 数量 / 参数 / 参考摊开给你看，**取得确认才执行**。

## 这个仓库是什么

一批**电商影像产线的方法论工位技能**，装在影策（Open AI Canvas）里给 Agent 用。
每个工位 = 一个单文件技能（SKILL.md），工位之间靠一份《产线事实表》交接；门房负责指路。

它不生产画面，也不替代影策的生成链路；它负责**生成之前的判断与工序**：
怎么拍（手机实拍降本）、怎么打光（三条路）、怎么保真（不可变短语 / 真图锚点）、
怎么合规（平台规则编码进提示词字段，而不是生成后补救）。

## 工位一览（中文真名在前，括号内为目录名）

| 工位 | 技能名（目录名） | 什么时候用 |
|---|---|---|
| E1 | `电商主图`（`jd-ec-main-image`） | 只有手机随手拍，要上架主图/副图 |
| E2 | `SKU变体矩阵`（`jd-ec-variant-matrix`） | 要多个配色/材质/款式变体 |
| E3 | `产品三视图`（`jd-ec-triview`） | 要多角度图、三视图 |
| E4 | `场景植入与氛围`（`jd-ec-scene-infuse`） | 商品要进场景、氛围要高级 |
| E5 | `平面海报排版`（`jd-ec-key-visual`） | 要海报、详情图、社媒图 |
| E6 | `产品运镜视频`（`jd-ec-product-video`） | 静态图要变成产品短片 |
| 门房 | `选包门房`（`scene-recipe-concierge`） | 不知道选哪个、模糊需求先问路 |

> **检索提示**：技能商店 / 种子市场搜**中文名**（如「电商主图」）即装；
> 英文目录名仅用于 GitHub 安装路径，不要当检索词用。
