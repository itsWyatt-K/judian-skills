# judian-skills（剧典技能库 · 公开版）

> 短剧创作方法论技能包，适配影策（Open AI Canvas）技能系统：
> 技能页 → 安装技能 → GitHub 标签 → 填本仓库地址 + 技能子目录（如 `skills/drama/onlyshot-3phase-cost`）。

## 分类

- `skills/drama/` 短剧技法
- `skills/creative/` 视觉提示词
- `skills/ecommerce/` 广告素材（筹备中）
